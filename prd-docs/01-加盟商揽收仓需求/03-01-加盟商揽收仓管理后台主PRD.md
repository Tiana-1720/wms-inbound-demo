## 一、业务背景

加盟商在南昌、赣州设立加盟揽收仓后，现网 WMS 缺少三类能力：接收速达「发车」预报、按空白调拨计划执行装车出库、把实装结果与东莞仓收货闭环。

本迭代在现网之上做增量，不重写集货仓、自营揽收仓：

- 新增仓库类型 **加盟揽收仓**，与 **自营揽收仓**、**集货仓** 拆开
- 加盟揽收仓收货订单由上游发车生成（**仅落南昌常规入库**）；东莞**常规入库**由现网逻辑在发车时自动推送，**不生调拨入库单**
- 调出仓为加盟揽收仓时走 **空单调拨**；计划调拨保持现网，本文不展开
- 空单调拨：**OMS 创建空白计划** → PDA **装车**生成/追加出库单（**已复核**）→ PC **确认出库**（**已出库**、库位库存 −）→ 东莞对该计划下**全部关联运单**常规入库收货完成 → 调拨 **已完成**

没有这些增量：加盟仓仍靠纸质交接，装车与出库脱节，总部无法按仓类型区分两套调拨。

## 二、功能范围

**In Scope（修改 / 优化 / 新增）**：

- 仓库类型新增 **加盟揽收仓**；现网「揽收仓」更名为 **自营揽收仓**（历史档案一次性迁移）
- 调拨策略按**调出仓库类型**带出默认：加盟揽收仓 → 空单调拨；不做仓到仓路由硬校验
- 接收速达发车推送，按**运单号**生成收货订单，状态=待收货，按**预报箱数**计预报库存
- 收货订单列表/详情可查看全部状态（含加盟路径用到的待收货 / 已绑托 / 已上架 / 已取消）
- 上游按运单号取消：仅待收货允许；已绑托、已上架拒绝。取消后状态=已取消，预报库存 −
- 同一**运单号**只能发车一次；未取消的重复发车拒绝；取消后重新发车则全量覆盖回待收货
- **调拨计划**（见 §3.2）：沿用现网「订单管理 → 调拨计划」及**详情页**；调拨计划新增**调拨类型**（上游推送计划运单=**计划调拨**，OMS 创建空白单=**空单调拨**）；**页面不展示该类型**、不提供按类型筛选或拆菜单；数据权限沿用现网（调出或调入命中可见），列表/Tab 同时含两类调拨；**本期后台增量**（OMS 创建空白调拨：必填**调出仓库**、**调入仓库**，不预填运单/托盘；PDA 装车 + PC 确认出库）仅作用于**空单调拨**（调出仓类型=**加盟揽收仓**）；**计划调拨**的创建、编辑、下推、PDA 复核/装柜沿用现网，不在本文重写；状态沿用现网 **待出库 / 已出库 / 已完成**，**预留已取消**（Tab 保留，**本期无取消入口**，后期迭代）
- 空单调拨出库：PDA **装车**生成/追加调出仓出库单（**已复核**）；PC **确认出库**→出库单 **已出库**、调拨计划 **已出库**、库位库存 −（见 §3.4）
- 空单 PDA 路径：不进入现网下架→复核→装柜；**装车时**生成/追加出库单，**不生调入仓调拨入库单**（东莞走发车现网推送的**常规入库**）
- **加盟揽收仓分货参数**：管理后台维护**小票阈值 M**、**小票混托票数上限 P**（§3.5）；未配置则 PDA 分货不可用
- **收货订单**详情日志（动作见 §5.1）：接收发车、上游取消、重新发车、PDA 确认绑托、PDA 上架完成

**Out of Scope**：

- 集货仓、自营揽收仓的原有收货、上架、出库计划、计划调拨、过机/到货扫描等（现网已有，本文不重写）
- 加盟商下单、贴标、发车界面（速达客户端）
- 速达报文开发（WMS 只接收）
- PDA 收货绑托、上架、装车的交互细节（另文；本文只定义回写与库存结果）
- **空单调拨取消**（后期迭代；状态枚举已预留，本期无列表/详情取消入口）
- 费用结算、运力调度、盘点、经营报表
- 管理后台手工新建收货订单
- 打印装车清单

### 3.4 与东莞仓对接（必须实现）

本文不描述东莞仓操作人员侧页面，只定义**空单调拨**与东莞仓的契约。计划调拨下推规则沿用现网（`WMS_V1.0 260314` §调拨计划生成出库单/收货订单），不在此重复。

**实现原则**：后台按单据 **`调拨类型`** 分支处理——**计划调拨**走现网引擎，**空单调拨**走本次增量引擎；**不按仓库单独配置下推时机**（见 §6.6 R24）。

#### 3.4.1 下推规则总览（按调拨类型分支）

| 维度 | 计划调拨（沿用现网） | 空单调拨（本次增量） |
| ---- | ---------------- | -------------- |
| **类型判定** | 上游推送计划运单 | OMS 创建空白单；调出仓库类型=加盟揽收仓（R02） |
| **创建时明细** | 上游推送计划运单 | **空**；不预填运单/托盘（R16） |
| **下推触发** | ① 创建计划时，若计划内**全部运单已在调出仓收货** → 立即下推<br>② 否则，等计划内运单**全部在调出仓收货后** → 下推 | **PDA 装车**生成/追加出库单（**已复核**）；**PC 确认出库**→出库单/调拨 **已出库** |
| **下推产物** | **同一触发点同时**生成：1 张调出仓出库单 + N 张调入仓入库单 | **仅**调出仓出库单（1 计划 : 1 出库单）；**不生**调入仓调拨入库单 |
| **出库单** | 1 计划 : 1 出库单；出库类型=调拨出库；状态=待出库 | 1 计划 : 1 出库单；PDA 装车后 **已复核**；PC 确认后 **已出库** |
| **东莞入库** | 调入仓入库单（调拨入库） | **不生调拨入库**；东莞**常规入库**由发车**现网自动推送** |
| **明细/数量来源** | 上游接口 + 复制原单 | PDA 装车扫描回写（扫箱号带出对应托） |
| **计划变更** | 增删运单、改两仓、运单/箱明细更新 → **同步更新**下游单据 | 创建后两仓锁定；**无 PC 改单、不同步下游**（R04/R22） |
| **PDA 作业路径** | 下架 → 复核 → 装柜（现网） | 装车；**不进入**现网复核/装柜 |
| **库存扣减** | 沿用现网 | **PC 确认出库**时库位库存 −（R14） |
| **调拨完结** | 沿用现网 | 东莞对该计划**全部关联运单**之**常规入库单**均**收货完成** → 已完成（R19） |

#### 3.4.2 计划调拨下推细则（沿用现网，本期不重写）

> 权威来源：`prd-docs/99-历史需求/WMS_V1.0 260314.md` §调拨计划生成出库单/收货订单

1. **触发条件（二选一，命中即下推）**
   - 创建调拨计划时，计划中**全部运单均已在调出仓库收货**（状态=已收货）→ **即刻**生成下游单据
   - 创建时未全部收货 → 待计划中运单**全部在调出仓收货后** → 再生成下游单据
2. **生成逻辑（出库单 + 入库单同批生成）**
   - **出库单**：1 个调拨计划 → 1 个出库单；出库类型=调拨出库；状态=待出库；明细取收货订单数据
   - **调入仓入库单**：1 个计划运单 → 1 张入库单；入库类型=调拨入库；预报仓库=调入仓库；收货仓库清空；收货单号重新生成；状态=待收货；其他数据复制原运单对应收货订单
3. **计划变更同步**
   - 调拨计划增删运单、更新调入/调出仓库、更新运单或箱明细 → **同步更新**已生成的收货订单（调入仓入库单视图）与出库单
4. **本期范围**
   - 创建、编辑、下推、PDA 复核/装柜、计划变更同步 → **代码与规则均沿用现网**，本文仅作对照说明

#### 3.4.3 空单调拨下推细则（本次增量）

> 与 §3.4.2 对照；东莞对接契约见 §3.4.4

1. **建计划阶段**：仅落调拨计划单（类型=空单调拨、状态=待出库、明细空）；**不**预生成出库单
2. **PDA 装车**：加盟揽收仓 PDA 装车扫描并确认（维护司机/车牌/电话）→ **同一调拨计划**下：
   - 若尚无出库单 → 生成 1 张调出仓出库单，状态=**已复核**；回写实装明细
   - 若已有出库单且状态=**已复核** → **不新建**；在原出库单下**追加**新运单明细
   - 调拨计划仍为 **待出库**；**不扣**库位库存；**不生**调入仓调拨入库单
3. **多次装车**：出库单 **已复核、未确认出库** 前，可多次装车追加运单；**确认出库后**不可再装
4. **PC 确认出库**（沿用现网出库管理）：出库单 **已复核** → **已出库**；调拨计划 → **已出库**；调出仓库位库存 **−**（R14）
5. **无计划变更同步**：待出库阶段无 PC 改单；已出库后全部只读
6. **与收货订单关系**：空单**不预填运单**；装车扫**库位库存中已上架货**（§3.5）

#### 3.4.4 空单调拨对接东莞仓契约

| 对接点 | 规则 |
| ---- | ---- |
| 东莞入库来源 | 加盟商发车时，**现网逻辑**自动向东莞推送**常规入库单**（`入库类型=常规入库`）；**不由**空单调拨装车/确认出库生成调拨入库单 |
| 关联运单 | 调拨计划下**关联运单**= PDA 装车扫描写入调拨明细/出库单明细的全部**运单号**（含多次装车追加） |
| 调拨完结触发 | 东莞仓对该计划下**全部关联运单**对应之**常规入库单**均**收货完成** → 调拨计划 **状态** → **已完成** |
| 不等待 | 东莞侧绑托、上架不阻塞调拨完结（R19） |
| 可见性 | 沿用现网：账号可用仓库命中**调出仓库或调入仓库**即可查看该调拨单 |




### 3.5 加盟揽收仓分货参数（管理后台）

> PDA 分货规则见《03-02》§十二；本节仅定义**后台可配置项**。

| 参数 | 含义 | 维护方式 | 校验 |
| :--- | :--- | :--- | :--- |
| **M** | 小票阈值（件）：预报箱数 ≤ M 判定为小票 | 库内配置，**必填** | 未配置则 PDA 分货入口提示「请先配置分货参数」 |
| **P** | 小票混托票数上限：同一未绑托混托格内最多容纳的小票运单数 | 管理后台按**加盟揽收仓**维护，**必填** | 正整数；建议默认 **5**（与会议口径对齐，可调整） |

- **菜单**：沿用现网基础资料/库内配置能力扩展（具体菜单路径对齐实施，本期须提供维护入口）
- **权限**：总部作业部或系统管理员可维护
- **生效**：保存后立即作用于 PDA 分货；进行中的分货会话以**进入分货页时**快照为准（待研发确认是否需强刷）

### 3.6 实体关系


| 关系            | 说明                        |
| ------------- | ------------------------- |
| 收货订单 : 速达发车   | 按**运单号** 1:1。未取消不可二次发车    |
| 收货订单 : 收货明细   | 1:N，明细按**箱号**             |
| 空单调拨 : 出库单    | 1:1；PDA 装车生成/追加，**已复核** → PC 确认 **已出库** |
| 空单调拨 : 东莞常规入库 | **无下推**；发车现网推送；完结按关联运单收货回写 |
| 空单调拨 : 收货订单   | 无下推。装车扫库位库存中已上架货 |

## 四、业务场景


| 场景ID | 场景          | 类型      | 说明                                     |
| ---- | ----------- | ------- | -------------------------------------- |
| S01  | 上游发车生成收货订单  | **主流程** | 按**运单号**落库待收货，预报库存 +**预报箱数**           |
| S02  | 待收货取消后重发    | **支线**  | 取消→已取消，预报库存 −；再发车全量覆盖回待收货（D15）         |
| S03  | OMS 创建空单调拨  | **主流程** | 调出=加盟揽收仓，必填调出/调入仓库，明细为空，状态=待出库         |
| S04  | 空单 PDA 装车 + PC 确认出库 | **主流程** | PDA 装车→出库单**已复核**；PC 确认出库→出库单/调拨**已出库**、库位库存 − |
| S05  | 东莞关联运单收货即调拨完结 | **主流程** | 东莞对该计划**全部关联运单**常规入库收货完成后，调拨→已完成；绑托/上架不挡完结 |
| S10  | 同一调拨计划多次装车 | **主流程** | 出库单**已复核**前可多次装车追加运单；确认出库后不可再装 |
| S06  | 已绑托/已上架不可取消 | **异常**  | 上游或 WMS 取消均拒绝                          |
| S07  | 预报与实收不一致    | **异常**  | 不改预报；须在待收货时走 S02。已绑托后只能线下处理            |
| S08  | 空单取消        | **后期迭代** | 预留：待出库且无扫描明细 → 已取消；**本期无取消入口**        |
| S09  | 重复发车        | **异常**  | 同一运单号未取消则拒绝，不用仓库号匹配                    |

## 五、状态机

状态变更只能通过动作，禁止表单直改**状态**。

### 5.1 收货订单（加盟揽收仓路径）

全局枚举沿用：待收货 / 收货中 / 已收货 / 已绑托 / 已上架 / 已取消。  
**加盟揽收仓不进入收货中、已收货**（那两条给自营/集货仓现网使用，本文不描述）。


| 状态  | 含义                | 是否终态          |
| --- | ----------------- | ------------- |
| 待收货 | 已收预报；**尚有未绑托箱时仍为本态**（不存在「部分绑托」状态） | 否             |
| 已绑托 | 该运单**全部箱号** PDA 绑托完成（无库存变动） | 否             |
| 已上架 | 上架完成，预报库存已结转库位库存  | **是**         |
| 已取消 | 待收货时取消成功          | 否（取消后重发可回待收货） |


```mermaid
stateDiagram-v2
    [*] --> 待收货 : 上游发车
    待收货 --> 已取消 : 取消发车
    已取消 --> 待收货 : 重新发车全量覆盖
    待收货 --> 已绑托 : PDA确认绑托
    已绑托 --> 已上架 : PDA上架完成
```




| 当前状态      | 动作       | 前置条件                   | 结果状态 | 后置影响                           | 失败处理       |
| --------- | -------- | ---------------------- | ---- | ------------------------------ | ---------- |
| （无单）      | 接收发车     | **运单号**无未取消的有效单；预报必填完整 | 待收货  | 生成**收货单号**；预报库存 +**预报箱数**      | 重复未取消运单：拒绝 |
| 待收货       | 上游取消     | 待收货                    | 已取消  | 预报库存 −                         | —          |
| 已取消       | 重新发车     | 原单已取消；新报文完整            | 待收货  | 按运单号全量覆盖头部与明细；预报库存按新**预报箱数**重建 | 必填缺失则保持已取消 |
| 待收货       | PDA 按托确认绑托 | 箱号匹配预报；该运单**尚有未绑托箱号** | **待收货** | 回写该托**托号**及明细**托号**；**不回写**头部**收货箱数**等；**不生成上架单**；无库存变动 | — |
| 待收货       | PDA 确认绑托（整单完成） | 箱号匹配预报；该运单**全部箱号**已绑托 | 已绑托  | 回写**托号**、**绑托完成时间**、**收货箱数**、**收货人**、**收货时间**、**收货仓库**；**不回写**收货重量/收货体积；无库存变动；**同事务生成上架单** | 无预报不可收     |
| 已绑托       | PDA 上架完成 | —                      | 已上架  | **上架完成时间**；预报库存 −、库位库存 +       | —          |
| 已绑托 / 已上架 | 取消       | —                      | 不变   | 无                              | 拒绝         |


**管理后台动作**：查看、筛选。无手工新增、无改预报、无直改状态。取消由上游接口或现网 WMS 取消入口触发，后台按上表校验。

### 5.2 空单调拨（沿用现网三态 + 预留已取消）

状态枚举：**待出库 / 已出库 / 已完成** 沿用现网（表格 12）；**已取消**为预留第四态（Tab 保留，**本期无用户入口写入**；后期迭代开放取消动作）。**列表状态仅通过 Tab 过滤，查询区不提供状态下拉**。


| 状态  | 含义                | 是否终态  | 本期 |
| --- | ----------------- | ----- | --- |
| 待出库 | 空单已建，待装车；出库单未确认出库前可多次装车 | 否     | 可用 |
| 已出库 | PC 确认出库完成；关联出库单已出库 | 否     | 可用 |
| 已完成 | 东莞对该计划全部关联运单常规入库均已收货 | **是** | 可用 |
| 已取消 | 待出库空单取消（预留）       | **是** | 枚举保留；**无取消入口** |


```mermaid
stateDiagram-v2
    [*] --> 待出库 : OMS 创建空白单
    待出库 --> 待出库 : PDA装车(出库单已复核)
    待出库 --> 已出库 : PC确认出库
    已出库 --> 已完成 : 东莞全部关联运单收货完成
    note right of 待出库 : 已取消：后期迭代\n本期无取消入口
```




| 当前状态 | 动作          | 前置条件                     | 结果状态 | 后置影响                         | 失败处理             |
| ---- | ----------- | ------------------------ | ---- | ---------------------------- | ---------------- |
| （无单） | 新增          | **调出仓库**类型=加盟揽收仓；调出/调入必填；**调出≠调入**（R29） | 待出库  | 生成**调拨计划单号**；明细空；表单不展示状态     | 缺仓、同仓则不可保存          |
| 待出库  | PDA 装车      | 已扫实装；维护司机/车牌/电话                     | **待出库**  | 回写明细；生成/追加出库单→**已复核**；**不扣**库位库存 | 拆票/目的仓与调入仓不一致则拦截 |
| 待出库  | PC 确认出库      | 关联出库单=**已复核**                     | 已出库  | 出库单→**已出库**；调拨→**已出库**；库位库存 −（R14） | 出库单非已复核则不可确认 |
| 已出库  | 东莞收货完成（系统） | 该计划下**全部关联运单**之东莞常规入库均已收货            | 已完成  | 对接回写，只读；后续绑托/上架不改调拨状态        | —                |
| 待出库  | 取消          | （后期迭代）明细无运单                | 已取消  | 全部只读                           | 已有扫描明细则拒绝        |


### 5.3 出库单（空单调拨 · 加盟路径增量）

空单调拨关联的调出仓出库单，在加盟路径下**新增/沿用**状态 **已复核**（PDA 装车完成）与 **已出库**（PC 确认出库）。


| 状态  | 含义                | 是否终态  |
| --- | ----------------- | ----- |
| 已复核 | PDA 装车完成，待 PC 确认出库 | 否     |
| 已出库 | PC 确认出库完成         | **是** |


| 当前状态 | 动作          | 前置条件                     | 结果状态 | 后置影响                         |
| ---- | ----------- | ------------------------ | ---- | ---------------------------- |
| （无单） | PDA 装车      | 调拨计划=待出库；已扫实装             | 已复核  | 生成出库单；回写司机/车牌/电话及明细          |
| 已复核 | PDA 装车（追加） | 同一调拨计划；出库单仍为已复核           | 已复核  | 在原出库单下追加运单明细；调拨仍为待出库        |
| 已复核 | PC 确认出库      | 沿用现网确认出库前置校验               | 已出库  | 库位库存 −；调拨计划 → 已出库            |
| 已出库 | —           | —                        | —    | 只读                           |

## 六、核心业务规则



### 6.1 仓库类型与调拨策略


| 规则ID | 规则                                      |
| ---- | --------------------------------------- |
| R01  | 仓库类型：集货仓、自营揽收仓、加盟揽收仓。现网揽收仓迁为自营揽收仓       |
| R02  | 调出仓库=加盟揽收仓 → 空单调拨（本文）。其他类型走现网计划调拨，不在此展开 |
| R03  | 不做南昌只能调东莞的组合硬校验；方向靠选仓与作业，不靠路由表          |
| R04  | 空单创建后**调出仓库**、**调入仓库**锁定                |
| R29  | **调出仓库**与**调入仓库**不能相同（空单调拨新增、计划调拨沿用同一约束） |




### 6.2 收货订单接收与取消


| 规则ID | 规则                                |
| ---- | --------------------------------- |
| R05  | **收货单号**由系统生成，全局唯一；收货订单仅由速达发车生成，不手工编号 |
| R06  | 未取消的同一运单号禁止再次发车                   |
| R07  | 取消后重发：全量覆盖头部与收货明细，回写字段重置，状态回待收货   |
| R08  | 仅待收货可取消；已绑托、已上架不可取消（加盟商与 WMS 均不可） |
| R09  | 预报类字段快照只读。差异不改预报，须待收货时走取消重发       |




### 6.3 加盟揽收仓库存


| 规则ID | 规则                |
| ---- | ----------------- |
| R11  | 发车：预报库存 +**预报箱数** |
| R12  | 绑托：库存不变           |
| R13  | 上架：预报库存 −，库位库存 +  |
| R14  | **PC 确认出库**时库位库存 −（PDA 装车不扣库存）       |
| R15  | 不使用「收货即暂存」        |




### 6.4 空单调拨与东莞仓对接


| 规则ID | 规则                                      |
| ---- | --------------------------------------- |
| R16  | **OMS 创建空白调拨**：WMS 管理后台「调拨计划→新增」即 OMS **同一能力**（含接口推送）；仅总部作业部可操作；明细仅 PDA 回写 |
| R17  | **预留（后期迭代）**：待出库无明细可取消→已取消；**本期无取消入口** |
| R18  | PDA 装车生成/追加出库单（**已复核**）；**不生**调入仓调拨入库单；东莞常规入库由发车现网推送 |
| R19  | 东莞对该计划**全部关联运单**常规入库均收货完成后调拨→已完成；不等待绑托、上架           |
| R20  | 不允许拆票装车；整票**运单号**一次关联                   |
| R30  | 同一调拨计划 1:1 出库单；已复核前可多次装车追加运单；确认出库后不可再装 |




### 6.5 字段锁定


| 规则ID | 规则                                       |
| ---- | ---------------------------------------- |
| R21  | 收货订单预报字段后台只读；**状态**不可下拉改                 |
| R22  | 空单调拨两仓创建后只读；待出库无业务字段可改；已出库/已完成/已取消全部只读 |


### 6.6 调拨下推引擎（按类型分支）


| 规则ID | 规则 |
| ---- | ---- |
| R24  | 调拨下推按 **`调拨类型`** 分支：**计划调拨**走现网引擎（§3.4.2），**空单调拨**走增量引擎（§3.4.3）；**不按仓库单独配置下推时机** |
| R25  | **计划调拨**：创建时或全部运单在调出仓收货后，**同批**生成出库单与调入仓入库单；计划变更**同步**下游（§3.4.2）；本期零改造 |
| R26  | **空单调拨**：**PDA 装车**生成/追加出库单（**已复核**）；**PC 确认出库**→已出库并扣库存；建计划**不下推**；**不生**调拨入库单（§3.4.3） |
| R27  | 计划调拨仍**同批**生成出库单与调入仓入库单；空单调拨**仅**生成调出仓出库单；差异在**触发时机与下游产物** |
| R28  | 东莞常规入库由发车现网推送；调拨完结按关联运单东莞收货回写（R19） |

## 七、权限设计

不新建权限引擎。账号、角色、菜单沿用现网。


| 角色       | 可见范围                                        | 加盟增量操作                      |
| -------- | ------------------------------------------- | --------------------------- |
| 总部作业部    | 可用仓库命中的收货订单、调拨单                             | OMS 创建空白调拨；PC 确认出库（沿用现网）            |
| 加盟揽收仓操作员 | 收货订单、调拨单：沿用现网数据权限 | 后台以查看为主；收货/装车在 PDA          |
| 集货仓操作员   | 调入仓库命中本仓的调拨单；东莞常规入库（发车现网推送）                        | 东莞收货作业沿用现网；调拨完结由系统回写 |


调拨数据权限**沿用现网**：调出仓库 **或** 调入仓库命中即可见。不改为「只按调出」。

## 八、边界与异常处理


| 场景            | 处理方式                       |
| ------------- | -------------------------- |
| 待收货时取消与绑托同时到达 | 已到已绑托则取消失败；仍为待收货则可取消。不可都成功 |
| 已绑托后发现少货      | 不可取消、不可改预报；线下协调            |
| 未取消重复发车       | 按运单号拒绝                     |
| 调入仓常规入库尚未全部收货    | 调拨保持已出库；全部关联运单收货完成后即已完成        |
| 并发重复装车同一调拨        | 同一出库单已复核状态下追加明细；确认出库后无装车入口           |
| 出库单已出库后再次确认出库     | 拒绝（只读）           |
