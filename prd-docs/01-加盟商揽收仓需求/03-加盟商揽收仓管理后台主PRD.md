## 一、业务背景

加盟商在南昌、赣州设立加盟揽收仓后，现网 WMS 缺少三类能力：接收速达「发车」预报、按空单执行调拨、发车后把实装结果交给集货仓继续收货。

本迭代在现网之上做增量，不重写集货仓、自营揽收仓：

- 新增仓库类型 **加盟揽收仓**，与 **自营揽收仓**、**集货仓** 拆开
- 加盟揽收仓收货订单由上游发车生成，差异不在 WMS 改预报
- 调出仓为加盟揽收仓时走 **空单调拨**；计划调拨保持现网，本文不展开
- 空单发车后必须对接集货仓：生成调入仓入库单，该单命中**手动收货策略**（按收货 → 绑托 → 上架执行入库）；**调入仓收货完成即调拨完结**，不等待绑托、上架

没有这些增量：加盟仓仍靠纸质交接，集货仓无法按实装运单收货，总部无法按仓类型区分两套调拨。

## 二、功能范围

**In Scope（修改 / 优化 / 新增）**：

- 仓库类型新增 **加盟揽收仓**；现网「揽收仓」更名为 **自营揽收仓**（历史档案一次性迁移）
- 调拨策略按**调出仓库类型**带出默认：加盟揽收仓 → 空单调拨；不做仓到仓路由硬校验
- 接收速达发车推送，按**运单号**生成收货订单，状态=待收货，按**预报箱数**计预报库存
- 收货订单列表/详情可查看全部状态（含加盟路径用到的待收货 / 已绑托 / 已上架 / 已取消）；**预报仓库**与**收货仓库**分列分筛
- 上游按运单号取消：仅待收货允许；已绑托、已上架拒绝。取消后状态=已取消，预报库存 −
- 同一**运单号**只能发车一次；未取消的重复发车拒绝；取消后重新发车则全量覆盖回待收货
- **调拨计划**（见 §3.2）：沿用现网「订单管理 → 调拨计划」；调拨计划新增**调拨类型**（上游推送=**计划调拨**，总部手工创建=**空单调拨**）；**页面不展示该类型**、不提供按类型筛选或拆菜单；数据权限沿用现网（调出或调入命中可见），列表/Tab 同时含两类调拨；**本期后台增量**（总部手工新增空单：必填**调出仓库**、**调入仓库**，不预填运单/托盘；PDA 装车发车）仅作用于**空单调拨**（调出仓类型=**加盟揽收仓**）；**计划调拨**的创建、编辑、下推、PDA 复核/装柜沿用现网，不在本文重写；状态沿用现网 **待出库 / 已出库 / 已完成**，**预留已取消**（Tab 保留，**本期无取消入口**，后期迭代）
- 空单发车后对接集货仓：生成调出仓出库单 + 调入仓入库单（见 §3.4；相对现网计划调拨，下推时机与数据来源见 §3.4.1）
- 空单 PDA 路径：不进入现网复核/装柜；**发车时**才生成出库单与下游入库单（见 §3.2）
- 详情页**操作日志**按单据拆分，展示列统一为：**操作内容**、**操作时间**、**操作人**（不跨单混排）
- **收货订单**详情日志（动作见 §5.1）：接收发车、上游取消、重新发车、PDA 确认绑托、PDA 上架完成
- **调拨计划**详情日志（动作见 §5.2）：新增、PDA 发车、调入仓收货完成（系统）
- 界面统一展示 **运单号**（接口仍可叫订单号）

**Out of Scope**：

- 集货仓、自营揽收仓的原有收货、上架、出库计划、计划调拨、过机/到货扫描等（现网已有，本文不重写）
- 加盟商下单、贴标、发车界面（速达客户端）
- 速达报文开发（WMS 只接收）
- PDA 收货绑托、上架、装车的交互细节（另文；本文只定义回写与库存结果）
- **空单调拨取消**（后期迭代；状态枚举已预留，本期无列表/详情取消入口）
- 费用结算、运力调度、盘点、经营报表
- 管理后台手工新建收货订单
- 打印装车清单

## 三、单据定位



### 3.1 收货订单（加盟揽收仓增量）


| 项目   | 内容                                    |
| ---- | ------------------------------------- |
| 单据层级 | 预报层。与入库单共用表，主键**收货单号**                |
| 核心职责 | 承载速达发车预报，作为加盟仓 PDA 收货唯一依据；无预报不可收      |
| 单据来源 | 速达发车推送；不提供手工新增                        |
| 加盟路径 | 待收货 → 已绑托 → 已上架；或待收货 → 已取消。不经过收货中、已收货 |
| 菜单   | 订单管理 → 收货订单，可查看全部状态（与现网列表一致，不按状态藏单）   |
| 操作日志 | 详情页展示；类型见 §5.1；格式见 §2（操作内容、操作时间、操作人）   |




### 3.2 调拨计划单（空单调拨增量）


| 项目   | 内容                                           |
| ---- | -------------------------------------------- |

| 数据范围 | 数据权限沿用现网：调出仓库 **或** 调入仓库命中可见。列表/Tab 同时含计划调拨与空单调拨，**不提供按类型筛选或拆菜单**；**本期后台增量**（总部手工新增空单、PDA 装车发车）仅作用于**空单调拨**（调出仓类型=加盟揽收仓）；**计划调拨**的创建、编辑、下推、PDA 复核/装柜沿用现网，不在本文重写；状态沿用现网 **待出库 / 已出库 / 已完成**，**预留已取消**（Tab 保留，**本期无取消入口**，后期迭代） |
| 调拨类型 | 系统字段：**计划调拨**（上游推送）、**空单调拨**（总部手工新增）；后台落库区分；**列表/详情/新增页均不展示、不可筛** |
| 单据层级 | 计划层。不直接扣库存                                   |
| 核心职责 | 总部锁定**调出仓库**、**调入仓库**（空单）；实装由 PDA 回写；一计划多**运单号** |
| 单据来源 | 上游推送 → **计划调拨**；调出仓库类型=加盟揽收仓时，总部手工新增 → **空单调拨**                       |
| PDA 路径 | **空单**：装车扫描 + 发车确认；**不进入**现网下架→复核→装柜；建计划时**不**预生成待出库出库单；**发车时**生成出库单并下推调入仓入库单。**计划调拨**：沿用现网 PDA 复核/装柜，本文不展开 |
| 下游   | 发车后：调出仓出库单 + 调入仓入库单（对接集货仓，见 §3.4）                   |
| 操作日志 | 详情页展示；类型见 §5.2；格式见 §2（操作内容、操作时间、操作人）   |

### 3.4 与集货仓对接（必须实现）

本文不描述集货仓如何做收货入库页面，只定义**空单调拨**交给集货仓的契约。计划调拨下推规则沿用现网（`WMS_V1.0 260314` §调拨计划生成出库单/收货订单），不在此重复。

**实现原则**：后台按单据 **`调拨类型`** 分支处理下推——**计划调拨**走现网引擎，**空单调拨**走本次增量引擎；**不按仓库单独配置下推时机**（见 §6.6 R24）。

#### 3.4.1 下推规则总览（按调拨类型分支）

| 维度 | 计划调拨（沿用现网） | 空单调拨（本次增量） |
| ---- | ---------------- | -------------- |
| **类型判定** | 上游推送创建 | 总部手工新增；调出仓库类型=加盟揽收仓（R02） |
| **创建时明细** | 上游推送计划运单 | **空**；不预填运单/托盘（R16） |
| **下推触发** | ① 创建计划时，若计划内**全部运单已在调出仓收货** → 立即下推<br>② 否则，等计划内运单**全部在调出仓收货后** → 下推 | **仅 PDA 装车确认发车**时（R18） |
| **下推产物** | **同一触发点同时**生成：1 张调出仓出库单 + N 张调入仓入库单 | **同一触发点同时**生成：1 张调出仓出库单 + N 张调入仓入库单 |
| **出库单** | 1 计划 : 1 出库单；出库类型=调拨出库；状态=待出库 | 1 计划 : 1 出库单；明细继承 PDA 实装 |
| **调入仓入库单** | 1 运单 : 1 张；入库类型=调拨入库；复制原收货订单数据 | 1 实装运单 : 1 张；实装量**写入预报列**；生成时集货仓**预报库存 +预报箱数** |
| **明细/数量来源** | 上游接口 + 复制原单 | PDA 装车扫描回写（扫库位库存中已上架货） |
| **计划变更** | 增删运单、改两仓、运单/箱明细更新 → **同步更新**下游单据 | 创建后两仓锁定；**无 PC 改单、不同步下游**（R04/R22） |
| **PDA 作业路径** | 下架 → 复核 → 装柜（现网） | 装车扫描 + 发车；**不进入**复核/装柜 |
| **集货仓库存** | 沿用现网暂存/存储规则 | 调入仓入库单**生成时**按**预报箱数**计**预报库存 +** |
| **调入仓收货策略** | 沿用现网 | **手动收货策略**（收货 → 绑托 → 上架） |
| **调拨完结** | 沿用现网 | 调入仓该批入库单均**收货完成** → 已完成（R19）；不等待绑托/上架 |

#### 3.4.2 计划调拨下推细则（沿用现网，本期不重写）

> 权威来源：`prd-docs/99-历史需求/WMS_V1.0 260314.md` §调拨计划生成出库单/收货订单

1. **触发条件（二选一，命中即下推）**
   - 创建调拨计划时，计划中**全部运单均已在调出仓库收货**（状态=已收货）→ **即刻**生成下游单据
   - 创建时未全部收货 → 待计划中运单**全部在调出仓收货后** → 再生成下游单据
2. **生成逻辑（出库单 + 入库单同批生成）**
   - **出库单**：1 个调拨计划 → 1 个出库单；出库类型=调拨出库；状态=待出库；明细取收货订单数据
   - **调入仓入库单**：1 个计划运单 → 1 张入库单；入库类型=调拨入库；预报仓库=调入仓库；收货仓库清空；收货单号重新生成；状态=待收货；其他数据复制原运单对应收货订单
3. **计划变更同步**
   - 调拨计划增删运单、更新调入/调出仓库、更新运单或箱明细 → **同步更新**已生成的收货订单（调入仓入库单视图）与出库单
4. **本期范围**
   - 创建、编辑、下推、PDA 复核/装柜、计划变更同步 → **代码与规则均沿用现网**，本文仅作对照说明

#### 3.4.3 空单调拨下推细则（本次增量）

> 与 §3.4.2 对照；对接集货仓契约见 §3.4.4

1. **建计划阶段**：仅落调拨计划单（类型=空单调拨、状态=待出库、明细空）；**不**预生成出库单/调入仓入库单
2. **发车触发**：加盟揽收仓 PDA 装车确认发车 → 调拨计划状态 → **已出库**；**同一事务**内：
   - 回写实装明细（运单号、客户代码、箱数、重量、体积）
   - 调出仓库位库存 **−**（R14）
   - 生成 1 张调出仓出库单 + 按实装运单各 1 张调入仓入库单
3. **无计划变更同步**：待出库阶段无 PC 改单；已发车后全部只读
4. **与收货订单关系**：空单**不预填运单**、**不下推**收货订单；装车扫**库位库存中已上架货**（§3.5）

#### 3.4.4 空单调拨对接集货仓契约

| 对接点  | 规则                                                                           |
| ---- | ---------------------------------------------------------------------------- |
| 触发时机 | 加盟揽收仓 PDA 装车确认发车，调拨计划 **状态** → 已出库                                           |
| 调出仓  | 生成出库单：**调拨计划单号**、**归属仓库**=调出仓库，明细继承实装**运单号**、**客户代码**、**箱数**、**重量**、**体积**   |
| 调入仓  | 按实装运单各生成一张入库单；**入库类型=调拨入库**；**预报仓库**=**调入仓库**；**收货仓库**空，待集货仓收货回写；**收货单号**新生成 |
| 收货策略 | 调拨入库单**命中手动收货策略**，含义是：集货仓按**标准入库流程**执行，即 **收货 → 绑托 → 上架**。不是「只能走 PC 收货、不能过机」 |
| 拆单   | **一个实装运单号对应一张调入仓入库单**                                                        |
| 回写   | 调入仓该批入库单均**收货完成**后，调拨计划 **状态** → 已完成。绑托、上架继续按标准流程做，不挡住调拨完结                   |
| 集货仓库存 | 调入仓入库单**生成时**，集货仓按每张单的**预报箱数**计**预报库存 +**（实装箱数/重量/体积已写入预报列）；收货完成等后续节点沿用现网集货仓库存规则，本文不展开 |
| 可见性  | 沿用现网：账号可用仓库命中**调出仓库或调入仓库**即可查看该调拨单，故集货仓账号能看到作为调入方的空单                         |




### 3.5 实体关系


| 关系            | 说明                        |
| ------------- | ------------------------- |
| 收货订单 : 速达发车   | 按**运单号** 1:1。未取消不可二次发车    |
| 收货订单 : 收货明细   | 1:N，明细按**箱号**             |
| 空单调拨 : 出库单    | 发车后 1:1                   |
| 空单调拨 : 调入仓入库单 | 1:N，按实装运单拆                |
| 空单调拨 : 收货订单   | 无下推。空单不预填运单，装车扫库位库存中的已上架货 |

## 四、业务场景


| 场景ID | 场景          | 类型      | 说明                                     |
| ---- | ----------- | ------- | -------------------------------------- |
| S01  | 上游发车生成收货订单  | **主流程** | 按**运单号**落库待收货，预报库存 +**预报箱数**           |
| S02  | 待收货取消后重发    | **支线**  | 取消→已取消，预报库存 −；再发车全量覆盖回待收货（D15）         |
| S03  | 总部创建空单调拨    | **主流程** | 调出=加盟揽收仓，必填调出/调入仓库，明细为空，状态=待出库         |
| S04  | 空单发车对接集货仓   | **主流程** | 发车→已出库；出库单 + 调入仓调拨入库单（手动收货策略=收货→绑托→上架） |
| S05  | 调入仓收货即调拨完结  | **主流程** | 调入仓入库单收货完成后，调拨→已完成；绑托/上架不挡完结           |
| S06  | 已绑托/已上架不可取消 | **异常**  | 上游或 WMS 取消均拒绝                          |
| S07  | 预报与实收不一致    | **异常**  | 不改预报；须在待收货时走 S02。已绑托后只能线下处理            |
| S08  | 空单取消        | **后期迭代** | 预留：待出库且无扫描明细 → 已取消；**本期无取消入口**        |
| S09  | 重复发车        | **异常**  | 同一运单号未取消则拒绝，不用仓库号匹配                    |

## 五、状态机

状态变更只能通过动作，禁止表单直改**状态**。

### 5.1 收货订单（加盟揽收仓路径）

全局枚举沿用：待收货 / 收货中 / 已收货 / 已绑托 / 已上架 / 已取消。  
**加盟揽收仓不进入收货中、已收货**（那两条给自营/集货仓现网使用，本文不描述）。


| 状态  | 含义                | 是否终态          |
| --- | ----------------- | ------------- |
| 待收货 | 已收预报，未确认绑托        | 否             |
| 已绑托 | PDA 收货绑托完成（无库存变动） | 否             |
| 已上架 | 上架完成，预报库存已结转库位库存  | **是**         |
| 已取消 | 待收货时取消成功          | 否（取消后重发可回待收货） |


```mermaid
stateDiagram-v2
    [*] --> 待收货 : 上游发车
    待收货 --> 已取消 : 取消发车
    已取消 --> 待收货 : 重新发车全量覆盖
    待收货 --> 已绑托 : PDA确认绑托
    已绑托 --> 已上架 : PDA上架完成
```




| 当前状态      | 动作       | 前置条件                   | 结果状态 | 后置影响                           | 失败处理       |
| --------- | -------- | ---------------------- | ---- | ------------------------------ | ---------- |
| （无单）      | 接收发车     | **运单号**无未取消的有效单；预报必填完整 | 待收货  | 生成**收货单号**；预报库存 +**预报箱数**      | 重复未取消运单：拒绝 |
| 待收货       | 上游取消     | 待收货                    | 已取消  | 预报库存 −                         | —          |
| 已取消       | 重新发车     | 原单已取消；新报文完整            | 待收货  | 按运单号全量覆盖头部与明细；预报库存按新**预报箱数**重建 | 必填缺失则保持已取消 |
| 待收货       | PDA 确认绑托 | 箱号匹配预报                 | 已绑托  | 回写**托号**、**绑托完成时间**、**收货箱数**、**收货人**、**收货时间**、**收货仓库**；**不回写**收货重量/收货体积；无库存变动 | 无预报不可收     |
| 已绑托       | PDA 上架完成 | —                      | 已上架  | **上架完成时间**；预报库存 −、库位库存 +       | —          |
| 已绑托 / 已上架 | 取消       | —                      | 不变   | 无                              | 拒绝         |


**管理后台动作**：查看、筛选（含**预报仓库**、**收货仓库**分列）。无手工新增、无改预报、无直改状态。取消由上游接口或现网 WMS 取消入口触发，后台按上表校验。

### 5.2 空单调拨（沿用现网三态 + 预留已取消）

状态枚举：**待出库 / 已出库 / 已完成** 沿用现网（表格 12）；**已取消**为预留第四态（Tab 保留，**本期无用户入口写入**；后期迭代开放取消动作）。**列表状态仅通过 Tab 过滤，查询区不提供状态下拉**。


| 状态  | 含义                | 是否终态  | 本期 |
| --- | ----------------- | ----- | --- |
| 待出库 | 空单已建，待装车          | 否     | 可用 |
| 已出库 | 已发车，已生成出库单与调入仓入库单 | 否     | 可用 |
| 已完成 | 调入仓该批入库单均已收货      | **是** | 可用 |
| 已取消 | 待出库空单取消（预留）       | **是** | 枚举保留；**无取消入口** |


```mermaid
stateDiagram-v2
    [*] --> 待出库 : 总部创建空单
    待出库 --> 已出库 : PDA发车
    已出库 --> 已完成 : 调入仓收货完成
    note right of 待出库 : 已取消：后期迭代\n本期无取消入口
```




| 当前状态 | 动作          | 前置条件                     | 结果状态 | 后置影响                         | 失败处理             |
| ---- | ----------- | ------------------------ | ---- | ---------------------------- | ---------------- |
| （无单） | 新增          | **调出仓库**类型=加盟揽收仓；调出/调入必填；**调出≠调入**（R29） | 待出库  | 生成**调拨计划单号**；明细空；表单不展示状态     | 缺仓、同仓则不可保存          |
| 待出库  | PDA 发车      | 已扫实装                     | 已出库  | 回写明细；库位库存 −；出库单；调入仓入库单（§3.4）；集货仓**预报库存 +预报箱数** | 拆票/目的仓与调入仓不一致则拦截 |
| 已出库  | 调入仓收货完成（系统） | 该计划下调拨入库单均已收货            | 已完成  | 对接回写，只读；后续绑托/上架不改调拨状态        | —                |
| 待出库  | 取消          | （后期迭代）明细无运单                | 已取消  | 全部只读                           | 已有扫描明细则拒绝        |

## 六、核心业务规则



### 6.1 仓库类型与调拨策略


| 规则ID | 规则                                      |
| ---- | --------------------------------------- |
| R01  | 仓库类型：集货仓、自营揽收仓、加盟揽收仓。现网揽收仓迁为自营揽收仓       |
| R02  | 调出仓库=加盟揽收仓 → 空单调拨（本文）。其他类型走现网计划调拨，不在此展开 |
| R03  | 不做南昌只能调东莞的组合硬校验；方向靠选仓与作业，不靠路由表          |
| R04  | 空单创建后**调出仓库**、**调入仓库**锁定                |
| R29  | **调出仓库**与**调入仓库**不能相同（空单调拨新增、计划调拨沿用同一约束） |




### 6.2 收货订单接收与取消


| 规则ID | 规则                                |
| ---- | --------------------------------- |
| R05  | **收货单号**由系统生成，全局唯一；收货订单仅由速达发车生成，不手工编号 |
| R06  | 未取消的同一运单号禁止再次发车                   |
| R07  | 取消后重发：全量覆盖头部与收货明细，回写字段重置，状态回待收货   |
| R08  | 仅待收货可取消；已绑托、已上架不可取消（加盟商与 WMS 均不可） |
| R09  | 预报类字段快照只读。差异不改预报，须待收货时走取消重发       |
| R10  | **预报仓库**与**收货仓库**分字段、分筛选，不合并      |




### 6.3 加盟揽收仓库存


| 规则ID | 规则                |
| ---- | ----------------- |
| R11  | 发车：预报库存 +**预报箱数** |
| R12  | 绑托：库存不变           |
| R13  | 上架：预报库存 −，库位库存 +  |
| R14  | 装车发车：库位库存 −       |
| R15  | 不使用「收货即暂存」        |




### 6.4 空单调拨与集货仓对接


| 规则ID | 规则                                      |
| ---- | --------------------------------------- |
| R16  | 仅总部可新建空单；明细仅 PDA 回写                     |
| R17  | **预留（后期迭代）**：待出库无明细可取消→已取消；**本期无取消入口** |
| R18  | 发车后按 §3.4 生成调入仓入库单；命中手动收货策略=按收货→绑托→上架执行；生成时集货仓**预报库存 +预报箱数** |
| R19  | 调入仓该批入库单均收货完成后调拨→已完成；不等待绑托、上架           |
| R20  | 不允许拆票发车；整票**运单号**一次关联                   |




### 6.5 字段锁定


| 规则ID | 规则                                       |
| ---- | ---------------------------------------- |
| R21  | 收货订单预报字段后台只读；**状态**不可下拉改                 |
| R22  | 空单调拨两仓创建后只读；待出库无业务字段可改；已出库/已完成/已取消全部只读 |
| R23  | 界面列名用**运单号**                             |


### 6.6 调拨下推引擎（按类型分支）


| 规则ID | 规则 |
| ---- | ---- |
| R24  | 调拨下推按 **`调拨类型`** 分支：**计划调拨**走现网引擎（§3.4.2），**空单调拨**走增量引擎（§3.4.3）；**不按仓库单独配置下推时机** |
| R25  | **计划调拨**：创建时或全部运单在调出仓收货后，**同批**生成出库单与调入仓入库单；计划变更**同步**下游（§3.4.2）；本期零改造 |
| R26  | **空单调拨**：**仅 PDA 发车时**同批生成出库单与调入仓入库单；建计划**不下推**；计划变更**不同步**下游（§3.4.3） |
| R27  | 两类调拨均在**同一触发点同批**生成出库单与调入仓入库单；差异在**何时触发**，不在「两张单是否分开生成」 |
| R28  | **收货策略**（如手动收货）与**下推时机**解耦：下推由 `调拨类型` 决定；调入仓如何收货由收货策略决定 |

## 七、权限设计

不新建权限引擎。账号、角色、菜单沿用现网。


| 角色       | 可见范围                                        | 加盟增量操作                      |
| -------- | ------------------------------------------- | --------------------------- |
| 总部作业部    | 可用仓库命中的收货订单、调拨单                             | 新增空单调拨（取消后期迭代）            |
| 加盟揽收仓操作员 | 收货订单：未收货看**预报仓库**，收货后看**收货仓库**。调拨：调出或调入命中本仓 | 后台以查看为主；收货/装车在 PDA          |
| 集货仓操作员   | 调入仓库命中本仓的调拨单及对应调拨入库单                        | 对接单按标准流程收货→绑托→上架；作业细节不在本文展开 |


调拨数据权限**沿用现网**：调出仓库 **或** 调入仓库命中即可见。不改为「只按调出」。

## 八、边界与异常处理


| 场景            | 处理方式                       |
| ------------- | -------------------------- |
| 待收货时取消与绑托同时到达 | 已到已绑托则取消失败；仍为待收货则可取消。不可都成功 |
| 已绑托后发现少货      | 不可取消、不可改预报；线下协调            |
| 未取消重复发车       | 按运单号拒绝                     |
| 调入仓入库单尚未收货    | 调拨保持已出库；全部收货完成后即已完成        |
| 并发重复发车        | 第一次成功后已出库，第二次无入口           |
