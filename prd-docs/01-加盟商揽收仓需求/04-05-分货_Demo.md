# 分货_Demo

> **文档定位**：AI 生成 PDA「分货」移动端原型的输入文档。**本文件为生成物，不是业务规则权威源。**
> **字段定义**：见《收货订单-入库单字段清单》§一头部、§二收货明细；本文件只写页面呈现规则，严禁重复定义枚举与必填性。
> **动作与状态**：见《03-02-加盟商揽收仓PDA主PRD》§5.1、§6.1；本文件只翻译为页面显隐，不新增动作。
> **版本**：V1.1 | 2026-09-01（V1.0：初版；本版：菜单改为「分货」，不沿用现网绑托页）

---

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 分货 |
| 页面目标 | 操作员逐箱扫描，在同一页面完成收货确认与分货组托，最终确认绑托 |
| 页面路径 | `/pda/inbound/sorting` |
| 菜单路径 | `PDA → 入库管理 → 分货` |
| 权限 | PDA，入库管理 → 分货；数据范围见主 PRD §七（未收货按**预报仓库**过滤） |
| 与现网关系 | **不沿用**现网 `PDA → 入库管理 → 绑托` 页面；加盟揽收仓为**独立新页面**，仅业务动作与主 PRD §5.1 对齐 |
| 设备视口 | 竖屏，基准宽度 **375px** |
| 骨架结构 | 顶栏 → 扫描区 → 运单信息区 → 扫描进度区 → 箱明细列表 → 底部固定操作栏 |

**与上架页视觉一致性**：顶栏、信息区白底、内容区浅灰底、卡片列表、底部双按钮布局与《04-06-上架_Demo》保持一致，便于 PDA 端统一体验。

## 3. 扫描区

| 元素 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 箱号扫描 | `ScanInput` | 置顶常驻；placeholder：`请扫描箱号`；支持硬件扫枪 + 软键盘；扫码后**自动触发校验**，无需点搜索 |

### 3.1 扫描校验（呈现层，规则来自主 PRD §5.1.3、§6.1）

| 校验项 | 失败反馈 |
| :--- | :--- |
| 箱号/运单不存在 | Toast：`箱号不存在` |
| 收货订单**状态**≠待收货 | Toast：`当前运单不可分货` |
| 箱号无预报（S08） | Toast：`无预报箱号，不可分货` |
| 箱号已绑托 | Toast：`该箱已绑托，不可重复扫描` |
| 件数与**预报箱数**不一致（绑托提交时） | 弹窗提示走上游取消重发；PDA 不改**预报箱数**（R08） |

扫描成功后：当前箱高亮（蓝色/高亮底），累加「当前量」。

## 4. 运单信息区（只读）

白底信息块，字段均来自字段清单，控件 **ReadonlyText**（R31：不可编辑预报类字段）。

| 行 | 展示字段 | 展示格式示例 |
| :--- | :--- | :--- |
| 第 1 行 | **运单号** | `运单号：DSL26010128343` |
| 第 2 行 | **预报箱数**、扫描进度 | `预报：350箱`　`已扫：12箱`（已扫=当前会话累计，绑托前未回写**收货箱数**） |
| 第 3 行 | **状态** | `状态：待收货`（状态 Tag，蓝色） |

**不展示**：**预报重量**、**预报体积**、**收货重量**、**收货体积**（加盟路径绑托阶段不回写重量/体积，R05）。

## 5. 扫描进度区（只读）

| 元素 | 说明 |
| :--- | :--- |
| 当前托分配 | 展示当前操作分配的**托号**（分货/绑托中由系统生成/预分配；确认绑托后回写至明细） |
| 当前量 / 剩余量 | `当前量：12箱`　`剩余量：338箱`（剩余量 = **预报箱数** − 当前量；绑托提交前为页面计算展示） |

点击「当前量」数字可进入**箱明细列表**（本页内展开或下半屏列表，只读）。

---

## 6. 箱明细列表

卡片列表，每卡一行，字段来自收货明细 §二：

| 展示内容 | 对应字段 | 控件 | 说明 |
| :--- | :--- | :--- | :--- |
| 箱号 | **箱号** | ReadonlyText | 主展示；当前扫描箱高亮 |
| 托号 | **托号** | ReadonlyText | 确认绑托前可为空或显示预分配托号 |

**不展示**：**预报重量**、**预报尺寸**、**预报体积**（本页聚焦扫箱分货，明细轻量展示）。

**交互（呈现层）**：

- 长按当前箱号：从「当前量」中剔除该箱（仅待收货态）
- 列表支持纵向滚动

## 7. 底部固定操作栏

`FixedBottomBar`，按钮高度 ≥ 44px。**不渲染 disabled 按钮**。

来自 §5.1.4 动作能力矩阵（**状态=待收货**）：

| 按钮 | 样式 | 展示条件 | 对应动作 | 行为 |
| :--- | :--- | :--- | :--- | :--- |
| 重置 | 白底蓝边 + 蓝字（次按钮） | 待收货且已有扫描数据 | —（呈现层操作） | 清空当前页扫描缓存与箱列表高亮；**不修改服务端状态** |
| 确认绑托 | 实心蓝底 + 白字（主按钮） | 待收货且至少扫入 1 箱 | **确认绑托** | 触发 §5.1.3；成功后 Toast「绑托成功」；收货订单→**已绑托**；同事务生成上架单 |

> 页面菜单名为「分货」，底部主按钮文案沿用主 PRD 动作名「确认绑托」（§5.1.4），不改为「确认分货」。

**不展示**（矩阵 ❌）：查看待上架单、执行上架、修改预报、取消。

**状态≠待收货**时：底部操作栏**整体不展示**（只读查看场景，若从详情进入）。

## 8. 二次确认与阻断弹窗

| 触发 | 弹窗标题 | 内容 | 确认按钮 | 取消按钮 |
| :--- | :--- | :--- | :--- | :--- |
| 剩余量 ≤ 5 箱提交绑托 | 提示 | `剩余5箱及以下，请检查` | 确认绑托 | 取消 |
| 件数差异 | 提示 | `实收与预报不一致，请协调上游取消后重发` | 知道了 | — |
| 确认绑托成功 | — | Toast：`绑托成功` | — | — |

## 9. 空状态、加载状态、错误状态

| 状态 | 触发条件 | 展示 |
| :--- | :--- | :--- |
| **空状态** | 进入页面尚未扫描 | 扫描区下方插画 + 文案：`请扫描箱号开始分货` |
| **加载** | 扫码后拉取运单/箱预报 | 运单信息区骨架屏或全页 Loading |
| **错误** | 校验失败 | Toast 或行内红字；不新增主 PRD 未定义 error code |
