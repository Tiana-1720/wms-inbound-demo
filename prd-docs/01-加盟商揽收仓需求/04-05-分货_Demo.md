# 分货_Demo

> **文档定位**：AI 生成 PDA「分货」移动端原型的输入文档。**本文件为生成物，不是业务规则权威源。**
> **字段定义**：见《收货订单-入库单字段清单》§一头部、§二收货明细；本文件只写页面呈现规则，严禁重复定义枚举与必填性。
> **动作与状态**：见《03-02-加盟商揽收仓PDA主PRD》§5.1、§6.1、**§十二**；本文件只翻译为页面显隐，不新增动作。
> **版本**：V1.4 | 2026-09-01（本版：进入弹窗选托数、格内「托满」、去除底部确认绑托）

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 分货 |
| 页面目标 | 操作员逐箱扫描，在同一页面完成收货确认与分货组托，最终确认绑托 |
| 页面路径 | `/pda/inbound/sorting` |
| 菜单路径 | `PDA → 入库管理 → 分货` |
| 权限 | PDA，入库管理 → 分货；数据范围见主 PRD §7.1（未收货按**预报仓库**过滤） |

| 骨架结构 | 顶栏 → **作业托数弹窗** → 扫描区 → 运单信息区 → 作业格列表（N 格，格内「托满」） |

## 3. 进入弹窗（作业托数）

进入分货页时**先展示弹窗**，用户确认后进入作业主界面：

| 元素 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 弹窗标题 | Modal | `选择作业托数` |
| 作业托数 N | `InputNumber` | 默认 **1**，范围 **1–10**；**N=1** 单托单分，**N>1** 多托同分（R41） |
| 开始作业 | 主按钮 | 确认后关闭弹窗，展示分货主界面；预生成 N 个作业格 |
| 说明文案 | ReadonlyText | N=1：`单托单分，小票可混托`；N>1：`多托同分 · N 格，新运单各占一格` |

**交互**：

- 弹窗**不可关闭跳过**（无取消、不可点遮罩关闭）
- N 写入 `sessionStorage`，退出应用前保持（R41）
- 主界面顶栏下只读展示 `作业托数 N`（不可在作业中修改）

## 4. 扫描区

| 元素 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 箱号扫描 | `ScanInput` | 置顶常驻；placeholder：`请扫描箱号`；支持硬件扫枪 + 软键盘；扫码后**自动触发校验**，无需点搜索 |

### 4.1 扫描校验（呈现层，规则来自主 PRD §5.1.3、§6.1、§12.2–§12.3）

| 校验项 | 失败反馈 |
| :--- | :--- |
| 箱号/运单不存在 | Toast：`箱号不存在` |
| 收货订单**状态**≠待收货 | Toast：`当前运单不可分货` |
| 箱号无预报（S08） | Toast：`无预报箱号，不可分货` |
| 箱号已绑托 | Toast：`该箱已绑托，不可重复扫描` |
| 大票扫入含其他运单的格 | Toast：`大票不可混托` |
| 小票须落原格却扫入他格 | Toast：`小票须在同一托` |
| N 格占满且须绑托释放 | Toast：`请先确认绑托释放作业格` |
| 件数与**预报箱数**不一致（绑托提交时） | 弹窗提示走上游取消重发；PDA 不改**预报箱数**（R08） |

扫描成功后：当前箱高亮（蓝色/高亮底），累加对应作业格的「已扫箱数」。

## 5. 运单信息区（只读）

白底信息块，展示**当前扫描运单**（最近一次成功扫码所属运单），字段均来自字段清单，控件 **ReadonlyText**（R31）。

| 行 | 展示字段 | 展示格式示例 |
| :--- | :--- | :--- |
| 第 1 行 | **运单号** | `运单号：DSL26010128343` |
| 第 2 行 | **预报箱数**、扫描进度 | `预报：350箱`　`已扫：12箱`（已扫=该运单当前会话累计，绑托前未回写**收货箱数**） |
| 第 3 行 | **状态**、大小票 Tag | `状态：待收货`；预报箱数 ≤ N 为**小票**，> N 为**大票**（N 为库内配置，Demo 占位 15） |

**不展示**：**预报重量**、**预报体积**、**收货重量**、**收货体积**（加盟路径绑托阶段不回写重量/体积，R05）。

## 6. 作业格列表（只读 + 选中）

展示 **N** 个作业格卡片（N=作业托数），每格对应一个预分配**托号**：

| 元素 | 说明 |
| :--- | :--- |
| 格序号 | `作业格 1` … `作业格 N` |
| 托号 | 系统预分配，如 `PL25010100001` |
| 已扫箱数 | 当前格累计箱数 |
| 运单摘要 | 本格涉及的运单号列表（小票混托时多票） |
| 选中态 | 点击格切换当前操作格；扫码落入规则由 §12.3 决定，不一定等于选中格 |

箱明细嵌套在格卡片内或格下方同屏展示（纵向滚动）。

---

## 7. 箱明细列表

卡片列表，每卡一行，字段来自收货明细 §二：

| 展示内容 | 对应字段 | 控件 | 说明 |
| :--- | :--- | :--- | :--- |
| 箱号 | **箱号** | ReadonlyText | 主展示；当前扫描箱高亮 |
| 运单号 | **运单号** | ReadonlyText | 混托格展示所属运单 |
| 托号 | **托号** | ReadonlyText | 确认绑托前显示预分配托号 |

**不展示**：**预报重量**、**预报尺寸**、**预报体积**。

**交互**：

- 列表支持纵向滚动
- **不提供**长按剔除、过机顺序带出、暂存等现网绑托页能力（主 PRD §12.5）

| 选中态 | 点击格切换当前操作格（高亮边框） |
| 托满 | 每格底部主按钮；至少扫入 1 箱时展示；触发**确认绑托**（R40） |

## 10. 空状态、加载状态、错误状态

| 状态 | 触发条件 | 展示 |
| :--- | :--- | :--- |
| **空状态** | 进入页面尚未扫描 | 扫描区下方插画 + 文案：`请扫描箱号开始分货` |
| **加载** | 扫码后拉取运单/箱预报 | 运单信息区骨架屏或全页 Loading |
| **错误** | 校验失败 | Toast 或行内红字；不新增主 PRD 未定义 error code |
