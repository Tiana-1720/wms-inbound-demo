## 零、下推时机（按调拨类型）

| 调拨类型 | 出库单生成时机 | 说明 |
| :--- | :--- | :--- |
| **计划调拨** | 创建调拨计划时或全部运单在调出仓收货后 | 与调入仓入库单**同批**生成；**出库类型=调拨出库**；沿用现网 |
| **空单调拨** | **建计划时同步生成**（**待出库**、明细空，1 计划 : 1 出库单） | **出库类型=调拨出库**；加盟路径增量见主 PRD §5.3 |
| **计划出库** | 上游下发出库计划后同步生成 | **出库类型=计划出库**；沿用现网 |

## 一、头部字段

| 字段名称 | 类型 | 来源 | 列表展示 | 可筛选 | 备注 |
| :--- | :--- | :--- | :---: | :---: | :--- |
| 出库单号 | 文本 | 系统生成 | 否 | 否 | 单据主键；路由参数 |
| 计划单号 | 文本 | 系统带出 | **是** | **是** | 展示格式：`计划单号(业务归属)`，如 `LT260871425(SD)` |
| 调拨计划单号 | 引用 | 系统带出 | 否 | 是（同计划单号） | 调拨类出库关联；可链调拨详情 |
| 业务归属 | 枚举 | 上游系统 | 否 | 否 | 拼接到计划单号后，如 SD、DS |
| 归属仓库 | 引用 | 系统带出 | 否 | 否 | 继承调拨计划单调出仓库 |
| 备注 | 文本 | 上游/用户 | **是** | 否 | |
| 计划件数 | 数字 | 系统计算 | **是** | 否 | 计划总件数（总箱数） |
| 计划订单数 | 数字 | 系统计算 | **是** | 否 | 计划总订单数 |
| 在库比例 | 数字 | 系统计算 | **是** | 否 | 在库件数/计划件数 × 100% |
| 计划装柜时间 | 日期 | 上游系统 | **是** | 否 | 多仓取最早参与排序 |
| 是否锁单 | 枚举 | 系统生成 | **是** | 否 | `是` / `否`；PDA **装车锁定**或 PC **手动锁单**后为 **是** |
| 出库类型 | 枚举 | 系统生成 | **是** | **是** | `计划出库`、`调拨出库` |
| 调拨类型 | 枚举 | 系统生成 | 否 | 否 | `计划调拨`、`空单调拨`；决定「更多」增量动作 |
| 司机 | 文本 | 用户填写 | 否 | 否 | PDA 装车锁定回写 |
| 车牌号 | 文本 | 用户填写 | 否 | 否 | 同上 |
| 电话 | 文本 | 用户填写 | 否 | 否 | 同上 |
| 状态 | 枚举 | 系统生成 | **是**（Tab） | Tab | 现网：**待出库 / 已下架 / 已复核 / 已出库 / 已取消** |

## 四、字段说明

| 字段 | 作用 |
| :--- | :--- |
| **计划单号** | 列表主展示列；计划出库为上游出库计划单号，调拨出库为调拨计划单号 + 业务归属 |
| **在库比例** | 列表 Progress 展示；在库件数/计划件数 |
| **出库类型** | 区分计划出库与调拨出库；调拨出库列表展示 **调** Tag |
| **调拨类型** | 计划调拨走现网下架；空单调拨走加盟关联运单/确认出库 |
