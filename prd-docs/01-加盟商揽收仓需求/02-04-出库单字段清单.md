# 出库单字段清单

> **当前版本**：粗纲版。仅用于主 PRD 编写前统一字段命名，后续会基于主 PRD 规则补全完整维度。  
> **规则来源**：`03-01-加盟商揽收仓管理后台主PRD.md` V1.8；现网 `WMS_V1.0 260314` 出库单（调拨出库）
> **引用规则**：继承调拨计划单字段标注来源单据，不重复写字段定义
> **对齐说明**：下推时机按 **`调拨类型`** 分支——**计划调拨**沿用现网；**空单调拨**：PDA 装车→出库单**已复核**，PC 确认出库→**已出库**

## 零、下推时机（按调拨类型）

| 调拨类型 | 出库单生成时机 | 说明 |
| :--- | :--- | :--- |
| **计划调拨** | 创建调拨计划时（全部运单已收货）或全部运单在调出仓收货后 | 与调入仓入库单**同批**生成；计划变更同步下游；沿用现网 |
| **空单调拨** | **PDA 装车**时生成/追加；**PC 确认出库**时→**已出库** | 建计划**不**预生成；明细来自 PDA 实装回写；**不生**调入仓调拨入库单 |

## 四、字段说明

| 字段 | 作用 |
| :--- | :--- |
| **归属仓库** | 货物所属揽收仓（调拨计划单调出仓库）；不含调入仓库 |
| **司机 / 车牌号 / 电话** | PDA 装车时填写；装车时回写 |
| **备注** | 出库单级补充说明 |
| **运单号** | 明细行主关联键；一个出库单可含多运单 |
| **客户代码** | 运单所属客户 |
| **箱数 / 重量 / 体积** | 运单级实装量；继承调拨计划单明细 |

> **暂不含**：调入仓库、装车人、装车开始时间、发运时间、实装总箱数/重量/体积、集货仓预报推送状态（本期去掉）。  
> **明细不含**：参考号、托号、箱号、库位（装车执行层不在本明细维护）。
