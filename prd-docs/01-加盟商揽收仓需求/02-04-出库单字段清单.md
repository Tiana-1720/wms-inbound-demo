## 零、下推时机（按调拨类型）

| 调拨类型 | 出库单生成时机 | 说明 |
| :--- | :--- | :--- |
| **计划调拨** | 创建调拨计划时或全部运单在调出仓收货后 | 与调入仓入库单**同批**生成；**出库类型=调拨出库**；沿用现网 |
| **空单调拨** | **建计划时同步生成**（**待出库**、明细空，1 计划 : 1 出库单） | **出库类型=调拨出库**；加盟路径增量见主 PRD §5.3 |
| **计划出库** | 上游下发出库计划后同步生成 | **出库类型=计划出库**；沿用现网 |

## 二、明细字段（行级）

> 每行代表**一个实装运单**（整票关联，不允许拆票装车，R20）。空单调拨建计划时明细为空；由 PDA **装车暂存/锁定**或 PC **关联运单**回写，与调拨计划单明细**同源同步**（主 PRD §5.3、R50）。
> **不收录**（装车执行层不在本明细维护）：参考号、托号、箱号、库位、装柜顺序、出库渠道、品名、客户备注、内部备注、目的仓库、目的邮编、预计到仓时间等现网扩展列——**本期加盟路径 Demo 不展示**；若计划出库沿用现网详情，以现网字段为准。
> **列表展示**：明细字段**出库列表主表不展示**；在出库详情/关联运单明细表展示。**运单号**可在列表查询区筛选。

| 字段名称 | 字段来源 | 取值说明 | 必填性 | 新增页 | 详情页 | 列表展示 | 可筛选 | 详情展示 | 字段说明 | 备注 |

## 四、字段说明

| 字段 | 作用 |
| :--- | :--- |
| **计划单号** | 列表主展示列；计划出库为上游出库计划单号，调拨出库为调拨计划单号 + 业务归属 |
| **在库比例** | 列表 Progress 展示；在库件数/计划件数 |
| **出库类型** | 区分计划出库与调拨出库；调拨出库列表展示 **调** Tag |
| **调拨类型** | 计划调拨走现网下架；空单调拨走加盟关联运单/确认出库 |
| **柜号** | 出库作业页头部字段；列表页不展示；关联运单页 §2.3 只读对齐现网 |
| **司机电话** | 与调拨计划单 §5.6、PDA 装车锁定回写口径一致；UI 可展示为「电话」 |

## 五、快照字段说明

| 类型 | 字段 | 说明 |
| :--- | :--- | :--- |
| **快照（系统带出并存储）** | 明细.**客户代码** | 关联运单/装车扫描时从收货订单或库位库存带出 |
| **下游回写** | 明细.**运单号**、**箱数**、**重量**、**体积**；头部 **司机**、**司机电话**、**车牌号** | PDA 装车暂存/锁定或 PC 关联运单写入；装车锁定同时回写头部司机信息 |
| **用户填写** | **柜号** | 现网出库作业维护；关联运单页只读展示 |
| **系统生成** | **出库单号**、**状态**、**是否锁单**、系统字段 | 建计划或上游下推时生成；状态由动作推进（主 PRD §5.3） |
| **系统计算** | **计划件数**、**计划订单数**、**在库比例** | 列表展示；沿用现网 |
