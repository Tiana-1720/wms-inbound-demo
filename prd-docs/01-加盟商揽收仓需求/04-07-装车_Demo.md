# 装车_Demo

> **文档定位**：AI 生成 PDA「空单调拨装车」移动端原型的输入文档。**本文件为生成物，不是业务规则权威源。**
> **字段定义**：见《调拨计划单字段清单》；本文件只写页面呈现规则。
> **动作与状态**：见《03-02-加盟商揽收仓PDA主PRD》§5.2、§6.4、**§十三**；本文件只翻译为页面显隐。
> **视觉一致性**：布局骨架与《04-06-上架_Demo》子页 B 对齐（头信息白底 + 卡片列表灰底 + 底部主按钮）。
> **版本**：V1.3 | 2026-09-03（V1.3：已扫票/托展示；会话保持；新扫置顶；去掉状态 Tag 与底部汇总）

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 装车 |
| 页面目标 | 操作员扫描已上架货物关联调拨计划单，维护司机/车牌后装车 |
| 页面路径 | `/pda/transfer/load/{调拨计划单号}` |
| 菜单路径 | `PDA → 出库管理 → 装车` |
| 权限 | PDA，出库管理 → 装车；数据范围见主 PRD §7.1（**调出仓库**或**调入仓库**命中本仓可见） |
| 适用范围 | 仅 **空单调拨**（调出仓库类型=加盟揽收仓）；**计划调拨**不展开（走现网复核/装柜，R19） |
| 设备视口 | 竖屏，基准宽度 **375px** |
| 骨架结构 | 顶栏 → 调拨头信息区（含已扫票/托）→ 扫描区 → 已扫明细卡片列表 → 底部固定操作栏 |

**页面流**：

```
装车计划列表（待出库空单） → 点击进入本页 → 扫描装车 → 维护司机/车牌/电话 → 装车
```

> 装车计划列表 Demo 本期简化为：展示出库单**未出库**且**调出仓库**命中本仓的空单调拨卡片（含 `待出库`、`已复核` 可追加；字段见 §2.2）；不单独产出列表文件。

### 1.1 空单调拨·出库下推规则（标准需求）

| 阶段 | 系统行为 |
| :--- | :--- |
| OMS 建计划 | 仅生成调拨计划单（待出库、明细空）；**不下推**、**不预生成**待出库出库单 |
| PDA 装车 | 生成/追加调出仓出库单→**已复核**；**调拨计划→已复核**；回写实装明细；**占用**库位库存（可多次追加） |
| PC 确认出库 | 出库单→**已出库**；库位库存**实扣** |
| 调入仓入库 | **不生调拨入库单**；东莞**常规入库**由加盟商发车时**现网自动推送** |

> 原型 Mock 与标准需求一致：装车确认后**调拨计划与出库单均为已复核**，回写明细并占用库存；刷新页面后 Mock 数据重置。

## 3. 扫描区

| 元素 | 控件 | 规格 |
| :--- | :--- | :--- |
| 箱号扫描 | `ScanInput` | placeholder：`请扫描箱号装车`；扫码自动校验 |

### 3.1 扫描规则呈现（主 PRD §5.2.3、§6.4）

| 规则 | 失败反馈 |
| :--- | :--- |
| 货物须在库位库存且已上架（R20、S10） | Toast：`货物未上架或不在库` |
| 每扫 1 次校验**当前托下全部箱**可用库存；任一箱被占用 | Toast：`箱号{箱号}已被{占用方}占用` |
| 扫箱号带出对应托、关联整托（Q12）；小票混托一扫带出托上全部运单 | 扫描成功后整托运单入明细；**新扫描插入列表顶部** |
| 进入作业页 | **带出该计划单号未提交的已扫票/托**（退出再进入仍保持） |
| 不允许拆票（Q15） | 装车时拦截，见 §6 |
| 运单多托未扫齐扫下一票（R31） | Toast：`请先扫齐当前运单全部托` |
| 重复扫描同一托 | Toast：`该运单已关联`（幂等，§8.2） |
| 出库单已出库（调拨已出库） | 整页只读，无扫描区 |

扫描成功：在已扫明细区**顶部**新增/更新运单卡片（后扫的托排在最前；混托多票连续一组置顶）。

**已扫计数**：头信息与列表卡片展示 `已扫：N票 / M托`——**票数**=明细运单条数，**托数**=去重托号。

## 6. 底部固定操作栏

来自 §5.2.4 动作能力矩阵。

| 按钮 | 样式 | 展示条件 | 对应动作 | 行为 |
| :--- | :--- | :--- | :--- | :--- |
| 装车 | 实心蓝底（主按钮） | 待出库且已有扫描明细 | **装车** | 打开司机信息弹窗；填写后点「确认装车」触发 §5.2.3 装车 |

### 6.1 司机信息弹窗（装车确认）

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `司机信息` |
| 字段 | 司机、电话、车牌号（均必填，单行输入） |
| 确认按钮 | `确认装车` |
| 取消按钮 | `取消` |

- 点底部「装车」打开**司机信息弹窗**；输入司机、电话、车牌；校验通过后点「确认装车」提交。
- 未填齐：Toast `请填写司机、电话和车牌号`；弹窗不关闭。
- 装车成功：Toast `装车成功，已占用库存`；返回装车计划列表。

## 7. 空状态、加载状态、错误状态

| 状态 | 触发条件 | 展示 |
| :--- | :--- | :--- |
| **空状态** | 待出库空单进入，尚未扫描 | 列表区：`请扫描箱号开始装车` |
| **会话恢复** | 曾扫描未提交装车，再次进入本页或列表 | 头信息/列表 `已扫` 与明细卡片与上次一致 |
| **加载** | 进入页面拉取调拨计划 | 头信息骨架屏 |
| **错误** | 未上架/无库存/托占用/多托未扫齐 | Toast（见 §3.1） |
| **只读** | 调拨已出库或出库单已出库 | 头信息 + 已扫明细只读；无扫描区、无底部栏 |
| **可追加装车** | 调拨=已复核、出库单=已复核 | 可再次进入装车页追加运单 |

## 8. Mock 数据规格

### 待出库空单（可装车）

| 字段 | 值 |
| :--- | :--- |
| 调拨计划单号 | AT26010100001 |
| 调出仓库 | NC-LS-01（加盟揽收仓） |
| 调入仓库 | DS-JH-01 |
| 状态 | 待出库 |
| 明细 | 空（扫描后回写） |

### 可扫描箱号（`pda-transfer-load.ts`）

箱号格式：`FBA1988W5Y0GU` + 6 位流水。扫箱**带出整托**；小票混托时一扫关联托上全部运单。

| 托号 | 运单号 | 可扫箱号 | 结果 |
| :--- | :--- | :--- | :--- |
| PL25010100001 | DSL26010128343 | `FBA1988W5Y0GU000001` | ✅ +1 票 / +1 托 |
| PL25010100002 | DSL26010128344 | `FBA1988W5Y0GU000401` | ✅ +1 票 / +1 托 |
| PL25010100020 | 28302+28303+28304 | `000381` / `000389` / `000394` | ✅ 小票混托：+3 票 / +1 托 |
| PL25010100021 | DSL26010128399 | `000701` | ❌ 托上 `000702` 已被 `AT26010100999` 占用 |
| PL25010100004 | DSL26010128346 | `FBA1988W5Y0GU000601` | ❌ 未上架或不在库 |

### 已扫明细示例

| 运单号 | 客户代码 | 箱数 | 重量 | 体积 |
| :--- | :--- | :--- | :--- | :--- |
| DSL26010128343 | CUST001 | 30 | 125.50 | 1.250000 |
| DSL26010128344 | CUST002 | 30 | 118.00 | 1.100000 |

### 已出库（只读演示）

| 调拨计划单号 | 状态 |
| :--- | :--- |
| AT26010100002 | 已出库 |

> **说明**：装车列表展示出库单**未出库**的空单调拨。PDA 装车后**调拨计划与出库单均为已复核**，列表仍可进入**追加装车**（至 PC 确认出库）。

> **原型交互**：未提交装车前，扫描会话按调拨计划单号保持（原型 `sessionStorage`）；**新扫描置顶**。装车「确认」成功后**调拨计划与出库单均为已复核**，明细落计划单并占用库存；清空会话后可继续**追加装车**（至 PC 确认出库）。刷新页面后 Mock 重置。
