# 装车_Demo

> **文档定位**：AI 生成 PDA「空单调拨装车」移动端原型的输入文档。**本文件为生成物，不是业务规则权威源。**
> **字段定义**：见《调拨计划单字段清单》；本文件只写页面呈现规则。
> **动作与状态**：见《03-02-加盟商揽收仓PDA主PRD》§5.2、§6.4、**§十三**；本文件只翻译为页面显隐。
> **视觉一致性**：布局骨架与《04-06-上架_Demo》子页 B 对齐（头信息白底 + 卡片列表灰底 + 底部主按钮）。
> **版本**：V1.2 | 2026-09-02（V1.2：装车替代发车；出库单已复核；PC 确认出库扣库存）

---

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 装车 |
| 页面目标 | 操作员扫描已上架货物关联调拨计划单，维护司机/车牌后装车 |
| 页面路径 | `/pda/transfer/load/{调拨计划单号}` |
| 菜单路径 | `PDA → 出库管理 → 装车` |
| 权限 | PDA，出库管理 → 装车；数据范围见主 PRD §7.1（**调出仓库**或**调入仓库**命中本仓可见） |
| 适用范围 | 仅 **空单调拨**（调出仓库类型=加盟揽收仓）；**计划调拨**不展开（走现网复核/装柜，R19） |
| 设备视口 | 竖屏，基准宽度 **375px** |
| 骨架结构 | 顶栏 → 调拨头信息区 → 司机信息区 → 扫描区 → 已扫明细卡片列表 → 汇总区 → 底部固定操作栏 |

**页面流**：

```
装车计划列表（待出库空单） → 点击进入本页 → 扫描装车 → 维护司机/车牌/电话 → 装车
```

> 装车计划列表 Demo 本期简化为：仅展示**状态**=待出库且**调出仓库**命中本仓的空单调拨卡片（字段见 §2.2）；不单独产出列表文件。

## 3. 扫描区

| 元素 | 控件 | 规格 |
| :--- | :--- | :--- |
| 箱号扫描 | `ScanInput` | placeholder：`请扫描箱号装车`；扫码自动校验 |

### 3.1 扫描规则呈现（主 PRD §5.2.3、§6.4）

| 规则 | 失败反馈 |
| :--- | :--- |
| 货物须在库位库存且已上架、**未被占用**（R20、S10） | Toast：`货物未上架或不在库` |
| 货物已被其他调拨占用 | Toast：`该货物已被占用` |
| 扫箱号带出对应托、关联整托（Q12） | 扫描成功后整托运单入明细 |
| 目的仓须与**调入仓库**一致（Q14） | Toast：`目的仓与调入仓库不一致` |
| 不允许拆票（Q15） | 装车时拦截，见 §6 |
| 重复扫描同一运单 | Toast：`该运单已关联`（幂等，§8.2） |
| 出库单已出库（调拨已出库） | 整页只读，无扫描区 |

扫描成功：在已扫明细区新增/更新一条运单卡片。

## 4. 已扫明细卡片列表（灰底可滚动）

每扫入一票（整票）一张白卡片，字段来自调拨计划单 §二明细：

| 卡片区域 | 字段 | 展示格式 |
| :--- | :--- | :--- |
| 主行 | **运单号** | `运单号 DSL26010128343`（加粗） |
| 副行 1 | **客户代码** | `客户：CUST001` |
| 副行 2 | **箱数**、**重量**、**体积** | `30箱`　`125.50KG`　`1.250000CBM` |

**不展示**：托号、箱号（字段清单 §二：明细不含托号/箱号）。

卡片支持左滑删除（仅**待出库**且出库单未确认出库，删除后从本次实装清单移除整票运单行；对应主 PRD §5.2.3 **删除扫描**；**不拆票**——删票不删部分箱）。

## 6. 底部固定操作栏

来自 §5.2.4 动作能力矩阵。

| 按钮 | 样式 | 展示条件 | 对应动作 | 行为 |
| :--- | :--- | :--- | :--- | :--- |
| 重置 | 白底蓝边（次按钮） | 待出库且已有扫描明细（未提交装车） | —（呈现层） | 清空本次未提交的扫描缓存 |
| 装车 | 实心蓝底（主按钮） | 待出库且**汇总箱数** ≥ 1；司机/车牌/电话已填 | **装车** | 二次确认后触发 §5.2.3 装车 |

**不展示**：取消、修改调出/调入仓库、打印装车清单（Q17）。

**调拨计划已出库 / 已完成 / 已取消**：底部栏**不展示**；整页只读（R32）。

### 6.1 装车二次确认弹窗

| 标题 | 内容 | 确认按钮 | 取消按钮 |
| :--- | :--- | :--- | :--- |
| 确认装车 | `确认装车？将生成/更新出库单（已复核），并占用库位库存；待 PC 确认出库后实扣` | 确认装车 | 取消 |

### 6.2 拆票拦截（装车时）

| 场景 | 反馈 |
| :--- | :--- |
| 一票多箱仅部分关联 | Toast：`须整票装车，不可拆票装车` |

## 7. 空状态、加载状态、错误状态

| 状态 | 触发条件 | 展示 |
| :--- | :--- | :--- |
| **空状态** | 待出库空单进入，尚未扫描 | 列表区：`请扫描箱号开始装车` |
| **加载** | 进入页面拉取调拨计划 | 头信息骨架屏 |
| **错误** | 未上架/无库存/错装 | Toast（见 §3.1） |
| **只读** | 调拨已出库或出库单已出库 | 头信息 + 已扫明细只读；无扫描区、无底部栏 |
| **可追加装车** | 调拨=已复核、出库单=已复核 | 可再次进入装车页追加运单 |
