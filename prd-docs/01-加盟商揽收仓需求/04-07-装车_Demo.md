# 装车_Demo

> **文档定位**：AI 生成 PDA「空单调拨装车」移动端原型的输入文档。**本文件为生成物，不是业务规则权威源。**
> **字段定义**：见《调拨计划单字段清单》；本文件只写页面呈现规则。
> **动作与状态**：见《03-02-加盟商揽收仓PDA主PRD》§5.2、§6.4、**§十三**；本文件只翻译为页面显隐。
> **视觉一致性**：布局骨架与《04-06-上架_Demo》子页 B 对齐（头信息白底 + 卡片列表灰底 + 底部主按钮）。
> **版本**：V1.5 | 2026-09-07（列表筛选未锁单出库单；明细扫描进度；PDA 不展示客户代码；底部按钮样式）

## 1. 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 装车 |
| 页面目标 | 操作员扫描已上架货物关联调拨计划单，通过**装车暂存**保存进度或**装车锁定**确认装车 |
| 页面路径 | `/pda/transfer/load/{调拨计划单号}` |
| 菜单路径 | `PDA → 出库管理 → 装车` |
| 权限 | PDA，出库管理 → 装车；数据范围见主 PRD §7.1（**调出仓库**或**调入仓库**命中本仓可见） |
| 适用范围 | 仅 **空单调拨**（调出仓库类型=加盟揽收仓）；**计划调拨**不展开（走现网复核/装柜，R19） |
| 设备视口 | 竖屏，基准宽度 **375px** |
| 骨架结构 | 顶栏 → 调拨头信息区（含已扫票/托）→ 扫描区 → 已扫明细卡片列表 → 底部固定操作栏 |

**页面流**：

```
装车计划列表（待出库空单） → 点击进入本页 → 扫描装车 → **装车暂存**（保存进度）或 **装车锁定**（司机弹窗确认）
```

> 装车计划列表 Demo 本期简化为：查询关联出库单**状态=待出库或已复核**且**是否锁单=否**的空单调拨（调出仓命中本仓）；**已出库**或**已锁单**不展示；不单独产出列表文件。

### 1.1 空单调拨·出库下推规则（标准需求）

| 阶段 | 系统行为 |
| :--- | :--- |
| OMS 建计划 | 生成调拨计划单（待出库、明细空）+ **同时生成**调出仓出库单（**待出库**、明细空）；**1 计划 : 1 出库单** |
| PDA 装车暂存 | 将已扫运单关联至**空出库单**并回写调拨明细；**不锁单据**；出库单**仍为待出库**；提交前校验**可用库存**；保存后**箱库存→已占用** |
| PDA 装车锁定 | 更新运单/调拨明细；**出库单→已复核**；**调拨计划→已复核**；**是否锁单=是**；**箱库存→已占用**；锁定后须 PC 解锁续装 |
| PC 关联运单 | 仅建运单与出库单关联，**不变更单据状态**；校验可用库存；**箱库存→已占用**；须再**手动锁单** |
| PC 打印装柜单 | 沿用现网模板；仅打印，不变库存 |
| PC 确认出库 | 出库单→**已出库**；库位库存**实扣** |
| 调入仓入库 | **不生调拨入库单**；东莞**常规入库**由加盟商发车时**现网自动推送** |

> 原型 Mock 与标准需求一致：**装车锁定**确认后**调拨计划与出库单均为已复核**；**装车暂存**将运单关联至空出库单、出库单仍为**待出库**；刷新页面后 Mock 数据重置。

## 3. 扫描区

| 元素 | 控件 | 规格 |
| :--- | :--- | :--- |
| 箱号扫描 | `ScanInput` | placeholder：`请扫描箱号装车`；扫码自动校验 |

### 3.1 扫描规则呈现（主 PRD §5.2.3、§6.4）

| 规则 | 失败反馈 |
| :--- | :--- |
| 货物须在库位库存且已上架（R20、S10） | Toast：`货物未上架或不在库` |
| 每扫 1 次校验**当前托下全部箱**可用库存；任一箱被占用 | Toast：`箱号{箱号}已被{占用方}占用` |
| 扫箱号带出对应托、关联整托（Q12）；小票混托一扫带出托上全部运单 | 扫描成功后整托运单入明细；**新扫描插入列表顶部** |
| 进入作业页 | **带出该计划单号未提交的已扫票/托**（退出再进入仍保持） |
| 不允许拆票（Q15） | 装车时拦截，见 §6 |
| 运单多托未扫齐扫下一票（R31） | Toast：`请先扫齐当前运单全部托` |
| 重复扫描同一托 | Toast：`该运单已关联`（幂等，§8.2） |
| 出库单已出库（调拨已出库） | 整页只读，无扫描区 |

扫描成功：在已扫明细区**顶部**新增/更新运单卡片（后扫的托排在最前；混托多票连续一组置顶）。

**已扫计数**：头信息与列表卡片展示 `已扫：N票 / M托`——**票数**=明细运单条数，**托数**=去重托号。

| 卡片区域 | 字段 | 展示格式 |
| :--- | :--- | :--- |
| 主行左 | **运单号** | `运单号 DSL26010128343`（加粗） |
| 主行右 | **扫描进度** | `10/20箱`（**已扫本托箱数累加 / 运单总箱数**；扫 1 次带出托上全部运单） |
| 副行 | **箱数**、**重量**、**体积** | `30箱`　`125.50KG`　`1.250000CBM` |

**不展示**：**客户代码**（后台仍回写存储）、托号、箱号（字段清单 §二：明细不含托号/箱号）。

卡片提供「**移除**」按钮（待出库/已复核且出库单未出库；按**整托**移除，混托多票一并移除；对应主 PRD **删除扫描**）。

> **本期原型**：作业页**不展示** §三汇总区（`合计：N箱` 等）；进度以头信息 `已扫：票/托` 为准。

## 6. 底部固定操作栏

来自 §5.2.4 动作能力矩阵。

| 按钮 | 样式 | 展示条件 | 对应动作 | 行为 |
| :--- | :--- | :--- | :--- | :--- |
| 装车锁定 | 描边（次按钮，左） | 待出库/已复核且未锁单、已有扫描明细 | **装车锁定** | 打开司机信息弹窗；填写后点「确认装车锁定」提交（§6.1） |
| 装车暂存 | 实心蓝底（主按钮，右） | 待出库/已复核且未锁单、已有扫描明细 | **装车暂存** | 校验可用库存；保存进度；**不锁单据**；Toast `暂存成功，已占用库存` |

**不展示**：重置、取消、修改调出/调入仓库、打印装柜单（Q17：PDA **不打印**；由 PC **先打印装柜单再确认出库**）。

**调拨计划已出库 / 已完成 / 已取消**：底部栏**不展示**；整页只读（R32）。

### 6.1 司机信息弹窗（装车锁定确认）

| 元素 | 规格 |
| :--- | :--- |
| 标题 | `司机信息` |
| 字段 | 司机、电话、车牌号（均必填，单行输入） |
| 确认按钮 | `确认装车锁定` |
| 取消按钮 | `取消` |

- 点底部「装车锁定」打开**司机信息弹窗**；输入司机、电话、车牌；校验通过后点「确认装车锁定」提交。
- 未填齐：Toast `请填写司机、电话和车牌号`；弹窗不关闭。
- 装车锁定成功：Toast `装车锁定成功，已占用库存`；返回装车计划列表。

### 6.2 拆票拦截（装车时）

| 场景 | 反馈 |
| :--- | :--- |
| 一票多箱仅部分关联 | Toast：`须整票装车，不可拆票装车` |

## 7. 空状态、加载状态、错误状态

| 状态 | 触发条件 | 展示 |
| :--- | :--- | :--- |
| **空状态** | 待出库空单进入，尚未扫描 | 列表区：`请扫描箱号开始装车` |
| **会话恢复** | 曾扫描未提交装车暂存/锁定，再次进入本页或列表 | 头信息/列表 `已扫` 与明细卡片与上次一致 |
| **加载** | 进入页面拉取调拨计划 | 头信息骨架屏 |
| **错误** | 未上架/无库存/托占用/多托未扫齐 | Toast（见 §3.1） |
| **只读** | 调拨已出库、出库单已出库或**是否锁单=是** | 头信息 + 已扫明细只读；无扫描区、无底部栏 |
| **可追加装车** | 出库单**已复核**且**是否锁单=否**（如装车暂存后） | 可再次进入装车页追加运单 |

### 待出库空单（可装车）

### 可扫描箱号（`pda-transfer-load.ts`）

箱号格式：`FBA1988W5Y0GU` + 6 位流水。扫箱**带出整托**；小票混托时一扫关联托上全部运单。

| 托号 | 运单号 | 可扫箱号 | 结果 |
| :--- | :--- | :--- | :--- |
| PL25010100001 | DSL26010128343 | `FBA1988W5Y0GU000001` | ✅ +1 票 / +1 托；进度 **10/20** |
| PL25010100005 | DSL26010128343 | `FBA1988W5Y0GU000002` | ✅ 同上运单第 2 托；进度 **20/20** |
| PL25010100002 | DSL26010128344 | `FBA1988W5Y0GU000401` | ✅ +1 票 / +1 托；进度 **30/30** |
| PL25010100020 | 28302+28303+28304 | `000381` / `000389` / `000394` | ✅ 小票混托：+3 票 / +1 托；各票 **8/8、5/5、6/6** |
| PL25010100021 | DSL26010128399 | `000701` | ❌ 托上 `000702` 已被 `AT26010100999` 占用 |
| PL25010100004 | DSL26010128346 | `FBA1988W5Y0GU000601` | ❌ 未上架或不在库 |

### 已扫明细示例（PDA 展示）

| 运单号 | 扫描进度 | 箱数 | 重量 | 体积 |
| :--- | :--- | :--- | :--- | :--- |
| DSL26010128343 | 10/20箱 | 20 | 125.50 | 1.250000 |
| DSL26010128344 | 30/30箱 | 30 | 118.00 | 1.100000 |

> **客户代码**仍由系统回写至调拨/出库明细，**PDA 装车页不展示**。

### 已出库（只读演示）

| 调拨计划单号 | 状态 |
| :--- | :--- |
| AT26010100002 | 已出库 |

> **说明**：装车列表查询出库单**待出库/已复核且未锁单**的空单调拨（如 AT26010100001、AT26010100003、AT26010100004）；**装车锁定**后**是否锁单=是**，**不再出现在列表**（如 AT26010100005）；须 PC 解锁后才能续装。

> **原型交互**：未提交装车前，扫描会话按调拨计划单号保持（原型 `sessionStorage`）；**新扫描置顶**。**装车锁定**成功后出库单/调拨**已复核**且**已锁单**，明细落计划单并占用库存，清空会话。**装车暂存**不锁单，可继续追加。刷新页面后 Mock 重置。
