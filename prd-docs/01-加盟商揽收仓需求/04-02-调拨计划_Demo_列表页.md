## 1.2 状态 Tab 栏

列表页主过滤入口。Tab 集合：**待出库 / 已出库 / 已完成 / 已取消**（沿用现网三态 + **预留已取消**；**本期无取消入口**，已取消 Tab 用于筛选预留态/历史数据）。

| Tab 标签 | 过滤逻辑 |
| :--- | :--- |
| 全部 | 展示所有状态（默认选中） |
| 待出库 | 状态 = 待出库 |
| 已出库 | 状态 = 已出库 |
| 已完成 | 状态 = 已完成 |
| 已取消 | 状态 = 已取消 |

**Tab 交互规则**：

- 每个 Tab 右侧展示当前条件下的计数（格式：`Tab名 (N)`，超过 99 展示 `99+`，0 也展示）
- 切换 Tab 后列表刷新，页码重置为第 1 页，**不清空**查询区其他条件

## 1.3 查询区

### 布局说明

桌面端栅格布局（约 4 列 × 1 行）。默认展示全部筛选项，无「展开/收起」区域。

> **状态**：仅通过 §1.2 状态 Tab 过滤，**查询区不提供状态下拉**。

右侧操作组顺序：`重置` → `查询`（主按钮）

### 查询条件

> 以下字段均来自字段清单「可筛选=是」。

| 字段 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 调拨计划单号 | `Input` | 精确匹配；placeholder：`调拨计划单号` |
| 运单号 | `Input` | 精确匹配；placeholder：`运单号`；按明细运单号反查所属计划单 |
| 调出仓库 | `SelectWithSearch` | **多选**；展示格式 `仓库代码(仓库名称)` |
| 调入仓库 | `SelectWithSearch` | **多选**；规格同调出仓库 |

## 1.5 表格

### 表格行为

| 行为 | 规格 |
| :--- | :--- |
| 行勾选 | 不支持 |
| 列宽拖拽 | 支持 |
| 固定列 | **调拨计划单号**列左固定；**操作**列右固定 |
| 行展开 | **不支持**（明细不进主列表） |
| 分页 | 默认每页 **20** 条，支持切换（20 / 50 / 100） |
| 空值展示 | 无数据时展示 `-`；汇总无明细时为 `0` |

| 重量 | 汇总.汇总重量 | KG，最多 2 位小数 | 100px | |
