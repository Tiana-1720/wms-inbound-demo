## 3.2 状态区

- **当前状态 Badge**：颜色语义同列表页（待出库=蓝、已出库=橙、已完成=绿、已取消=灰）
- **状态含义文案**（只读说明，来自主 PRD §5.2）：

| 状态 | 含义 |
| :--- | :--- |
| 待出库 | 空单已建，待装车 |
| 已出库 | 已发车，已生成出库单与调入仓入库单 |
| 已完成 | 调入仓该批入库单均已收货 |
| 已取消 | 待出库空单作废 |

- **状态时间线**（按实际发生时间倒序展示，无数据项隐藏）：

| 节点 | 展示条件 | 时间字段来源 |
| :--- | :--- | :--- |
| 创建 | 始终 | 创建时间 |
| 作废 | 状态=已取消 | 最后修改时间 |
| PDA 发车 / 已出库 | 状态∈{已出库, 已完成} | 最后修改时间（发车动作时点） |
| 调入仓收货完成 | 状态=已完成 | 最后修改时间（系统回写时点） |

> 时间线节点名称与主 PRD §2 In Scope 操作日志类型对齐；具体时间点取系统字段，Demo 不新增独立业务时间字段。

只读表格；列来自字段清单明细区「详情展示=是」：

| 列名 | 内容说明 |
| :--- | :--- |
| 序号 | 从 1 起 |

## 3.7 操作按钮区（固定底部）

按状态与前置条件动态展示。**不渲染 disabled 操作**。

| 状态 | 前置条件 | 展示的操作按钮 |
| :--- | :--- | :--- |
| 待出库 | 明细无运单 | 返回列表 / **作废** |
| 待出库 | 明细已有运单 | 返回列表 |
| 已出库 | — | 返回列表 |
| 已完成 | — | 返回列表 |
| 已取消 | — | 返回列表 |

**按钮说明**：

- **返回列表**：跳转 `/order/TransferPlan`，保持进入详情前的 Tab 与查询条件（若前端可还原）
- **作废**：二次确认（文案同列表页）；成功后状态 → 已取消；Toast「作废成功」；刷新详情或回列表

> **不在详情提供的动作**：新增（列表/新增页）、PDA 发车、调入仓收货完成（系统）、编辑备注（备注字段未收录，字段清单 §5.6）

**权限**：作废仅总部作业部；待出库且无明细（主 PRD §七 / §5.2）。

## 3.8 操作日志 / 时间线展示建议

> 主 PRD §2 In Scope：详情页操作日志含——创建调拨、作废、PDA 回写、发运、调入仓收货回写。

建议在状态区下方或独立卡片 **操作日志** 中按时间倒序展示：

| 日志类型 | 触发动作（主 PRD） | 建议展示字段 |
| :--- | :--- | :--- |
| 创建调拨 | 新增 | 操作人、操作时间、说明「创建空单调拨计划」 |
| 作废 | 作废 | 操作人、操作时间 |
| PDA 回写 | PDA 发车（明细回写） | 操作人/终端、操作时间、关联运单号列表摘要 |
| 发运 | PDA 发车 | 操作时间、状态变更 待出库→已出库 |
| 调入仓收货回写 | 调入仓收货完成（系统） | 系统、操作时间、状态变更 已出库→已完成 |

**展示规格**：

- 时间格式 `YYYY-MM-DD HH:mm:ss`
- 每条日志一行：时间 + 类型 + 操作人 + 摘要
- Demo Mock 至少覆盖 5 种日志类型各 1 条（按单据状态取舍）

## 3.9 页面状态与反馈

### 空态 / 异常

| 场景 | 展示 |
| :--- | :--- |
| 单号不存在 | 全页「单据不存在或无权查看」+ 返回列表 |
| 明细为空 | 明细卡片内「暂无实装运单」 |

### 加载状态

| 场景 | 展示 |
| :--- | :--- |
| 首次进入 | 状态区 + 卡片 Skeleton |
| 作废提交中 | 作废按钮 Loading，防重复提交 |

### 错误状态

| 场景 | 反馈 |
| :--- | :--- |
| 详情加载失败 | Toast「加载失败，请重试」 |
| 作废失败（已有明细） | Toast「作废失败，该计划已有实装运单」 |
| 网络异常 | Toast「网络异常，请重试」 |
