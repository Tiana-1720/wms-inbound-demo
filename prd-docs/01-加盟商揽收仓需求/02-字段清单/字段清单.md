## 单据关系

```
收货订单 ══ 入库单（共用表，一份字段清单，状态驱动；加盟路径不进收货中/已收货）
    │
    └──→ 上架单（本步不展开）
              ↘
调拨计划单 ──→ 出库单（本步不展开）
              ──→ 调入仓入库单（共用表，入库类型=调拨入库）
```

- **收货订单 / 入库单**：共用同一数据表，字段见《收货订单-入库单字段清单》；主键=**收货单号**
- **调拨计划单**：总部创建空单；明细仅 PDA 回写；一计划多运单
- **上架单 / 出库单**：本步不定稿，不把作业单号、库位、出库单号等写入上两份清单

## 命名约定

- 上游 TMS 推送的单号字段统一称 **运单号**（TMS 接口字段名仍为「订单号」）
- WMS 内部主键：收货单号（入库单同指）、调拨计划单号
- 收货订单状态定稿用 **已取消**（不再用「已撤销」）
- 空单调拨状态复用现网四态：**待出库 / 已出库 / 已完成 / 已取消**（不再用「待装车 / 已发运」）

## 快照字段总述

| 单据 | 快照（系统带出并存储） | 下游回写 | 系统计算 | 用户填写 |
| :--- | :--- | :--- | :--- | :--- |
| 收货订单 / 入库单 | 运单号、预报箱数及粗纲 TMS 预报类字段 | 收货箱数、收货人、收货时间、收货仓库、托号、绑托/上架完成时间。不回写收货重量/体积；不收录扫描时间/扫描人/明细绑托时间 | 无独立计算列（汇总与头部同源） | 无（后台不新建、不改预报） |
| 调拨计划单 | 明细.客户代码（上游推单必填） | 明细运单号、箱数（≥1）、重量、体积 | 汇总箱数/重量/体积（列表不展示） | 调出仓库、调入仓库（落仓库代码）；备注不收录 |

详见各单据清单 §五。

## 已确认规则（原待确认 1–7）

| # | 字段/主题 | 确认结论 | 依据 |
| :--- | :--- | :--- | :--- |
| 1 | 单号 | **收货单号**=`IB`+年月日+5 位流水号。**调拨计划单号**=`AT`+`YYMMDD`+5 位流水号 | 现网表格 22；本次确认 |
| 2 | 状态 / 入库类型 | 取值以**中文**为准。入库类型**不展示、不可筛**；收货订单**仅列出常规入库**。速达发车=常规入库；空单对接=调拨入库（不进收货订单列表） | 现网表格 6、12；本次确认 |
| 3 | 预报必填全集 | 沿用现网表格 7，其中**客户代码改为上游推单必填**；客户等级/渠道仍选填 | 现网表格 7；本次确认 |
| 4 | 重量/体积 | 重量最多 **2** 位小数；体积保留 **6** 位小数 | 现网表格 19 |
| 5 | 收货回写时点 | **收货箱数**、**收货仓库**绑托完成后回写。**收货重量 / 收货体积不回写**。**收货人 / 收货时间**=PDA 提交绑托的操作人、操作时间 | 本次确认 |
| 6 | 调拨入库落数字段 | 实装箱数/重量/体积**写入预报列**（预报箱数/预报重量/预报体积） | 本次确认 |
| 7 | 列表 | **默认排序**=创建时间升序。列表页查询区对齐现网 **12 项**（见 Demo 列表页 V1.1 §1.3），无展开区；预报仓库与收货仓库分筛规则保留在字段能力层，待后续迭代暴露。**列序、列宽待定** | Demo 列表页 V1.1；列序列表宽本次确认待定 |
