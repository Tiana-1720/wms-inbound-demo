## 五、展示与引用规则

### 5.1 状态与动作（禁止表单直改状态）

| 当前状态 | 动作 | 前置条件 | 结果状态 | 对本单字段的影响 |
| :--- | :--- | :--- | :--- | :--- |
| （无单） | 新增 | 调出仓库类型=加盟揽收仓；调出仓库、调入仓库必填 | 待出库 | 生成调拨计划单号；明细空；表单不展示状态 |
| 待出库 | 作废 | 明细无运单 | 已取消 | 全部只读 |
| 待出库 | PDA 发车 | 已扫实装 | 已出库 | 回写明细；后续本单只读 |
| 已出库 | 调入仓收货完成（系统） | 该计划下调拨入库单均已收货 | 已完成 | 对接回写，只读；后续绑托/上架不改本单状态 |

### 5.2 字段锁定

- 创建后：**调出仓库**、**调入仓库**只读（R04/R22），落库存仓库代码
- 待出库：无业务字段可改（备注暂不收录）
- 已出库 / 已完成 / 已取消：全部只读（R22）
- **状态**不可下拉修改

### 5.3 快照 / 实时 / 计算区分

| 类别 | 字段 | 说明 |
| :--- | :--- | :--- |
| 用户填写 | 调出仓库、调入仓库 | 创建时选仓，落库存仓库代码；创建后锁定 |
| 下游回写 | 明细.运单号、明细.箱数、明细.重量、明细.体积 | PDA 装车回写；箱数不允许为 0 |
| 系统带出并存储（快照） | 明细.客户代码 | 上游推单必填，扫描时从收货订单带出并落在本单明细 |
| 系统计算（实时） | 汇总箱数、汇总重量、汇总体积 | 按明细加总；**列表不展示**，详情可展示 |
| 系统生成 | 调拨计划单号、状态、创建人/时间、最后修改人/时间 | 用户不可改 |

### 5.4 下游引用（本清单不定义下游字段本体）

发车后按主 PRD §3.4 生成下游单据，本单只被引用：

- 调出仓出库单：继承**调拨计划单号**；明细继承实装**运单号**、**客户代码**、**箱数**、**重量**、**体积**（出库单字段见出库单清单，本文不展开）
- 调入仓入库单：按实装运单各生成一张；**入库类型=调拨入库**；**预报仓库**=本单**调入仓库**；**收货仓库**空；**收货单号**新生成；实装箱数/重量/体积**写入预报列**（入库单字段见《收货订单-入库单字段清单》）

### 5.5 列表与权限

- **默认排序**：按创建时间升序（现网调拨计划查询条件）
- **筛选**：沿用现网表格 11（运单号/调拨计划号精确搜索；调入仓库、调出仓库多选，显示 `仓库代码(仓库名称)`）
- 列表优先列：调拨计划单号、调出仓库、调入仓库、状态、创建时间。汇总箱数/重量/体积**列表不展示**。**列序、列宽待定**
- 数据权限沿用现网：账号可用仓库命中**调出仓库或调入仓库**即可查看（主 PRD §七）
- 重量最多 2 位小数，体积保留 6 位小数（现网表格 19）

### 5.6 明确不纳入本单的字段

- 计划发运时间、发运时间（粗纲已去掉）
- **备注**：暂不需要，不收录
- **调拨策略**：不在本清单落字段（按调出仓库类型带出，见主 PRD R02）
- 出库单号、归属仓库、入库类型、收货单号、预报仓库、收货仓库（下游或收货订单字段）
- 托号、箱号、初始/目标库位（上架/装车执行层）
