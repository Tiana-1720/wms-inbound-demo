## 2.2 弹窗底部操作栏

| 元素 | 规格 |
| :--- | :--- |
| 位置 | 弹窗 footer，**右对齐** |
| 按钮（从左到右） | `取消`（次操作）　`确定`（主操作） |
| 关闭 | 点「取消」、右上角 ×、或遮罩（提交中禁用）均关闭弹窗并回到列表 |

**确定行为**（对应主 PRD §5.2 动作「新增」）：

- 校验调出仓库、调入仓库必填
- **调出仓库与调入仓库不能相同**（R29）
- 调出仓库类型须为加盟揽收仓（R02）；缺仓、同仓或类型不符则阻断
- 保存成功：生成调拨计划单号，状态=待出库，明细空；Toast「保存成功」；**关闭弹窗**；列表刷新并定位「待出库」Tab

## 2.3 弹窗表单区

弹窗宽度约 **640px**。布局：**两列**并排（调出仓库 | 调入仓库）；标签左对齐，必填项带 `*`。

| 字段 | 控件类型 | 详细规格 |
| :--- | :--- | :--- |
| 调出仓库 | `SelectWithSearch` * | 单选；数据来源仓库档案；展示 `仓库代码(仓库名称)`；落库仓库代码；选项限加盟揽收仓（R02） |
| 调入仓库 | `SelectWithSearch` * | 单选；数据来源仓库档案；展示 `仓库代码(仓库名称)`；**不能与调出仓库相同**（R29）；不做仓到仓路由硬校验（R03） |

> **不展示**：调拨计划单号、状态、**调拨类型**、调拨明细、汇总（创建时空单，字段清单 §二、§三）。

卡片底部说明文案：「明细由 PDA 装车扫描回写，创建时不预填运单」
