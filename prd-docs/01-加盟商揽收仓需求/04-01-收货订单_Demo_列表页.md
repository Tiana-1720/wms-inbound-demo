## 1.1 页面概述

## 1.2 状态 Tab 栏

列表页主过滤入口。Tab 集合与现网收货订单列表一致，可查看全部状态，不按状态藏单（主 PRD §3.1）。

| Tab 标签 | 过滤逻辑 |
| :--- | :--- |
| 全部 | 展示所有状态（默认选中） |
| 待收货 | 状态 = 待收货 |
| 收货中 | 状态 = 收货中 |
| 已收货 | 状态 = 已收货 |
| 已绑托 | 状态 = 已绑托 |
| 已上架 | 状态 = 已上架 |
| 已取消 | 状态 = 已取消 |
| 异常 | **异常类型** 不为空（非状态枚举值；对齐现网 Tab） |

**Tab 交互规则**：

- 每个 Tab 右侧展示当前条件下的计数（格式：`Tab名 (N)`，超过 99 展示 `99+`，0 也展示）
- 切换 Tab 后列表刷新，页码重置为第 1 页，**不清空**查询区条件
- **状态、异常类型**仅通过 Tab 过滤，查询区**不提供**对应下拉（对齐现网列表页截图）

## 1.3 查询区

### 布局说明

对齐现网**三行栅格**布局（桌面端约 5 列）。查询区**仅展示下列 12 项**，无「展开/收起」区域。

| 行 | 字段 |
| :--- | :--- |
| 第 1 行 | 运单号、参考号、收货单号、客户代码、渠道 |
| 第 2 行 | 收货仓库、目的国、业务类型、业务归属 |
| 第 3 行 | 运输类型、预计到仓日期、收货日期、操作按钮组 |

右侧操作组顺序：`重置` → `查询`（主按钮，蓝色）

> **范围说明**：字段清单中另有「可筛选=是」的预报仓库、目的仓库、客户等级、状态、异常类型、箱号、托号等，**本期列表页查询区不暴露**（状态/异常见 §1.2 Tab；其余字段留待后续迭代或详情/高级检索，不在本 Demo 列表页重复定义控件）。

### 查询条件（12 项）

> 控件类型取自字段清单「取值说明/备注」及现网表格 5 口径；界面标签与现网截图一致。

| 字段 | 界面标签 | 控件类型 | 规格说明 |
| :--- | :--- | :--- | :--- |
| 运单号 | 运单号 | `BatchSearchInput` | placeholder：`运单号,多个用逗号或空格隔开`；精确匹配；支持多值 |
| 参考号 | 参考号 | `BatchSearchInput` | placeholder：`参考号,多个用逗号或空格隔开`；精确匹配；支持多值 |
| 收货单号 | 收货单号 | `BatchSearchInput` | placeholder：`收货单号,多个用逗号或空格隔开`；精确匹配；支持多值 |
| 客户代码 | 客户代码 | `Input` | 模糊匹配 |
| 渠道 | 渠道 | `Input` | 模糊匹配（现网表格 5） |
| 收货仓库 | 收货仓库 | `SelectWithSearch` | 多选；数据来源仓库档案；展示格式 `仓库代码(仓库名称)` |
| 目的国 | 目的国 | `SelectWithSearch` | 字典为国家二字码 |
| 业务类型 | 业务类型 | `Select` | 枚举：`整柜`、`散货` |
| 业务归属 | 业务归属 | `Select` | 枚举：`德速`、`速达`、`德捷` |
| 运输类型 | 运输类型 | `Select` | 枚举：`海运`、`空运`、`快递` |
| 预计到仓时间 | **预计到仓日期** | `DateRange` | 区间选择；格式 `YYYY-MM-DD`；placeholder：预计到仓开始日期 / 预计到仓结束日期 |
| 收货时间 | **收货日期** | `DateRange` | 区间选择；格式 `YYYY-MM-DD`；placeholder：收货开始日期 / 收货结束日期 |

**查询交互**：

- 点击「查询」：携带 Tab 条件 + 查询区条件请求列表，页码重置为 1
- 点击「重置」：清空查询区全部条件（**不重置**当前 Tab），立即刷新列表
- Enter 键在输入框内触发查询

## 1.7 Mock 数据规格

### 状态覆盖要求

| 状态 / Tab | 最少条数 | 备注 |
| :--- | :--- | :--- |
| 待收货 | ≥ 3 | 收货箱数/重量/体积为 0 或 `-` |
| 收货中 | ≥ 1 | 现网自营/集货仓路径 |
| 已收货 | ≥ 1 | 现网自营/集货仓路径 |
| 已绑托 | ≥ 2 | 收货箱数已回写，收货重量/体积为空 |
| 已上架 | ≥ 2 | 收货箱数已回写 |
| 已取消 | ≥ 1 | |
| 异常（异常类型非空） | ≥ 1 | |
| **总计** | **≥ 12** | |

### 数据要求

- **收货单号**格式：`IB` + 年月日 + 5 位流水号，如 `IB26070800087`
- **运单号**：虚构，如 `SDL260581625`
- **参考号**：可为 `-` 或虚构参考号
- **客户代码**：虚构，如 `amzbao`
- **预报仓库 / 收货仓库**：展示如 `YW(义乌紫鑫仓)`；待收货时收货仓库为 `-`
- **预报/收货箱数**：待收货展示 `0 / 11`；已绑托后展示 `11 / 11`
- **业务类型**：散货 / 整柜；**业务归属**：速达 / 德速 / 德捷；**运输类型**：海运 / 空运 / 快递
- 所有数据使用虚构演示数据，不使用真实公司信息

## 1.8 页面状态与反馈

### 空状态

| 场景 | 展示 |
| :--- | :--- |
| 首次进入 / 查询无结果 | 表格区域居中展示「暂无数据」插图 + 文案「暂无收货订单」 |
| 某 Tab 计数为 0 | Tab 仍展示 `(0)`；点击进入后同上空状态 |

### 加载状态

| 场景 | 展示 |
| :--- | :--- |
| 首次加载 / Tab 切换 / 查询 / 翻页 | 表格区域展示 Skeleton 行（≥ 5 行）或 Loading 遮罩 |
| Tab 计数加载 | Tab 标签计数位展示小型 Loading，加载完成后替换为数字 |

### 错误状态

| 场景 | 反馈类型 | 文案 |
| :--- | :--- | :--- |
| 列表接口失败 | Toast | 加载失败，请重试 |
| 网络异常 | Toast | 网络异常，请重试 |
| Tab 计数接口失败 | 静默降级 | Tab 计数展示 `-`，不影响列表主查询 |

### 操作成功反馈

列表页无写操作，无成功 Toast。
