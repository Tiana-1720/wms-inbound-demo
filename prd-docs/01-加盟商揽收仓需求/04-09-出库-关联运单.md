## 2.3 头部信息区

布局**对齐现网出库作业页**（两行，无卡片标题）。**全部只读**（`Form disabled`），不可编辑（主 PRD R22；关联运单不通过表单改状态）。

### 第一行（只读文本）

| 字段 | 控件 | 展示规格 |
| :--- | :--- | :--- |
| 出库计划号 | ReadonlyText | 取头部 **计划单号** |
| 状态 | ReadonlyText + Tag | **待出库** / **已复核** / **已出库** |

### 第二行（表单外观，只读）

| 字段 | 控件 | 展示规格 | 显隐/只读 |
| :--- | :--- | :--- | :--- |
| 柜号 | `Input` | placeholder `请输入` | **只读** |
| 司机电话 | `Input` | 未回写时空；placeholder `请输入`（UI 标签可沿用现网「电话」） | **只读**（PDA 装车锁定回写） |
| 车牌号 | `Input` | 同上 | **只读** |

**不展示**：备货库位、出库单号、调拨计划单号、归属仓库、备注等。

## 2.4 选择运单区域

卡片标题：**选择运单**。主页面仅展示「**选择运单**」按钮；点击后打开 **Modal 弹窗**完成查询与勾选。

### 业务约束（呈现层，规则来自主 PRD）

- 关联对象须为**库位库存中已上架**货物对应运单（§3.4.3、PDA 装车同源）
- **不允许拆票装车**（R20）：勾选粒度为**整票运单**，须整票关联
- 提交前校验**可用库存**，不足则拒绝（§5.3、R14）
- 保存后：**仅建立运单与出库单关联**并回写明细；**出库单状态仍为待出库**（若原状态为待出库）或保持**已复核**（若原状态为已复核）；**不变更调拨单状态**（R50）

### 主页面

| 元素 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 选择运单 | 按钮（主操作） | 打开选择运单弹窗 |
| 已选提示 | 文本 | 弹窗确认后展示 `已选 N 票（待保存）`；0 票不展示 |

### 选择运单弹窗（Modal）

| 元素 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 运单号 | `Input` | 精确搜索；placeholder：`运单号,多个用逗号或空格隔开` |
| 查询 | 按钮 | 刷新弹窗内可选运单列表 |
| 运单表格 | `Table` + 行勾选 | 每行一票；**整票勾选**；已保存关联运单勾选且不可取消 |
| 确定 | 按钮 | 将本次勾选写入 §2.5 待保存预览；未选新运单 Toast `请至少选择一票运单` |
| 取消 | 按钮 | 关闭弹窗，不改动待保存清单 |

### 可选运单表格列

> 列字段来自收货/库存侧展示需要；写入出库单明细时仅回写 §二字段。

| 列名 | 说明 |
| :--- | :--- |
| 勾选 | 整票选择 |
| 运单号 | 候选运单主键 |
| 客户代码 | 选中后写入明细 **客户代码** |
| 箱数 | 该票可关联箱数；写入明细 **箱数** |
| 重量 | 单位 KG；写入明细 **重量** |
| 体积 | 单位 CBM；写入明细 **体积** |

**交互**：

- 主页面点击「选择运单」→ 打开弹窗
- 弹窗内查询、勾选运单 → 点击「确定」→ 同步加入 §2.5 待保存预览
- 弹窗内取消勾选 → 确定后从待保存清单移除（**已保存的历史关联**不可在弹窗取消，本期不展开移除规则）
- 库存被占用：行不可选或勾选时 Toast `可用库存不足`

## 2.6 固定底部操作栏

| 元素 | 规格 |
| :--- | :--- |
| 位置 | `fixed bottom-0 right-0` |
| 按钮顺序（从左到右） | `取消`（次操作）　`确定`（主操作） |

| 按钮 | 展示条件 | 行为 |
| :--- | :--- | :--- |
| 取消 | 常驻 | 返回 `/order/Outbound`；有未保存勾选时二次确认「放弃未保存的关联？」 |
| 确定 | 出库单=**待出库**或**已复核** | 触发主 PRD §5.3 动作 **PC 关联运单**；无待保存变更时 **disabled** |

**不展示**：**确认出库**、**打印装柜单**（在列表或调拨详情操作）；**手动锁单**（在调拨计划详情，§5.2）。

### 保存校验与反馈

| 场景 | 反馈 |
| :--- | :--- |
| 未选运单 | Toast：`请至少选择一票运单` |
| 可用库存不足 | Toast：`可用库存不足` |
| 保存成功 | Toast：`关联成功`；**状态 Tag 不变**；返回列表或停留本页并刷新明细 |
| 保存失败 | Toast：服务端原因；默认 `保存失败` |
