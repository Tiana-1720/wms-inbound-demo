# 调拨计划_Demo_详情页

> **文档定位**：AI 生成「调拨计划详情」前端原型的输入文档，聚焦页面结构、控件类型、交互行为。**本文件为生成物，不是业务规则权威源。**
> **字段定义**：字段枚举值、计算规则、必填性等见《调拨计划单字段清单》，本文件只写页面呈现规则，严禁重复定义。
> **动作与状态**：状态机、动作能力见《03-加盟商揽收仓管理后台主PRD》§5.2；本文件只翻译为页面显隐，不新增动作。
> **版本**：V1.4 | 2026-08-31（V1.3：取消改后期迭代；本版：调拨类型口径统一）

## 3.1 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 调拨计划详情 |
| 页面目标 | 查看调拨计划完整信息、实装明细与汇总（含计划调拨与空单调拨；后台以**调拨类型**区分，**页面不展示该字段**） |
| 页面路径 | `/order/TransferPlan/{调拨计划单号}` |
| 列表路径 | `/order/TransferPlan` |
| 骨架结构 | 状态区 → 基础信息 → 调拨明细 → 汇总信息 → 系统信息 → **操作日志** → 固定底部操作栏 |

## 3.2 状态区

当前状态 Badge：**待出库 / 已出库 / 已完成 / 已取消**（沿用现网三态 + 预留已取消；**本期无取消入口**）。状态变更节点见 §3.8 操作日志。

## 3.4 调拨明细卡片

只读表格：序号、运单号、客户代码、箱数、重量、体积。无明细时空态「暂无实装运单」。

## 3.5 汇总信息

单据级汇总箱数、汇总重量、汇总体积；无明细为 `0`。

创建人、创建时间、最后修改人、最后修改时间。

## 3.8 操作日志

卡片标题：**操作日志**。仅展示**本调拨计划单**日志，按**操作时间**倒序。

### 展示列（统一格式）

| 列名 | 说明 |
| :--- | :--- |
| 操作内容 | 动作中文描述（对应 §5.2 动作，见下表） |
| 操作时间 | `YYYY-MM-DD HH:mm:ss` |
| 操作人 | 总部用户姓名 / PDA 操作员 / **系统**（系统回写时） |

### 日志类型（= 主 PRD §5.2 本期动作）

| 操作内容（示例） | 操作人 |
| :--- | :--- |
| 创建调拨计划 | 总部登录用户 |
| PDA 装车发车 | PDA 操作员 |
| 调入仓收货完成 | 系统 |

> **取消调拨计划**：后期迭代日志类型；若 mock 数据含已取消态，可展示历史「取消调拨计划」日志，但本期无触发入口。

**空态**：仅「创建调拨计划」一条时正常；无日志时展示「暂无操作记录」。
