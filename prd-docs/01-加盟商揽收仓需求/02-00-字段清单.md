## 单据关系

```
收货订单 ══ 入库单（共用表，一份字段清单，状态驱动；加盟路径不进收货中/已收货）
    │
    │  PDA 确认绑托（状态→已绑托；无库存变动）
    ↓
  上架单（一运单一张；绑托完成系统生成；待上架→已完成；PDA 执行上架）
    │
    │  上架完成（联动共用表→已上架；预报库存− / 库位库存+）
    ↓
  库位库存 ──可被装车引用──→ 调拨计划单
                                    │
                                    └──→ 出库单（空单调拨：PDA 装车→已复核；PC 确认出库→已出库）
```

- **收货订单 / 入库单**：共用同一数据表，字段见《收货订单-入库单字段清单》；主键=**收货单号**；加盟路径 **待收货 → 已绑托 → 已上架**
- **上架单**：**绑托完成时系统自动生成**（一运单一张，1:1）；主键=**作业单号**；通过**运单号**关联共用表；字段见《上架单字段清单》（**定稿**）
- **调拨计划单**：OMS 创建空白调拨；明细仅 PDA 回写；一计划多运单
- **出库单**：空单调拨在 **PDA 装车**时生成/追加（**已复核**），**PC 确认出库**时→**已出库**；**不生**调入仓调拨入库单（东莞常规入库由发车现网推送）

## 命名约定

- 上游 TMS 推送的单号字段统一称 **运单号**（TMS 接口字段名仍为「订单号」）
- WMS 内部主键：收货单号（入库单同指）、**作业单号**（上架单）、调拨计划单号
- 收货订单状态定稿用 **已取消**（不再用「已撤销」）
- 空单调拨状态：沿用现网 **待出库 / 已出库 / 已完成**，**预留已取消**（Tab 保留；**本期无取消入口**）

## 快照字段总述

| 单据 | 快照（系统带出并存储） | 下游回写 | 系统计算 | 用户填写 |
| :--- | :--- | :--- | :--- | :--- |
| 收货订单 / 入库单 | 运单号、预报箱数及粗纲 TMS 预报类字段 | 收货箱数、收货人、收货时间、收货仓库、托号、绑托/上架完成时间。不回写收货重量/体积；不收录扫描时间/扫描人/明细绑托时间 | 无独立计算列（汇总与头部同源） | 无（后台不新建、不改预报） |
| 上架单 | 运单号、托号、件数（=收货箱数）、作业类型=收货上架 | 目标库位、件数（实际上架）、上架完成时间、上架人 | 托数/已上架托数/未上架托数 | 目标库位（PDA 人工选择，Q10） |
| 调拨计划单 | 明细.客户代码 | 明细运单号、箱数（≥1）、重量、体积 | 汇总箱数/重量/体积 | 调出仓库、调入仓库（落仓库代码） |

详见各单据清单 §五。

## 已确认规则（原待确认 1–7）

| # | 字段/主题 | 确认结论 | 依据 |
| :--- | :--- | :--- | :--- |
| 1 | 单号 | **收货单号**=`IB`+年月日+5 位流水号。**调拨计划单号**=`AT`+`YYMMDD`+5 位流水号 | 现网表格 22；本次确认 |
| 2 | 状态 / 入库类型 | 取值以**中文**为准；沿用现网入库类型过滤与展示规则 | 现网表格 6、12 |
| 3 | 预报必填全集 | 沿用现网表格 7 | 现网表格 7 |
| 4 | 重量/体积 | 重量最多 **2** 位小数；体积保留 **6** 位小数 | 现网表格 19 |
| 5 | 收货回写时点 | **收货箱数**、**收货仓库**绑托完成后回写。**收货重量 / 收货体积不回写**。**收货人 / 收货时间**=PDA 提交绑托的操作人、操作时间 | 本次确认 |
| 6 | 调拨入库落数字段 | 实装箱数/重量/体积**写入预报列**（预报箱数/预报重量/预报体积） | 本次确认 |
| 7 | 列表 | **默认排序**=创建时间升序。列表页查询区对齐现网 **12 项**（见 Demo 列表页 V1.1 §1.3），无展开区。**列序、列宽待定** | Demo 列表页 V1.1；列序列表宽本次确认待定 |
| 8 | 调拨下推 | 按 **`调拨类型`** 分支：**计划调拨**=现网（创建时或全部收货后同批下推出库单+调入仓入库单，计划变更同步下游）；**空单调拨**=建计划不下推；**PDA 装车**生成/追加出库单（已复核）；**PC 确认出库**→已出库并扣库存；**不生**调拨入库单 | 主 PRD V1.8 §3.4、§6.6 R24–R30 |
| 9 | 调拨两仓 | **调出仓库≠调入仓库**（R29 / Q19） | 主 PRD V1.6.1、Demo 新增页 §2.4 |
| 10 | 上架单生成 | 收货订单**全部箱绑托完成**、状态→**已绑托**时**同事务自动生成上架单**；**一运单一张**（1:1）；**件数**=该运单全部已绑托箱数 | PDA 主 PRD §5.1.3、R33/R43 |
