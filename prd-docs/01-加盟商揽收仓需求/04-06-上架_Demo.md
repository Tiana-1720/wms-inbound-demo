# 上架_Demo

> **文档定位**：AI 生成 PDA「上架」移动端原型的输入文档。**本文件为生成物，不是业务规则权威源。**
> **字段定义**：见《上架单字段清单》；箱号展示继承《收货订单-入库单字段清单》§二**箱号**（上架单不重复存储，仅呈现聚合）。
> **动作与状态**：见《03-02-加盟商揽收仓PDA主PRD》§5.3.4、§11；本文件只翻译为页面显隐。
> **原型参考**：上架作业页（子页 B）布局对齐产品原型（运单头信息 + 托卡片 + 库位选择 + 底部双按钮）。
> **版本**：V1.1 | 2026-09-01（本版：对齐主 PRD §11.0 现网/加盟区分）

---

## 0. 与现网上架区分（呈现层说明）

本 Demo **仅展开加盟揽收仓路径**。与现网上架的区分见主 PRD **§11.0**：

| 判定 | 本 Demo 是否覆盖 |
| :--- | :--- |
| 当前仓库 **仓库类型=加盟揽收仓** | ✅ 本文件 |
| 当前仓库 **仓库类型≠加盟揽收仓** | ❌ 走现网上架，不在本 Demo |

**勿混淆**：「历史上架库位」是跨库位提醒用的**数据字段**，不是独立的「历史上架功能」。

## 子页 B：上架作业页（对齐产品原型）

### B.1 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面路径 | `/pda/inbound/putaway/{作业单号}` |
| 骨架结构 | 顶栏 → 头信息区（白底）→ 托卡片列表（灰底）→ 底部固定操作栏 |

### B.2 顶栏

| 元素 | 规格 |
| :--- | :--- |
| 返回 | 返回子页 A |
| 标题 | `上架` |

### B.3 头信息区（只读，白底）

对齐原型三行布局：

| 行 | 展示字段 | 展示格式（原型对齐） |
| :--- | :--- | :--- |
| 第 1 行 | **运单号**、**作业单号** | `运单号：DSL26010128343`　`作业单号：TK2601010001` |
| 第 2 行 | **作业类型** | `作业类型：收货上架` |
| 第 3 行 | 进度汇总 | `已上架：350箱 / 8托`　`未上架：0箱 / 0托` |

**第 3 行字段来源**（系统计算，见上架单字段清单 §三）：

| 展示文案 | 计算口径 |
| :--- | :--- |
| 已上架 X箱 | 收货明细**箱号**中，所属托**上架状态**=已上架的箱数 |
| 未上架 X箱 | **件数**（头部）− 已上架箱数 |
| 已上架 Y托 | **已上架托数** |
| 未上架 Y托 | **未上架托数** |

**第 3 行可点击**（§11.2）：点击「已上架」或「未上架」区域 → 跳转 **子页 C** 对应 TAB。

**不展示**：**初始库位**（§11.3 #2）；**状态**、**件数**头部总数可在进度区隐含，不重复占行。

### B.4 托卡片列表（灰底可滚动）

每个**待上架**或**未完结**的托一行白色卡片（对齐原型）：

```
┌─────────────────────────────────────────┐
│ 托号 PL25010100001                       │
│ 箱号 FBA1988W5Y0GU000001...(30箱)    库位 > │
└─────────────────────────────────────────┘
```

| 卡片区域 | 字段 | 控件 | 规格 |
| :--- | :--- | :--- | :--- |
| 标题行 | 托明细.**托号** | ReadonlyText | 加粗，`托号 PL25010100001` |
| 内容左 | 收货明细.**箱号** + 托明细.**件数** | ReadonlyText | `箱号 {首箱箱号}...({件数}箱)`；首箱=该托下按箱号排序第一箱，**件数**=托明细.**件数** |
| 内容右 | 托明细.**目标库位** 或 头部.**目标库位** | `LocationPicker` | 文案「库位」+ 已选库位或占位 + `>`；点击打开 `BottomSheet` + `SelectWithSearch` |

**库位选择规则**（R10、§11.3 #3）：

- 仅可选揽收仓**备货库位**
- 不关联出库单、不做存储区
- 未选库位时，该托卡片右侧显示灰色占位「库位」

> **待确认**（字段清单 §六）：托级与单级**目标库位**关系未定时，Demo 按**托卡片独立选库位**呈现（与原型一致）；若产品确认仅头部维护，则改为头部统一库位、卡片只读展示。

**已上架托**（托明细.**上架状态**=已上架）：卡片只读，展示已选库位，不可再编辑。

### B.5 底部固定操作栏

对齐原型：左「重置」+ 右「确认上架」。

| 按钮 | 样式 | 展示条件 | 对应矩阵动作 | 行为 |
| :--- | :--- | :--- | :--- | :--- |
| 重置 | 白底蓝边（次按钮） | 状态=**待上架**且有未保存的库位选择 | —（呈现层） | 清空当前页未提交的库位选择；**不修改服务端** |
| 确认上架 | 实心蓝底（主按钮） | 状态=**待上架**且**当前焦点托**已选库位 | **上架确认** | 当前托下全部箱→已上架；更新托明细**上架状态**；更新进度区计数 |

**未选库位时**：「确认上架」按钮**不展示**（非 disabled）。

**全部托完成后**：上架单→**已完成**；联动收货订单→**已上架**；Toast `上架成功`；底部栏改为仅「返回」或自动返回子页 A。

**状态=已完成**：整页只读；底部栏不展示操作按钮。

### B.6 跨库位不一致提醒（§11.3 #5）

当同运单多托选择不同备货库位时，点「确认上架」弹出：

| 标题 | 内容 | 确认 | 取消 |
| :--- | :--- | :--- | :--- |
| 提示 | `当前库位和运单已上架的历史库位{库位}不一致，是否确认上架` | 确认上架 | 取消 |

## 加盟增量对照（§11.3，仅控件显隐）

| # | Demo 呈现 |
| :--- | :--- |
| 1 | 绑托完成即有待上架任务；收货订单状态为**已绑托**（不进已收货） |
| 2 | 作业页**不展示****初始库位**；入口列表**初始库位**列保留为空 |
| 3 | 库位选择器仅备货区；无出库单联动 |
| 4 | 库容超载二次确认：未配置则跳过 |
| 5 | 跨库位不一致弹窗见 B.6 |
| 6 | 整单完成后上架单**状态**=已完成 |

## 空状态、加载状态、错误状态

| :--- | :--- | :--- |
