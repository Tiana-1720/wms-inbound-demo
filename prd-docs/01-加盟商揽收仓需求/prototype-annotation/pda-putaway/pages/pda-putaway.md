## 需求描述：【上架页】

> 来源：04-06 上架 Demo 子页 A/B/C；03-02 §十一；02-03 上架单字段清单

### 页面入口

- PDA → **入库管理 → 上架**（或 库内作业 → 移库 → 上架 TAB，R35）
- 路径 `/pda/inbound/putaway`；双入口查询**同一上架单**

### 改动逻辑

1. **上架校验**：**加盟揽收仓**不收货测量可上架；**其他仓库**须收货测量后才可上架。
2. **数据范围**：查询移库作业**派发状态=待派发或已派发**且仍有待上架托的作业单（双入口查询**同一上架单**）。
3. **适用范围（本 Demo）**：加盟揽收仓路径；非加盟揽收仓走现网，不在本 Demo。
4. **进入方式**：扫箱号进入子页 B，或从列表点卡片进入；上架完成→收货订单**已上架**，**预报库存 − / 库位库存 +**。
5. **扫描校验（子页 A）**：箱号不存在 / 未绑托 / 已上架 / 作业单不在待派发·已派发 → 对应 Toast；成功跳转子页 B。
6. **库位规则（F-02）**：仅可选**备货库位**；运单首托未上架可选手动库位；已有托上架则取首托库位**自动带出禁止编辑**。
7. **确认上架**：当前焦点托已选库位后展示按钮；当前托全部箱→已上架，**托上全部运单**同步完成；跨库位不一致时 `Modal.confirm` 二次确认。

### 页面分区

| 分区 | 要点 |
| --- | --- |
| 入口扫描 | `ScanInput` 扫箱号；空态「暂无待派发/已派发的移库作业」 |
| 待上架列表 | 按运单一行：`运单`+运单号（加粗）、`箱号`+首箱（灰色）、右侧 `已上架/总箱数`；**不展示**作业单号、托号、派发状态 |
| 作业页头 | 运单号、作业单号、作业类型、已上架/未上架进度；点击进度→明细子页 |
| 托卡片 | 托号、运单列表、首箱+件数、目标库位 `LocationPicker`；仅展示当前焦点托 |
| 底部操作 | **重置**（清空未提交库位选择）/ **确认上架**（未选库位不展示按钮） |
| 明细子页 | TAB：全部/已上架/未上架；列：托号、运单号、箱号、库位；仅当前焦点托 |

### 研发备注

- 挂载点：`[data-anno='pda-putaway-page']`（覆盖入口/作业/明细子页）。
- 可扫描箱号见补充标注 **A1**（扫描区）。
