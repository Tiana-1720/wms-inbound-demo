## 需求描述：【入口扫描与待上架列表】

> 来源：04-06-上架_Demo.md 子页 A §A.1–A.4；03-02-加盟商揽收仓PDA主PRD.md §11.2、§11.4

### 业务定义

- 路径 `/pda/inbound/putaway`；双入口（入库管理→上架 / 库内作业→移库→上架 TAB）查询同一上架单（R35）。
- **仅加盟揽收仓路径**；仓库类型≠加盟揽收仓走现网上架，不在本 Demo。

### 交互规则

**方式 A · 扫描进入**

| 场景 | Toast |
| --- | --- |
| 箱号不存在 | `箱号不存在` |
| 未绑托 | `当前箱号未绑托` |
| 已上架 | `该箱已上架，不可重复上架` |

校验成功跳转子页 B，带出对应上架单。

**方式 B · 待上架任务列表**

| 卡片行 | 字段 | 说明 |
| --- | --- | --- |
| 主行 | 作业单号 | 加粗 |
| 副行 1 | 运单号 | 多票用 `、` 连接，如 `运单号：DSL…、DSL…` |
| 副行 2 | 托号、件数 | 大票多托时头部托号取值规则**待确认**（字段清单 §六） |
| 副行 3 | 初始库位 | 列保留；加盟路径展示 `-` |
| 角标 | 状态 | `待上架` Tag |

- 空状态：`暂无待上架任务`。
- 无查询区（字段清单 PDA 列表无可筛选字段组合为查询区）。

### 研发备注

- 挂载点：`[data-anno='pda-putaway-entry']`。
- 可扫描箱号清单见补充标注 **A1**。

## 需求描述：【原型 Mock · 可扫描箱号】

> 来源：04-06-上架_Demo.md §Mock 数据规格；`front-prototype/src/mocks/putaway.ts`

### 可扫描箱号（进入子页 B）

| 作业单号 | 运单号 | 状态 | 可扫箱号（示例） | 说明 |
| --- | --- | --- | --- | --- |
| TK2601010001 | DSL26010128343 | 待上架 | `FBA1988W5Y0GU000001`～`000350` | 8 托大票；**预置 Mock**，扫任一箱进入 |
| （分货生成） | DSL26010128302、28303、28304 | 待上架 | `000381`～`000399` | **小票混托**：须在**分货页**混扫并「托满」后自动生成上架单（`putaway-sync.ts`） |

| 场景 | 操作 |
| --- | --- |
| 大票上架 | 上架页扫 `FBA1988W5Y0GU000001` |

| 箱号 / 作业单 | 触发 |
| --- | --- |
| `FBA1988W5Y0GU000351`～`000380`（TK2601010002） | 该箱已上架，不可重复上架 |
| 未在 `putaway.ts` 索引中的箱号 | 箱号不存在 |

### 研发备注

- 列表入口默认展示预置待上架单 **TK2601010001**；混托上架单须先经**分货绑托**生成后方出现在列表。
- **小票混托**：多运单生成**一张**上架单；扫托上任一箱进入该单，确认上架时**整托全部运单**一并完成。

## 需求描述：【托卡片与库位选择】

> 来源：04-06-上架_Demo.md 子页 B §B.4；03-02-加盟商揽收仓PDA主PRD.md §11.3（R10）

### 字段与状态

| 卡片区域 | 字段 | 核心约束 |
| --- | --- | --- |
| 标题行 | 托号 | 加粗 |
| 运单行 | 运单号列表 | 混托托展示 `运单：A、B、C` |
| 内容左 | 首箱号 + 件数 | `箱号 {首箱}...({件数}箱)` |

- 同运单已上架托存在目标库位时，后续托**自动带出**并锁定（原型 `isLocationLocked`）。

## 需求描述：【底部重置与确认上架】

> 来源：04-06-上架_Demo.md 子页 B §B.5–B.6；03-02-加盟商揽收仓PDA主PRD.md §5.3.4、§11.3 #5

### 交互规则

| 按钮 | 展示条件 | 行为 |
| --- | --- | --- |
| 重置 | 有待保存的库位选择 | 清空当前页未提交的库位选择；**不修改服务端** |
| 确认上架 | 状态=待上架且**当前焦点托**已选库位 | 当前托下全部箱→已上架；**托上全部运单**同步完成 |

- **未选库位时**：「确认上架」**不展示**（非 disabled）。
- 末托完成：Toast `上架完成`；返回子页 A。
- 单托成功：Toast `上架成功`。

### 权限与异常

- **跨库位不一致**（§B.6）：同运单多托选择不同备货库位时，点确认上架弹出 `Modal.confirm` 二次确认；原型**尚无稳定 `data-anno`**，需人工补充后单独挂载。

### 研发备注

- 挂载点：`[data-anno='pda-putaway-bottom']`。
