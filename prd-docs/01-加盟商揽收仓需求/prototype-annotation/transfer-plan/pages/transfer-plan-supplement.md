## 需求描述：【下推规则 · 详情页与其它】

> 来源：03-加盟商揽收仓管理后台主PRD.md §3.4.3、§6.6（R24–R28）、§5.2、§2 In Scope、R22；调拨计划单字段清单.md §5.4.2、§一～§四；调拨计划_Demo_详情页.md §3.1～§3.8

### 空单调拨下推规则

- 后台按 **`调拨类型`** 分支下推：**计划调拨**沿用现网；**空单调拨**走本次增量（R24）。**不按仓库单独配置下推时机**（R24）。
- 列表页同时展示两类单据；**页面不展示调拨类型**；计划调拨见主 PRD §3.4.2，不在此展开。

| 维度 | 空单调拨（本次） |
| --- | --- |
| 类型判定 | 总部手工新增 + 调出仓=加盟揽收仓 |
| 建计划 | 仅落单（待出库、明细空）；**不**预生成出库单/调入仓入库单 |
| 下推触发 | **仅 PDA 装车确认发车**（R26） |
| 下推产物 | **同批**生成：1 张调出仓出库单 + N 张调入仓入库单（按实装运单拆） |
| 明细来源 | PDA 装车扫描回写；扫**库位库存中已上架货** |
| 计划变更 | 两仓锁定；**不同步**下游 |
| PDA 路径 | 装车扫描 + 发车；**不进入**复核/装柜 |
| 集货仓 | 调入仓入库单生成时**预报库存 +**；命中**手动收货策略** |
| 调拨完结 | 调入仓该批入库单均收货完成 → 已完成（R19） |

- 管理后台列表/详情**不提供** PDA 发车、下推触发入口；仅展示下推结果。

---

### 详情 · 页面全局 · 只读边界

- 详情页共用：列表含**计划调拨**（上游推送）与**空单调拨**（手工创建）两类单据；后台以**调拨类型**区分，**页面不展示该字段**。详情只读。
- 创建后**调出仓库 / 调入仓库**只读；待出库无业务字段可改；已出库 / 已完成 / 已取消全部只读（R22）。
- **状态**不可下拉修改；变更只能通过动作（新增、PDA 发车、调入仓收货完成；**取消后期迭代**）。
- 本期无编辑页；**取消**后期迭代（R17）；后台无保存/提交。「返回列表」回 `/order/TransferPlan`。

---

### 详情 · 状态区

- 页头 Badge 仅展示**四态**：**待出库 / 已出库 / 已完成 / 已取消**；**不展示** **已复核**、**已下架**。
- Tag 配色：待出库蓝、已出库橙、已完成绿、已取消灰（与列表一致）。

---

### 详情 · 基础信息

| 字段 | 必填/可编辑 | 核心约束 |
| --- | --- | --- |
| 调拨计划单号 | 只读 | `AT`+`YYMMDD`+5 位流水；系统生成 |
| 调出仓库 | 只读 | `仓库代码(仓库名称)`；创建后锁定（R04/R22） |
| 调入仓库 | 只读 | `仓库代码(仓库名称)`；创建后锁定 |
| 状态 | 只读 | Tag；不可下拉修改 |

---

### 详情 · 调拨明细

- 只读表格。每行一个实装运单；总部创建时明细为空，仅 PDA 装车扫描回写。一计划多运单；不允许拆票（R20）。空态：「暂无实装运单」。
- 列：序号、运单号、客户代码、箱数、重量、体积（参考号/托号/箱号/目的仓库/扫描时间不展示）。

---

### 详情 · 汇总信息

- 单据级**汇总箱数、汇总重量、汇总体积**；对明细行聚合。无明细为 `0`。

---

### 详情 · 系统信息

- 创建人、创建时间、最后修改人、最后修改时间；主 PRD 无审核动作，不使用审核人 / 审核时间。

---

### 详情 · 操作日志

- 仅展示**本调拨计划单**日志，按**操作时间**倒序；列：操作内容、操作时间、操作人。
- 日志类型：创建调拨计划、PDA 装车发车、调入仓收货完成；**取消调拨计划**后期迭代。

---

### 详情 · 底部操作栏

- 全部状态仅 **返回列表**；**取消**后期迭代。

- 列表页挂 `[data-anno='transfer-plan-list-page']`；详情页挂 `[data-anno='transfer-plan-detail-page']`（互为 fallback）。
