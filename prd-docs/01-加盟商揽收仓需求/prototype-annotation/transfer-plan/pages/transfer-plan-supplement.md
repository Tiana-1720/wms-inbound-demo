> 来源：03-01-加盟商揽收仓管理后台主PRD.md §3.4.3、§6.6（R24–R28）、§5.2、R22；02-02-调拨计划单字段清单.md §5.4.2

> **口径说明**：下列**空单调拨下推**为本次增量；**调拨计划详情页整体沿用现网**，本期无页面改造。原型详情页仅为演示跳转占位，研发以现网详情为准。

---

### 空单调拨下推规则（本次增量）

- 后台按 **`调拨类型`** 分支下推：**计划调拨**沿用现网；**空单调拨**走本次增量（R24）。**不按仓库单独配置下推时机**。
- 列表页同时展示两类单据；**页面不展示调拨类型**；计划调拨见主 PRD §3.4.2，不在此展开。

| 维度 | 空单调拨（本次） |
| --- | --- |
| 类型判定 | OMS 创建 + 调出仓=加盟揽收仓 |
| 建计划 | 仅落单（待出库、明细空）；**不**预生成出库单/调入仓入库单 |
| 下推触发 | **PDA 装车**→出库单**已复核**；**PC 确认出库**→已出库并扣库存 |
| 下推产物 | **仅**1 张调出仓出库单；**不生**调入仓调拨入库单 |
| 明细来源 | PDA 装车扫描回写；扫**库位库存中已上架货**（扫箱号带整托） |
| 计划变更 | 两仓锁定（R22）；**不同步**下游 |
| PDA 路径 | 装车；**不进入**复核/装柜 |
| 司机/电话/车牌 | **沿用现网**；PDA 装车后回写（落出库单） |
| 东莞对接 | 东莞**常规入库**由发车现网推送；调拨完结=东莞**全部关联运单**常规入库收货完成 |
| 调拨完结 | PC 确认出库→**已出库**；东莞收货完成→**已完成**（R19） |

- 管理后台列表/详情**不提供** PDA 装车、下推触发入口；仅展示下推结果。
