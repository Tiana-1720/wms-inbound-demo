## 需求描述：【调拨计划新增弹窗】

> 来源：04-03 调拨计划 Demo §2.1～§2.4；03-01 §3.2、§3.4.4、§5.2、§6.1（R02/R03/R16）、§6.4、R19、R29；02-02 调拨计划单字段清单 §一、§5.1、§5.2

### 页面入口

- 调拨计划列表 → 工具条「**新增**」（仅总部作业部）
- 或路径 `/order/TransferPlan/new`（无权限重定向列表）

### 改动逻辑

1. **弹窗模式**：列表点击「新增」打开 Modal；仅调出/调入两仓；仅**新增**无编辑；保存后类型=**空单调拨**（页面不展示类型）；**取消**关闭回列表。
2. **前置条件**：仅**总部作业部**可打开并确定；调出仓类型须为**加盟揽收仓**（R02）；保存后两仓锁定（R04/R22）。
3. **保存规则**：「确定」= 动作「新增」；调出/调入仓库必填；**调出≠调入**（R29）；不做仓到仓路由硬校验（R03）；明细不预填运单（R16）。
4. **保存结果**：生成计划单号（`AT`+`YYMMDD`+5 位流水），状态=待出库、明细空；**同步生成出库单**（待出库、明细空，1:1）；Toast「保存成功」→ 关闭弹窗 → 列表刷新定位「待出库」Tab。
5. **失败反馈**：缺仓/类型不符/同仓 → Toast「保存失败，请检查仓库选择」；同仓表单项「调入仓库不能与调出仓库相同」；网络异常 →「网络异常，请重试」。

### 页面分区

| 分区 | 要点 |
| --- | --- |
| 调出仓库 | 必填单选；限加盟揽收仓（R02）；展示 `代码(名称)` |
| 调入仓库 | 必填单选；不能与调出相同（R29） |
| 底部说明 | 建计划同时生成空出库单；明细由 PDA 装车或 PC 关联运单回写 |
| 底部操作 | **取消** / **确定** |

### 空单调拨·出库下推（本弹窗）

| 阶段 | 系统行为 |
| --- | --- |
| OMS 建计划（本弹窗） | 调拨计划待出库、明细空 + **同步生成**出库单（待出库、明细空） |
| PDA 装车暂存 | 关联运单至出库单；仍为待出库；箱库存→已占用 |
| PDA 装车锁定 | 出库单→已复核；调拨计划→已复核 |
| PC 关联运单 | 不变更状态；箱库存→已占用；须手动锁单 |
| PC 确认出库 | 出库单→已出库；库位库存实扣 |
| 调拨完结 | 调入仓常规入库全部收货后→调拨计划已完成 |
