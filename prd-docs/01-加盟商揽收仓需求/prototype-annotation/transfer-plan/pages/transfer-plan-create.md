## 需求描述：【新增弹窗 · 准入保存与仓库选择】

> 来源：调拨计划_Demo_新增页.md §2.1～§2.4；03-01-加盟商揽收仓管理后台主PRD.md §3.2、§3.4.4、§5.2、§6.1（R02/R03）、§6.4（R16）、R19、R29、§七；调拨计划单字段清单.md §一、§5.1、§5.2

### 页面模式

- **弹窗（Modal）**：列表页点击「新增」打开；字段仅调出/调入两仓，不做独立整页。
- 仅**新增**，本期无编辑页。保存后单据**类型=空单调拨**（后台落库；**页面不展示类型字段**）。**取消**关闭弹窗回到列表。**取消功能后期迭代**（字段清单 V1.5）。
- 调出仓库类型须为**加盟揽收仓**（R02）；保存后两仓锁定（R04/R22）。
- 建计划时**不**预生成待出库出库单；**PDA 装车**时生成/追加出库单（**已复核**）；**PC 确认出库**后出库单→**已出库**并实扣库存。
- 不生调入仓调拨入库单（R18/R26）；东莞常规入库由加盟商发车时现网自动推送；**调入仓库对应的常规入库单全部收货后，更新调拨计划为已完成**。

### 空单调拨·出库下推规则（原型标准需求）

| 阶段 | 系统行为 |
| --- | --- |
| OMS 建计划 | 仅生成调拨计划单（待出库、明细空）；**不下推**、**不预生成**出库单 |
| PDA 装车 | 生成/追加调出仓出库单→**已复核**；回写实装明细；**占用**库位库存（可多次追加） |
| PC 确认出库 | 出库单→**已出库**；库位库存**实扣**；调拨计划→**已出库** |
| 调入仓入库 | 不生调拨入库单（R18/R26）；东莞常规入库由加盟商发车时现网自动推送 |
| 调拨完结 | **调入仓库对应的常规入库单全部收货后，更新调拨计划为已完成** |

### 提交与结果

- 「**确定**」对应主 PRD §5.2 动作「新增」：校验调出仓库、调入仓库必填；**调出仓库≠调入仓库**（R29）；调出仓缺仓或类型不符则阻断。
- 不做仓到仓路由硬校验（R03）。明细由 PDA 装车扫描回写，创建时不预填运单（R16）。
- 成功：生成调拨计划单号（**沿用现网** `AT`+`YYMMDD`+5 位流水），状态=待出库，明细空；Toast「保存成功」；**关闭弹窗**；列表刷新并定位「待出库」Tab。
- 失败（缺仓/类型不符/同仓）：Toast「保存失败，请检查仓库选择」；同仓时表单项提示「调入仓库不能与调出仓库相同」。
- 网络异常：Toast「网络异常，请重试」。
- 「取消」/右上角 ×/遮罩：关闭弹窗，停留列表页。

### 调出/调入仓库

- 弹窗内**两列并排**展示调出/调入仓库；落库存**仓库代码**，界面展示 `仓库代码(仓库名称)`。
- 底部说明：「明细由 PDA 装车扫描回写，创建时不预填运单」。

| 字段 | 必填/可编辑 | 核心约束 |
| --- | --- | --- |
| 调出仓库 | 必填；单选 | 数据来源仓库档案；选项限加盟揽收仓（R02）；阻断提示「请选择调出仓库」 |
| 调入仓库 | 必填；单选 | 数据来源仓库档案；**不能与调出仓库相同**（R29）；不做仓到仓路由硬校验（R03）；阻断提示「请选择调入仓库」/「调入仓库不能与调出仓库相同」 |

### 权限与异常

- **按角色权限控制**（R16）：仅**总部作业部**可打开弹窗并确定；无权限时不展示「新增」；访问 `/order/TransferPlan/new` 重定向列表。

### 研发备注

- 底部 **取消 / 确定** 在弹窗 footer；`data-anno` 挂弹窗内容区 `transfer-plan-create-page`。
- 原型路由 `/order/TransferPlan/new` = 列表 + 弹窗打开。
- 装车扫描校验（拆票、多托顺序等）见 PDA 装车标注 **A1**，不在本弹窗展开。
