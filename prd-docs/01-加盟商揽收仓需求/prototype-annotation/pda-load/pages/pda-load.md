> 来源：04-07-装车_Demo.md §1；03-02-加盟商揽收仓PDA主PRD.md §十三

## 需求描述：【装车计划列表】

> 来源：04-07-装车_Demo.md §2.2；03-02-加盟商揽收仓PDA主PRD.md §十三、§7.1

### 业务定义

- 路径 `/pda/transfer/load`；菜单 `PDA → 出库管理 → 装车`。
- 仅展示**状态=待出库**且**调出仓库**命中本仓的**空单调拨**卡片；计划调拨不展开（R19）。
- 数据范围：**调出仓库**或**调入仓库**命中本仓可见。

### 字段与状态

| 卡片区域 | 字段 | 展示 |
| --- | --- | --- |
| 主行 | 调拨计划单号 | 加粗 |
| 副行 | 调出仓库 → 调入仓库 | 箭头连接 |
| 汇总 | 汇总箱数 | `合计：N箱`；创建时空单为 0 |
| 角标 | 状态 | `待出库` Tag |
| 附加 | 出库单状态 | 非「未生成」时展示 Tag（如已复核） |

### 交互规则

- 点击卡片进入 `/pda/transfer/load/{调拨计划单号}`。
- 空状态：`暂无待出库调拨计划`。

### 研发备注

- 挂载点：`[data-anno='pda-load-list-page']`。

## 需求描述：【扫描区与校验】

> 来源：04-07-装车_Demo.md §3、§3.1；03-02-加盟商揽收仓PDA主PRD.md §5.2.3、§6.4

### 交互规则

| 规则 | 失败反馈 |
| --- | --- |
| 货物须在库位库存且已上架、**未被占用**（R20、S10） | Toast：`货物未上架或不在库` |
| 货物已被其他调拨占用 | Toast：`该货物已被占用` |
| 扫箱号带出对应托、关联整托（Q12） | 扫描成功后整托运单入明细 |
| 目的仓须与调入仓库一致（Q14） | Toast：`目的仓与调入仓库不一致` |
| 重复扫描同一运单 | Toast：`该运单已关联` |
| 不允许拆票（Q15） | 装车时拦截，见标注 5 |

- `ScanInput` placeholder：`请扫描箱号装车`；扫码自动校验。

- 挂载点：`[data-anno='pda-load-work-scan']`。
- 可扫描箱号清单见补充标注 **A1**（按调拨计划单号区分）。

## 需求描述：【底部操作栏与装车确认】

> 来源：04-07-装车_Demo.md §6、§6.1–§6.2；03-02-加盟商揽收仓PDA主PRD.md §5.2.4、§十三

### 交互规则

| 按钮 | 展示条件 | 行为 |
| --- | --- | --- |
| 重置 | 待出库且已有扫描明细（未提交装车） | 清空本次未提交的扫描缓存 |
| 装车 | 待出库且已有扫描明细 | 打开**司机信息弹窗**（见标注 6），维护后二次确认装车 |

- **不展示**：取消、修改调出/调入仓库、打印装车清单（Q17）。
- 二次确认标题 `确认装车`；文案：`确认装车？将生成/更新出库单（已复核），并占用库位库存；待 PC 确认出库后实扣`。
- 装车成功 Toast：`装车成功，已占用库存`；返回列表。
- 拆票拦截 Toast：`须整票装车，不可拆票装车`。

### 结果处理

- 装车生成/追加出库单（**已复核**）；调拨计划→**已复核**；**占用**库位库存。

### 研发备注

- Demo PRD §6 原写「司机/电话/车牌已填」才展示装车按钮；**原型已调整为**有明细即可点装车、弹窗内维护司机信息（Demo PRD §2.1 内联区已收起，**待确认**是否回写 Demo）。
- 挂载点：`[data-anno='pda-load-work-bottom']`。
