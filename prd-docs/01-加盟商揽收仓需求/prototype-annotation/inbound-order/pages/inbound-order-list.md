## 需求描述：【收货订单列表】

> 来源：03-01 §5.1、§6.2（R05/R06/R11）；02-01 收货订单字段清单 §5.1；04-01 收货订单 Demo §1.1、§1.4

### 页面入口

- 管理后台 → **订单管理 → 收货订单**
- 路径 `/order/Inbound`

### 改动逻辑

1. **上游落单**：收货订单**仅由上游速达发车推送生成**，后台无手工新增（R05）；按**运单号 1:1**落单，初始**待收货**，**预报库存 + 预报箱数**（R11）；生成收货单号 `IB`+日期+5 位流水。
2. **重复与取消**：同一运单号存在未取消有效单时重复发车**拒绝**（R06）；已取消单可重新发车，全量覆盖回待收货（R07）。
3. **状态推进（加盟路径）**：待收货 → 已绑托 → 已上架；绑托回写收货箱数/收货人/收货时间/收货仓库；**不回写**收货重量/体积。
4. **列表模式**：只读查看 + 筛选；无新建/编辑/取消/改预报/直改状态；工具条**无「新增」**；UI 与筛选项**沿用现网**。
5. **权限与异常**：数据权限沿用现网；推送报文缺失或重复运单由接口拒绝。

### 页面分区

| 分区 | 要点 |
| --- | --- |
| 工具条 | **无「新增」**；取消/重发由上游触发 |
| 列表 | 推送成功后立即可见；默认**创建时间升序**；含「全部」「待收货」Tab |
| 筛选项 | 沿用现网（含入库类型过滤） |
