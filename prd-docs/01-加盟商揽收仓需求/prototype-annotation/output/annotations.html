[inbound-order:1] 页面全局 · 上游发车推送落单

inbound-order

需求描述：【页面全局 · 上游发车推送落单】

来源：03-01-加盟商揽收仓管理后台主PRD.md §5.1、§6.2（R05/R06/R11）；02-01-收货订单-入库单字段清单.md §5.1；04-01-收货订单_Demo_列表页.md §1.1、§1.4

业务定义（本次增量）

  • 收货订单仅由上游速达发车推送生成，管理后台不提供手工新增入口（Out of Scope / R05）。
  • 上游点击发车后，WMS 接收报文并按运单号 1:1落单；初始状态=待收货；预报库存 +预报箱数（R11）。
  • 落单时系统生成收货单号（IB+年月日+5 位流水号），写入上游快照字段。
  • 同一运单号存在未取消有效单时，重复发车拒绝（R06/S09）；已取消单可重新发车，全量覆盖回待收货（R07）。
  • 加盟路径状态推进：待收货 → 已绑托 → 已上架（绑托完成回写收货箱数/收货人/收货时间/收货仓库；不回写收货重量/体积）。

页面模式

  • 列表页为只读查看 + 筛选，无新建、编辑、取消、改预报、直改状态等写操作。
  • 工具条无「新增」按钮；取消/重发由上游接口触发，列表不提供对应入口。
  • 列表 UI、筛选项、入库类型过滤等沿用现网（见 Demo §1.2、§1.3）。

交互规则

  • 推送成功后，新单在列表立即可见（含「全部」「待收货」Tab），默认排序按创建时间升序。
  • 运单号命名、客户代码必填、常规入库菜单范围等规则沿用现网，不作为本次改造项。

权限与异常

  • 数据权限沿用现网。
  • 推送报文必填缺失或重复运单时，接口层拒绝；列表页无额外写操作反馈。

研发备注

  • 推送接口字段映射见字段清单 §七；报文格式/幂等见业务流程推演 TQ03，不在本标注展开。

[transfer-plan:1] 查询区、表格与分页

transfer-plan

需求描述：【查询区、表格与分页】

来源：调拨计划_Demo_列表页.md §1.1、§1.3、§1.5、§1.6、§1.7；调拨计划单字段清单.md §一、§三、§四、§5.5（V1.6）；03-01-加盟商揽收仓管理后台主PRD.md §3.2、§七（V1.5）

业务定义

  • 沿用现网菜单 订单管理 → 调拨计划；调拨计划需新增类型：现有通过上游推送的均为计划调拨；手工创建的为空单调拨；页面不需展示该类型（主 PRD §3.2；字段清单 §5.5）。
  • 数据权限沿用现网：账号可用仓库命中调出仓库或调入仓库即可查看；列表/Tab 同时含计划调拨与空单调拨，不提供按类型筛选或拆菜单。
  • 本期后台增量（总部手工新增空单、PDA 装车发车）仅作用于空单调拨（调出仓类型=加盟揽收仓）；计划调拨的创建、编辑、下推、PDA 复核/装柜沿用现网，不在本标注展开。
  • 默认排序按创建时间升序（字段清单 §5.5）。
  • 调拨计划单号、列表数量列（汇总箱数/重量/体积）、明细运单号/箱数命名、查询区与表格布局等沿用现网。
  • 明细字段不进主列表；运单号仅作筛选（按明细运单号反查所属计划单）。
  • 取消：后期迭代（主 PRD Out of Scope / R17 预留）；本期列表无取消操作；已取消仅通过 Tab 筛选预留态或历史数据。

交互规则

  • 行勾选、行展开：不支持。
  • 列宽拖拽：支持。固定列：调拨计划单号左固定，操作右固定。
  • 分页：默认每页 20，可切换 20 / 50 / 100。
  • 空值：无数据展示 -；汇总无明细为 0。
  • 查看：跳转 /order/TransferPlan/{调拨计划单号}；各状态均仅「查看」。
  • 列表不提供：取消（后期迭代）、PDA 发车、调入仓收货完成（系统）、编辑页入口。

字段与状态

字段/状态必填/可编辑核心约束
调拨计划单号（筛）可筛精确匹配；placeholder：调拨计划单号
运单号（筛）可筛精确匹配；按明细运单号反查计划单
调出仓库（筛）可筛多选；展示 仓库代码(仓库名称)
调入仓库（筛）可筛多选；规格同调出仓库
调拨计划单号（列）只读链接色；沿用现网单号规则（AT+YYMMDD+5 位流水）
调出/调入仓库（列）只读仓库代码(仓库名称)
箱数 / 重量 / 体积（列）只读沿用现网列表逻辑；对应汇总箱数 / 汇总重量 / 汇总体积；无明细为 0
状态（列）只读Tag：待出库蓝、已出库橙、已完成绿、已取消灰
创建时间（列）只读YYYY-MM-DD HH:mm:ss
最后修改时间（列）只读YYYY-MM-DD HH:mm:ss
操作只读查看
调拨类型（计划调拨 / 空单调拨）：后台区分；上游推送=计划调拨，手工新增=空单调拨；列表不展示、不可筛。

权限与异常

  • 新增：按角色权限控制（R16）；仅总部作业部展示工具条「新增」，仅用于创建加盟揽收仓空单。
  • 列表空态：「暂无数据」。
  • 加载失败：Toast「加载失败，请重试」。

研发备注

  • 查询区、表格、分页尚无独立 data-anno，本块暂挂页面根 [data-anno='transfer-plan-list-page']。
  • 列表列序、列宽：字段清单 §六 待确认。
  • 「最后修改时间」列表是否展示：字段清单 §四 待确认（Demo §1.5 已列出）。

[transfer-plan:4] 新增弹窗 · 准入保存与仓库

transfer-plan

需求描述：【新增弹窗 · 准入保存与仓库选择】

来源：调拨计划_Demo_新增页.md §2.1～§2.4；03-01-加盟商揽收仓管理后台主PRD.md §3.2、§5.2、§6.1（R02/R03）、§6.4（R16）、R29、§七；调拨计划单字段清单.md §一、§5.1、§5.2

页面模式

  • 弹窗（Modal）：列表页点击「新增」打开；字段仅调出/调入两仓，不做独立整页。
  • 仅新增，本期无编辑页。保存后单据类型=空单调拨（后台落库；页面不展示类型字段）。取消关闭弹窗回到列表。取消功能后期迭代（字段清单 V1.5）。
  • 新增表单不展示调拨计划单号、状态、调拨类型、调拨明细、汇总（创建时空单）。
  • 调出仓库类型须为加盟揽收仓（R02）；保存后两仓锁定（R04/R22）。
  • 建计划时不预生成待出库出库单；发车时才生成出库单并下推调入仓入库单（主 PRD §3.2 PDA 路径）。

提交与结果

  • 「确定」对应主 PRD §5.2 动作「新增」：校验调出仓库、调入仓库必填；调出仓库≠调入仓库（R29）；调出仓缺仓或类型不符则阻断。
  • 不做仓到仓路由硬校验（R03）。明细由 PDA 装车扫描回写，创建时不预填运单（R16）。
  • 成功：生成调拨计划单号（沿用现网 AT+YYMMDD+5 位流水），状态=待出库，明细空；Toast「保存成功」；关闭弹窗；列表刷新并定位「待出库」Tab。
  • 失败（缺仓/类型不符/同仓）：Toast「保存失败，请检查仓库选择」；同仓时表单项提示「调入仓库不能与调出仓库相同」。
  • 网络异常：Toast「网络异常，请重试」。
  • 「取消」/右上角 ×/遮罩：关闭弹窗，停留列表页。

调出/调入仓库

  • 弹窗内两列并排展示调出/调入仓库；落库存仓库代码，界面展示 仓库代码(仓库名称)。
  • 底部说明：「明细由 PDA 装车扫描回写，创建时不预填运单」。
字段必填/可编辑核心约束
调出仓库必填；单选数据来源仓库档案；选项限加盟揽收仓（R02）；阻断提示「请选择调出仓库」
调入仓库必填；单选数据来源仓库档案；不能与调出仓库相同（R29）；不做仓到仓路由硬校验（R03）；阻断提示「请选择调入仓库」/「调入仓库不能与调出仓库相同」

权限与异常

  • 按角色权限控制（R16）：仅总部作业部可打开弹窗并确定；无权限时不展示「新增」；访问 /order/TransferPlan/new 重定向列表。

研发备注

  • 底部 取消 / 确定 在弹窗 footer；data-anno 挂弹窗内容区 transfer-plan-create-page。
  • 原型路由 /order/TransferPlan/new = 列表 + 弹窗打开。
  • 发车时目的仓与调入仓库不一致则拦截：属于 PDA 装车，不在本弹窗展开（字段清单 §一 调入仓库备注）。
