[inbound-order:0] 收货订单列表

inbound-order

需求描述：【收货订单列表】

来源：03-01 §5.1、§6.2（R05/R06/R11）；02-01 收货订单字段清单 §5.1；04-01 收货订单 Demo §1.1、§1.4

页面入口

  • 管理后台 → 订单管理 → 收货订单
  • 路径 /order/Inbound

改动逻辑

  1. 上游落单：收货订单仅由上游速达发车推送生成，后台无手工新增（R05）；按运单号 1:1落单，初始待收货，预报库存 + 预报箱数（R11）；生成收货单号 IB+日期+5 位流水。
  2. 重复与取消：同一运单号存在未取消有效单时重复发车拒绝（R06）；已取消单可重新发车，全量覆盖回待收货（R07）。
  3. 状态推进（加盟路径）：待收货 → 已绑托 → 已上架；绑托回写收货箱数/收货人/收货时间/收货仓库；不回写收货重量/体积。
  4. 列表模式：只读查看 + 筛选；无新建/编辑/取消/改预报/直改状态；工具条无「新增」；UI 与筛选项沿用现网。
  5. 权限与异常：数据权限沿用现网；推送报文缺失或重复运单由接口拒绝。

页面分区

分区要点
工具条无「新增」；取消/重发由上游触发
列表推送成功后立即可见；默认创建时间升序；含「全部」「待收货」Tab
筛选项沿用现网（含入库类型过滤）

transfer-plan

需求描述：【调拨计划新增弹窗】

来源：04-03 调拨计划 Demo §2.1～§2.4；03-01 §3.2、§3.4.4、§5.2、§6.1（R02/R03/R16）、§6.4、R19、R29；02-02 调拨计划单字段清单 §一、§5.1、§5.2

页面入口

  • 调拨计划列表 → 工具条「新增」（仅总部作业部）
  • 或路径 /order/TransferPlan/new（无权限重定向列表）

改动逻辑

  1. 弹窗模式：列表点击「新增」打开 Modal；仅调出/调入两仓；仅新增无编辑；保存后类型=空单调拨（页面不展示类型）；取消关闭回列表。
  2. 前置条件：仅总部作业部可打开并确定；调出仓类型须为加盟揽收仓（R02）；保存后两仓锁定（R04/R22）。
  3. 保存规则：「确定」= 动作「新增」；调出/调入仓库必填；调出≠调入（R29）；不做仓到仓路由硬校验（R03）；明细不预填运单（R16）。

  5. 失败反馈：缺仓/类型不符/同仓 → Toast「保存失败，请检查仓库选择」；同仓表单项「调入仓库不能与调出仓库相同」；网络异常 →「网络异常，请重试」。

[pda-sorting:0] 分货绑托页

pda-sorting

需求描述：【分货绑托页】

来源：03-02 §十二、§6.1（R33/R37–R47）；04-05 分货 Demo §3–§8

页面入口

  • PDA → 入库管理 → 分货
  • 路径 /pda/inbound/sorting

改动逻辑

  1. 票型规则：预报箱数 ≤ M 为小票，> M 为大票（R37）；M/P 由后台按加盟揽收仓配置，未配置则阻断（R48）。
  2. 绑托原则：无系统满托容量；操作员判断托满后点「托满」（R40）；不存在部分绑托状态；全部箱绑完→已绑托并生成上架单（R33/R43）；绑托阶段无库存变动。
  3. 小票逻辑：同票同托；多票可混一托（≤P）；须扫齐全箱方可绑托（R45）；混托托满生成一张上架单含全部运单。
  4. 大票逻辑：同托同票不可混托（R38）；可拆多托、允许部分箱绑托；全部箱绑完才已绑托并生成上架单。
  5. 作业托数 N：进入先弹窗确认 N（1–99，默认 5），不可跳过（R41）；N=1 单托单分，N>1 多托同分；写入 sessionStorage。

页面分区

分区要点
作业托数弹窗确认 N 后预生成 N 个托位；顶栏只读展示 作业托数 N
扫描区ScanInput 置顶；扫码自动校验；失败 Toast 见 Demo §4.1；成功后弹出落托确认
落托确认弹窗标题「落托确认」；展示箱号、运单号、进入托序号；扫描键等同确认（R46）
托列表N 个托卡片；嵌套箱明细；当前扫描箱高亮；每格「托满」触发确认绑托
绑托反馈小票未扫齐→「小票须扫齐全部箱方可绑托」；件数不一致→协调上游弹窗；成功 Toast「绑托成功」

需求描述：【上架页】

改动逻辑

  1. 上架校验：加盟揽收仓不收货测量可上架；其他仓库须收货测量后才可上架。
  2. 适用范围（本 Demo）：加盟揽收仓路径；非加盟揽收仓走现网，不在本 Demo。

  5. 库位规则（F-02）：仅可选备货库位；运单首托未上架可选手动库位；已有托上架则取首托库位自动带出禁止编辑。
  6. 确认上架：当前焦点托已选库位后展示按钮；当前托全部箱→已上架，托上全部运单同步完成；跨库位不一致时 Modal.confirm 二次确认。

需求描述：【关联运单页】

来源：04-09-出库-关联运单.md；03-01 §5.3、R14/R20/R22/R50；02-04 出库单字段清单；04-08 §1.5.3

页面入口

  • 出库列表 → 空单调拨行「更多」→ 关联运单
  • 路径 /order/Outbound/{出库单号}/link-waybill
  • 待出库/已复核 · 空单调拨可进入；已出库整页阻断

改动逻辑

  1. PDA 无法扫描时的 PC 兜底
  2. 前置条件：待出库或已复核状态可点击「关联运单」；已出库或已锁单后不显示此按钮。
  3. 保存规则：保存时校验可用库存（R14）——当前仓库须有所选运单的可用库存；箱库存=已占用或查不到该仓库库存，均视为不可用。保存后状态不变，仅建关联并将箱库存→已占用；须再到调拨详情手动锁单。

页面分区

分区要点
出库单信息两行只读：计划号+状态；柜号、司机、电话、车牌
选择运单按钮打开弹窗；候选=已上架库存；支持运单号精确/多号搜索
选择运单弹窗整票勾选表格（运单号、客户代码、箱数、重量、体积）；确定写入待保存预览
运单明细只读表：历史+待保存合并；空态「暂无关联运单」
底部操作取消返回列表；确定提交关联

空单调拨·出库下推（本页）

阶段系统行为
OMS 建计划同步生成空出库单（待出库、明细空）
PDA 装车暂存关联运单；仍为待出库；箱库存→已占用
PC 关联运单整票关联；状态不变；箱库存→已占用；须手动锁单
装车锁定/手动锁单出库单→已复核
PC 确认出库出库单→已出库；库位库存实扣
