## 需求描述：【关联运单页总览】

> 来源：04-09-出库-关联运单.md §2.1、§2.7；03-01-加盟商揽收仓管理后台主PRD.md §5.3、R14、R50；04-08-出库列表页.md §1.5.3

### 页面入口

- 管理后台 → **出库管理 → 出库列表** → 空单调拨行「**更多**」→ **关联运单**
- 路径 `/order/Outbound/{出库单号}/link-waybill`
- **待出库 · 空单调拨**、**已复核 · 空单调拨** 可进入；**已出库** 不可进入本页

### 页面模式

- **PC 关联运单**兜底页：PDA 无法扫描时，手动勾选**整票运单**关联至该**空出库单**（或已有明细的出库单追加）。
- 适用出库单状态：**待出库** 或 **已复核**；**已出库** 整页阻断（Result 403）。
- 头部字段、状态 Tag **全部只读**；**不可**通过本页修改出库单状态（R22、R50）。
- **已复核** 状态仍可追加关联运单（§3.4.3-6，主 PRD §5.3）。

### 提交边界

- 底部「**确定**」触发主 PRD §5.3 动作 **PC 关联运单**；须有**待保存**的新勾选运单，否则按钮 **disabled**。
- 提交前校验**可用库存**（R14）；不足则拒绝。
- 保存后：**仅**建立运单与出库单关联并回写明细；**箱库存→已占用**；**出库单状态不变**（待出库仍为待出库，已复核仍为已复核）；**不变更调拨单状态**（R50）。
- 保存成功后须再到**调拨计划详情**执行 **手动锁单**（现网）→ 出库单 **已复核**。

### 结果处理

- 保存成功：Toast `关联成功`；**状态 Tag 不变**；清空待保存清单并刷新明细（原型停留本页）。
- 保存失败：Toast 服务端原因，默认 `保存失败`。

### 离开处理

- 「取消」/页头返回：跳转 `/order/Outbound`；有未保存勾选时 `Modal.confirm`「放弃未保存的关联？」。

### 空单调拨·出库下推规则（本页相关）

| 阶段 | 系统行为 |
| --- | --- |
| OMS 建计划 | **同时生成**空出库单（**待出库**、明细空）；**1 计划 : 1 出库单** |
| PDA 装车暂存 | 关联运单至出库单；**仍为待出库**；**箱库存→已占用** |
| **PC 关联运单（本页）** | 整票关联；**不变更出库单/调拨单状态**；**箱库存→已占用**；须再**手动锁单** |
| PDA 装车锁定 / PC 手动锁单 | 出库单→**已复核** |
| PC 确认出库 | 出库单→**已出库**；库位库存实扣 |

### 子模块标注

| 角标 | 模块 | 挂载点 |
| --- | --- | --- |
| 1 | 出库单信息 | `outbound-link-waybill-header` |
| 2 | 选择运单入口 | `outbound-link-waybill-select` |
| 3 | 选择运单弹窗 | `outbound-link-waybill-select-modal`（弹窗打开时） |
| 4 | 运单明细表 | `outbound-link-waybill-lines` |
| 5 | 底部取消与确定 | `outbound-link-waybill-actions` |

### 研发备注

- 挂载点：`[data-anno='outbound-link-waybill-page']`。
- **不展示**：确认出库、打印装柜单（在列表或调拨详情）；手动锁单（在调拨计划详情）。

## 需求描述：【出库单信息（只读头）】

> 来源：04-09-出库-关联运单.md §2.3；02-04-出库单字段清单.md §一

### 业务定义

- 卡片标题：**出库单信息**；桌面端栅格 **3 列**；**全部 ReadonlyText**，不可编辑。
- **不展示**：字段清单「暂不含」项（调入仓库、装车人、发运时间等）。

### 字段与状态

| 字段 | 必填/可编辑 | 核心约束 |
| --- | --- | --- |
| 出库单号 | 只读 | 单据主键 |
| 计划单号 | 只读 | 系统带出 |
| 调拨计划单号 | 只读 | 可链至调拨计划详情 |
| 归属仓库 | 只读 | `仓库代码(仓库名称)` |
| 状态 | 只读 | Tag：**待出库** / **已复核** / **已出库**；**不可下拉修改** |
| 司机 | 只读 | PDA **装车锁定**回写；空时 `-` |
| 车牌号 | 只读 | 同上 |
| 电话 | 只读 | 同上 |

## 需求描述：【选择运单入口】

> 来源：04-09-出库-关联运单.md §2.4 主页面；03-01-加盟商揽收仓管理后台主PRD.md §3.4.3、R20

### 业务定义

- 卡片标题：**选择运单**；主页面仅展示「**选择运单**」主按钮 + 已选提示。
- 关联对象须为**库位库存中已上架**货物对应运单（与 PDA 装车同源）。
- **不允许拆票装车**（R20）：勾选粒度为**整票运单**，须整票关联。
- 展示条件：出库单=**待出库**或**已复核**；**已出库**隐藏本区域。

### 交互规则

| 元素 | 行为 |
| --- | --- |
| 选择运单 | 打开选择运单弹窗（角标 **3**） |
| 已选提示 | 弹窗确认后展示 `已选 N 票（待保存）`；0 票不展示 |

### 研发备注

- 挂载点：`[data-anno='outbound-link-waybill-select']`。

## 需求描述：【选择运单弹窗】

> 来源：04-09-出库-关联运单.md §2.4 选择运单弹窗、可选运单表格列；03-01-加盟商揽收仓管理后台主PRD.md R14、R20

### 业务定义

- Modal 标题：**选择运单**；内嵌运单号筛选 + 可选运单表格 + 底部取消/确定。
- 候选运单来自库位库存**已上架**货物；每行一票，**整票勾选**。
- **已保存**的历史关联运单：勾选且**不可取消**（本期不展开移除规则）。

### 字段与状态

| 元素 | 必填/可编辑 | 核心约束 |
| --- | --- | --- |
| 运单号 | 可输入 | 精确搜索；多个运单号用逗号或空格隔开；placeholder `运单号,多个用逗号或空格隔开` |
| 查询 | 可点击 | 刷新弹窗内列表 |
| 运单表格 | 行勾选 | 列：运单号、客户代码、箱数、重量(KG)、体积(CBM) |
| 确定 | 可点击 | 写入待保存预览；未选新运单 Toast `请至少选择一票运单` |
| 取消 | 可点击 | 关闭弹窗，不改动待保存清单 |

### 交互规则

- 弹窗内查询、勾选 →「确定」→ 同步加入运单明细待保存预览（角标 **4**）。
- 弹窗内取消勾选新票 → 确定后从待保存清单移除（历史已保存关联不可取消）。
- 库存被占用：行不可选；强行勾选时 Toast `可用库存不足`。

### 研发备注

- 挂载点：`[data-anno='outbound-link-waybill-select-modal']`；须在弹窗打开后验证角标。

## 需求描述：【底部取消与确定】

> 来源：04-09-出库-关联运单.md §2.6；03-01-加盟商揽收仓管理后台主PRD.md §5.3、R14、R50

### 业务定义

- 固定底部操作栏：`fixed bottom`；按钮顺序 **取消**（次）　**确定**（主）。
- **不展示**：确认出库、打印装柜单、手动锁单。

### 交互规则

| 按钮 | 展示条件 | 行为 |
| --- | --- | --- |
| 取消 | 常驻 | 返回 `/order/Outbound`；有未保存勾选二次确认 |
| 确定 | 出库单=**待出库**或**已复核** | 触发 **PC 关联运单**；无待保存变更 **disabled** |

### 保存校验与反馈

| 场景 | 反馈 |
| --- | --- |
| 未选运单 | Toast：`请至少选择一票运单` |
| 可用库存不足 | Toast：`可用库存不足` |
| 保存成功 | Toast：`关联成功`；**状态 Tag 不变** |
| 保存失败 | Toast：默认 `保存失败` |

### 研发备注

- 挂载点：`[data-anno='outbound-link-waybill-actions']`。
