## 需求描述：【关联运单页】

> 来源：04-09-出库-关联运单.md；03-01 §5.3、R14/R20/R22/R50；02-04 出库单字段清单；04-08 §1.5.3

### 页面入口

- 出库列表 → 空单调拨行「更多」→ **关联运单**
- 路径 `/order/Outbound/{出库单号}/link-waybill`
- **待出库/已复核 · 空单调拨**可进入；**已出库**整页阻断

### 改动逻辑

1. **PDA 无法扫描时的 PC 兜底**
2. **前置条件**：待出库或已复核状态可点击「关联运单」；**已出库**或**已锁单**后不显示此按钮。
3. **保存规则**：保存时校验可用库存（R14）——当前仓库须有所选运单的可用库存；**箱库存=已占用**或**查不到该仓库库存**，均视为不可用。保存后状态不变，仅建关联并将箱库存→已占用；须再到调拨详情手动锁单。
4. **候选范围**：弹窗仅展示**收货仓库=当前仓库**（出库单归属仓库）的已上架运单。

### 页面分区

| 分区 | 要点 |
| --- | --- |
| 出库单信息 | 两行只读：计划号+状态；柜号、电话、车牌 |
| 选择运单 | 按钮打开弹窗；候选=已上架库存且**收货仓库=当前仓库**；支持运单号精确/多号搜索 |
| 选择运单弹窗 | 整票勾选表格（运单号、客户代码、箱数、重量、体积）；确定写入待保存预览 |
| 出库明细 | 对齐现网汇总条 + 扩展列明细表；**不展示操作日志** |
| 底部操作 | 取消返回列表；确定提交关联 |

### 空单调拨·出库下推（本页）

| 阶段 | 系统行为 |
| --- | --- |
| OMS 建计划 | 同步生成空出库单（待出库、明细空） |
| PDA 装车暂存 | 关联运单；仍为待出库；箱库存→已占用 |
| **PC 关联运单** | 整票关联；状态不变；箱库存→已占用；须手动锁单 |
| 装车锁定/手动锁单 | 出库单→已复核 |
| PC 确认出库 | 出库单→已出库；库位库存实扣 |
