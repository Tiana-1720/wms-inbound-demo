# 调拨计划_Demo_新增/编辑页

> **字段定义**：字段枚举值、计算规则、必填性等见《调拨计划单字段清单》，本文件只写页面呈现规则，严禁重复定义。
> **动作与状态**：状态机、字段锁定见《加盟商揽收仓管理后台主PRD》§5.2、§6.5（R04/R22）；本文件只翻译为页面显隐，不新增动作。
> **版本**：V1.0 | 2026-08-31

## 2.1 页面概述

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 调拨计划新增 / 编辑 |
| 页面目标 | 总部创建空单调拨计划（仅选调出/调入仓）；编辑态查看已建计划信息并在待出库无明细时作废 |
| 新增路径 | `/order/TransferPlan/new` |

## 2.2 新增态与编辑态差异

| 维度 | 新增态 | 编辑态 |
| :--- | :--- | :--- |
| 入口 | 列表页「新增」 | 详情页或列表（本模块**无独立「编辑」行操作**；编辑页主要用于创建后回看或路由直达） |
| 调拨计划单号 | 不展示 | 只读展示（保存后系统生成，字段清单） |
| 状态 | 不展示 | 只读 Tag 展示 |
| 调出仓库 / 调入仓库 | 可编辑 | 只读（创建后锁定，R04） |
| 调拨明细 | 不展示空表格；卡片展示空态「明细由 PDA 装车扫描回写，创建时不预填」 | 只读表格；无明细时空态同上 |
| 汇总区 | 不展示（空单无汇总） | 只读；明细为空时展示 `0` / `-` |
| 底部「保存」 | 展示 | **不展示**（待出库无业务字段可改，字段清单 §5.2） |
| 底部「作废」 | 不展示 | 仅**待出库且明细无运单**时展示（主 PRD §5.2） |

## 2.3 固定底部操作栏

| 元素 | 规格 |
| :--- | :--- |
| 位置 | `fixed bottom-0 right-0` |
| 新增态按钮（从左到右） | `返回列表`（次操作）　`保存`（主操作） |
| 编辑态按钮（从左到右） | `返回列表`（次操作）　`作废`（危险操作，仅待出库无明细时展示） |

**保存行为**（新增态，对应主 PRD §5.2 动作「新增」）：

- 校验调出仓库、调入仓库必填
- 调出仓库类型须为加盟揽收仓（R02）；缺仓或类型不符则阻断
- 保存成功：生成调拨计划单号，状态=待出库，明细空；Toast「保存成功」；跳转列表页并定位「待出库」Tab

**作废行为**（编辑态，对应主 PRD §5.2 动作「作废」）：

- 二次确认弹窗（文案同列表页 §1.6）
- 成功：状态 → 已取消；Toast「作废成功」；跳转列表页

> 主 PRD §5.2 另有「编辑备注」动作，但字段清单明确**备注暂不收录**（§5.6），本页**不提供备注输入**，编辑态无可保存的业务字段。

## 2.4 头部信息卡片

卡片标题：**基本信息**。布局：栅格（桌面端 4 列）。

| 字段 | 新增态 | 编辑态 | 控件类型 | 详细规格 |
| :--- | :--- | :--- | :--- | :--- |
| 调拨计划单号 | 不展示 | 只读 | `ReadonlyText` | 格式 `AT`+`YYMMDD`+5 位流水号 |
| 调出仓库 | 可编辑 * | 只读 | `SelectWithSearch` / `ReadonlyText` | 单选；数据来源仓库档案；展示 `仓库代码(仓库名称)`；落库仓库代码；选项限加盟揽收仓（R02） |
| 调入仓库 | 可编辑 * | 只读 | `SelectWithSearch` / `ReadonlyText` | 单选；数据来源仓库档案；展示 `仓库代码(仓库名称)`；不做仓到仓路由硬校验（R03） |
| 状态 | 不展示 | 只读 | `ReadonlyText` + Tag | 枚举：待出库 / 已出库 / 已完成 / 已取消 |

## 2.5 调拨明细卡片

卡片标题：**调拨明细**

> 明细字段均由 PDA 装车回写（R16）；新增/编辑页**不可手工增删改**明细行。

### 新增态

- 不渲染空明细表格
- 卡片内居中说明：「明细由 PDA 装车扫描回写，创建时不预填运单」

### 编辑态

只读表格，列来自字段清单明细区「详情展示=是」字段：

| 列名 | 控件类型 | 规格 |
| :--- | :--- | :--- |
| 序号 | `ReadonlyText` | 从 1 起 |
| 运单号 | `ReadonlyText` | 界面列名用运单号（R23） |
| 客户代码 | `ReadonlyText` | 快照只读 |
| 箱数 | `ReadonlyText` | 整数，≥1 |
| 重量 | `ReadonlyText` | KG，最多 2 位小数 |
| 体积 | `ReadonlyText` | CBM，保留 6 位小数 |

**空态**：无 PDA 回写时展示「暂无实装运单」。

## 2.6 汇总区（仅编辑态）

卡片标题：**汇总信息**（或嵌入明细卡片底部汇总行）

| 字段 | 控件类型 | 规格 |
| :--- | :--- | :--- |

## 2.9 权限（页面层）

- **新增 / 保存**：仅总部作业部（主 PRD §七 / R16）
- **作废**：总部作业部；待出库且无明细
- 其他角色无新增/作废入口；若直达 URL 则只读或拒绝
