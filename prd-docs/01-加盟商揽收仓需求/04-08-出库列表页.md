## 1.2 状态 Tab 栏

列表页主过滤入口。**沿用现网 Tab 全量**：

| Tab 标签 | 过滤逻辑 |
| :--- | :--- |
| 全部 | 展示所有状态（默认选中） |
| 待出库 | 状态 = **待出库** |
| 已下架 | 状态 = **已下架** |
| 已复核 | 状态 = **已复核** |
| 已出库 | 状态 = **已出库** |
| 已取消 | 状态 = **已取消** |

**Tab 交互规则**：

- 每个 Tab 右侧展示当前条件下的计数（格式：`Tab名 (N)`，超过 99 展示 `99+`，0 也展示）
- 切换 Tab 后列表刷新，页码重置为第 1 页
- **状态仅通过 Tab 过滤**；查询区**不提供状态下拉**

#### 状态 Tag 配色

| 状态 | 颜色语义 |
| :--- | :--- |
| 待出库 | 橙色 |
| 已下架 | 紫色 |
| 已复核 | 橙色 |
| 已出库 | 绿色 |
| 已取消 | 红色 |

#### 行内操作

行内操作使用**文字动作**。**不渲染 disabled 操作**。

| 状态 / 类型 | 展示的操作 | 说明 |
| :--- | :--- | :--- |
| 待出库 · **非空单调拨** | **生成下架作业** | 现网计划出库 / 计划调拨流程 |
| 待出库 · **空单调拨** | **更多** → **关联运单** | 加盟路径；**不展示**生成下架作业 |
| 已复核 · **空单调拨** | **更多** → **关联运单**、**打印装柜单**、**确认出库** | 加盟路径增量 |
| 已出库 / 已取消 / 其他 | — | 无操作或仅只读 |

**操作说明**：

| 操作 | 交互 |
| :--- | :--- |
| 生成下架作业 | 打开现网生成下架作业页（原型占位 Toast） |
| 关联运单 | 跳转《04-09-出库-关联运单》 |
| 打印装柜单 | 调用现网打印装柜单；**仅打印，不变库存** |
| 确认出库 | 二次确认弹窗（见 §1.6） |

## 1.6 二次确认弹窗规格

| 触发操作 | 弹窗标题 | 弹窗内容 | 确认按钮文案 | 取消按钮文案 |
| :--- | :--- | :--- | :--- | :--- |
| 确认出库 | 确认出库 | 确认后将扣减库位库存，出库单与调拨计划将变为**已出库**，且不可再装车。是否继续？ | **确认出库** | 取消 |

**校验失败反馈**（Toast，不弹窗）：

| 场景 | 文案 |
| :--- | :--- |
| 装柜单未打印 | `请先打印装柜单` |
| 出库单非已复核 | `当前状态不可确认出库` |
