## 五、展示与引用规则

### 5.1 状态与动作（禁止表单直改状态）

| 当前状态 | 动作 | 前置条件 | 结果状态 | 对本单字段的影响 |
| :--- | :--- | :--- | :--- | :--- |
| （无单） | 新增 | 调出仓库类型=加盟揽收仓；调出仓库、调入仓库必填；**调出≠调入**（R29） | 待出库 | 生成调拨计划单号；**调拨类型=空单调拨**；明细空；表单不展示状态与调拨类型 |
| 待出库 | PDA 发车 | 已扫实装 | 已出库 | 回写明细；后续本单只读 |
| 已出库 | 调入仓收货完成（系统） | 该计划下调拨入库单均已收货 | 已完成 | 对接回写，只读；后续绑托/上架不改本单状态 |
| 待出库 | 取消 | （**后期迭代**）明细无运单 | 已取消 | 全部只读；**本期无取消入口** |

### 5.2 字段锁定

- 创建后：**调出仓库**、**调入仓库**只读（R04/R22），落库存仓库代码
- 待出库：无业务字段可改
- 已出库 / 已完成 / 已取消：全部只读（R22）
- **状态**不可下拉修改

### 5.3 快照 / 实时 / 计算区分

| 类别 | 字段 | 说明 |
| :--- | :--- | :--- |
| 用户填写 | 调出仓库、调入仓库 | 创建时选仓，落库存仓库代码；创建后锁定 |
| 下游回写 | 明细.运单号、明细.箱数、明细.重量、明细.体积 | PDA 装车回写；箱数不允许为 0 |
| 系统带出并存储（快照） | 明细.客户代码 | 装车从收货订单带出并落在本单明细 |
| 系统计算（实时） | 汇总箱数、汇总重量、汇总体积 | 按明细加总；**列表展示汇总**，详情可展示 |
| 系统生成 | 调拨计划单号、**调拨类型**、状态、创建人/时间、最后修改人/时间 | 用户不可改；**调拨类型**页面不展示 |

### 5.4 下游引用与下推规则（按调拨类型分支）

> **实现原则**（主 PRD §3.4、§6.6 R24–R28）：后台按 **`调拨类型`** 路由下推引擎；**不按仓库单独配置下推时机**。两类调拨均在**同一触发点同批**生成出库单与调入仓入库单。

#### 5.4.1 计划调拨（沿用现网）

| 规则项 | 说明 |
| :--- | :--- |
| 类型判定 | 上游推送创建 → **计划调拨** |
| 下推触发 | ① 创建时计划内**全部运单已在调出仓收货** → 立即下推<br>② 否则等**全部运单在调出仓收货后** → 下推 |
| 下推产物 | **同批**生成：1 张调出仓出库单 + N 张调入仓入库单（1 运单 1 张） |
| 明细来源 | 上游推送 + 复制原收货订单 |
| 计划变更 | 增删运单、改两仓、运单/箱明细更新 → **同步更新**下游出库单与入库单 |
| PDA 路径 | 下架 → 复核 → 装柜（现网） |
| 本期改造 | **无** |

权威来源：`WMS_V1.0 260314` §调拨计划生成出库单/收货订单；主 PRD §3.4.2。

#### 5.4.2 空单调拨（本次增量）

| 规则项 | 说明 |
| :--- | :--- |
| 类型判定 | 总部手工新增 + 调出仓类型=加盟揽收仓 → **空单调拨** |
| 下推触发 | **仅 PDA 装车确认发车** |
| 建计划阶段 | **不**预生成出库单/调入仓入库单；明细空 |
| 下推产物 | **同批**生成：1 张调出仓出库单 + N 张调入仓入库单（按实装运单拆） |
| 明细来源 | PDA 装车扫描回写（扫库位库存中已上架货） |
| 计划变更 | 创建后两仓锁定；**不同步**下游 |
| PDA 路径 | 装车扫描 + 发车；**不进入**复核/装柜 |
| 集货仓库存 | 调入仓入库单**生成时**按**预报箱数**计**预报库存 +** |

发车后按主 PRD §3.4.4 生成下游单据，本单只被引用：

- 调出仓出库单：继承**调拨计划单号**；明细继承实装**运单号**、**客户代码**、**箱数**、**重量**、**体积**（出库单字段见出库单清单，本文不展开）
- 调入仓入库单：按实装运单各生成一张；**入库类型=调拨入库**；**预报仓库**=本单**调入仓库**；**收货仓库**空；**收货单号**新生成；实装箱数/重量/体积**写入预报列**；**生成时集货仓预报库存 +预报箱数**（主 PRD §3.4.4）

### 5.5 列表与权限

- **菜单与范围**：沿用现网「订单管理 → 调拨计划」；调拨计划新增**调拨类型**（上游推送=**计划调拨**，总部手工创建=**空单调拨**）；**页面不展示该类型**、不提供按类型筛选或拆菜单；数据权限沿用现网（调出或调入命中可见），列表/Tab 同时含两类调拨；**本期后台增量**（总部手工新增空单、PDA 装车发车）仅作用于**空单调拨**（调出仓=加盟揽收仓）；**计划调拨**创建/编辑/下推/PDA 复核装柜**沿用现网**；状态沿用现网三态 + **预留已取消**（Tab 保留，**本期无取消入口**）
- **默认排序**：按创建时间升序（现网表格 11）
- **筛选**：沿用现网表格 11（运单号/调拨计划号精确搜索；调入仓库、调出仓库多选，显示 `仓库代码(仓库名称)`）。**状态仅通过 Tab 过滤，查询区不提供**
- 列表优先列：调拨计划单号、调出仓库、调入仓库、**汇总箱数/汇总重量/汇总体积**、状态、创建时间。**明细字段不进主列表**。**列序、列宽待定**
- 数据权限沿用现网：账号可用仓库命中**调出仓库或调入仓库**即可查看（主 PRD §七）
- 重量最多 2 位小数，体积保留 6 位小数（现网表格 19）

### 5.6 明确不纳入本单的字段

- 计划发运时间、发运时间
- **备注**、**司机/司机电话/车牌号**（现网表格 13 有；空单不收录；若装车需采集，落出库单，见出库单粗纲）
- **调拨策略**：不在本清单落字段（按调出仓库类型带出，见主 PRD R02）
- 出库单号、归属仓库、入库类型、收货单号、预报仓库、收货仓库（下游或收货订单字段）
- 托号、箱号、初始/目标库位（上架/装车执行层）
