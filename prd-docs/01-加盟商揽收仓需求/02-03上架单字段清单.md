# 上架单字段清单

> **当前版本**：粗纲版。仅用于主 PRD 编写前统一字段命名，后续会基于主 PRD 规则补全完整维度。  
> **规则来源**：`context/01-业务背景与介绍.md`、`01-业务流程推演.md`  
> **单据关系**：**一入库单对应一运单**；上架单通过运单号关联共用表；**无明细行，字段均为头部字段**。

---

## 一、头部字段粗纲

| 字段名称 | 类型 | 来源 | 备注 |
| :--- | :--- | :--- | :--- |
| 作业单号 | 文本 | 系统生成 | 单据主键 |
| 作业类型 | 枚举 | 系统生成 | 本期=上架 |
| 运单号 | 文本 | 系统带出并存储 | 关联入库单共用表；**一运单一入库单** |
| 托号 | 文本 | 系统带出并存储 | 继承绑托结果 |
| 初始库位 | 引用 | 系统带出并存储 | 上架前暂存库位 |
| 目标库位 | 引用 | 用户选择 | 揽收仓备货库位；Q10 操作员人工选择 |
| 件数 | 数字 | 下游回写 | 实际上架件数/箱数 |

## 四、字段说明

| 字段 | 作用 |
| :--- | :--- |
| **作业单号** | 上架作业单主键 |
| **作业类型** | 本期=上架 |
| **运单号** | 关联入库单共用表；收货仓库等同表获取 |
| **托号** | 待上架托盘 |
| **初始库位** | 上架前货物暂存库位 |
| **目标库位** | 揽收仓备货库位；PDA **人工选择**（Q10）；确认后**库位库存 +** |
| **件数** | 该作业实际上架件数/箱数 |

> 上架至**揽收仓备货库位**，不是 TMS 预报中的目的仓库；不含目的仓库、收货单号。
