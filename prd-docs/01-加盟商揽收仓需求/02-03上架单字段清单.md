# 上架单字段清单

> **当前版本**：定稿版。字段定义以本文档为准，主 PRD 和 Demo PRD 只引用，不重复定义字段全集。
> **文档定位**：加盟揽收仓 **上架单**（PDA 上架作业单）字段的唯一定义来源。
> **单据关系**：**一运单一张上架单**（1:1 对应入库单共用表记录）；通过**运单号**关联收货订单/入库单；**绑托完成时系统自动生成**（PDA 主 PRD §3.2、§5.3、R33–R34）。
> **引用规则**：
> - 继承收货订单字段时标注「继承自收货订单-入库单字段清单」，不重复写字段定义
> - 下游文档只引用字段名称写规则，严禁重复定义字段本体
> **修改原则**：字段定义变化 → **只改本文件**；下游 Demo PRD 不手动修改，由 AI 重新生成
> **版本**：V1.0 定稿版 | 更新时间：2026-09-01
> **规则来源**：`03-02-加盟商揽收仓PDA主PRD.md` V1.1、`01-业务流程推演.md` V1.4、`02-00-字段清单.md` V1.1
> **页面范围**：本期仅 **PDA** 执行；**不提供**管理后台手工新增/编辑页（PDA 主 PRD Out of Scope / R33）。

## 一、头部字段（单据级）

> 上架单由 PDA **确认绑托完成**时系统**同事务自动生成**；用户不可手工新建（R33）。
> 「新增页」列：一律**不展示**。「编辑页」列：指 PDA 上架作业页；**已完成**后全部只读。

## 二、托明细字段（行级）

> 每行代表该运单下的**一个托盘**（**托号**）。大票多托时一行一托；一票一托时仅一行（PDA 主 PRD R36、R07）。
> 生成上架单时由绑托结果带出；PDA 上架时**按托逐托确认**至整单完成（R36）。
> **列表展示**：托明细**主列表不展示**，在 PDA 上架作业页/详情托明细区展示。


| 字段名称 | 字段来源 | 取值说明 | 必填性 | 新增页 | 编辑页 | 列表展示 | 可筛选 | 详情展示 | 字段说明 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 托号 | 系统带出并存储 | 文本 | 必填 | 不展示 | 只读（ReadonlyText） | 否 | 是（Input） | 是 | 托盘号 | 继承收货订单绑托回写（§5.1.3）；PDA 可按托号检索待上架任务（R35）；快照存储 |
| 件数 | 系统带出并存储 | 数字，整数，≥1 | 必填 | 不展示 | 只读（ReadonlyText） | 否 | 否 | 是 | 该托箱数 | 由收货订单箱明细按托号汇总；生成上架单时带出；快照存储 |
| 上架状态 | 系统生成 | 枚举：`待上架`、`已上架` | 系统自动 | 不展示 | 只读（ReadonlyText） | 否 | 否 | 是 | 该托是否已完成上架确认 | 支撑 R36 按托逐托确认；**枚举命名与落库规则待确认**（§六） |
| 目标库位 | 用户填写 | 引用库位档案 | 选填 | 不展示 | 可编辑（SelectWithSearch） | 否 | 否 | 是 | 该托上架目标库位 | **托级与单级目标库位关系待确认**（§六）；若仅头部维护目标库位，本列可不落库 |

## 三、统计汇总字段（单据级，系统计算）

> 本期 PDA 待上架列表以头部字段为主（作业单号、运单号、托号、件数、初始库位）；无独立列表汇总列（粗纲）。
> 以下字段用于 PDA 作业页统计展示，**不单独作为列表列**（若与头部重复，以头部为准）。


| 字段名称 | 字段来源 | 取值说明 | 必填性 | 新增页 | 编辑页 | 列表展示 | 可筛选 | 详情展示 | 字段说明 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 托数 | 系统计算 | 数字，整数，≥1 | 系统自动 | 不展示 | 只读（ReadonlyText） | 否 | 否 | 是 | 本单托盘总数 | = §二 托明细行数；大票多托场景展示（R36）；**是否必展示待确认**（§六） |
| 已上架托数 | 系统计算 | 数字，整数，≥0 | 系统自动 | 不展示 | 只读（ReadonlyText） | 否 | 否 | 是 | 已完成上架确认的托盘数 | = §二 上架状态=已上架 的行数；R36 按托确认进度；**字段是否落库待确认**（§六） |
| 未上架托数 | 系统计算 | 数字，整数，≥0 | 系统自动 | 不展示 | 只读（ReadonlyText） | 否 | 否 | 是 | 待上架托盘数 | = 托数 − 已上架托数；PDA 作业进度展示；**字段是否落库待确认**（§六） |

## 五、快照字段说明

| 类型 | 字段 | 说明 |
| :--- | :--- | :--- |
| **快照（系统带出并存储）** | **运单号**、**托号**（头部）、**初始库位**、**件数**（生成时）、**作业类型** | 绑托完成生成上架单时从收货订单/绑托结果带出（R34）；后续共用表变更不影响已生成上架单 |
| **快照（托明细）** | **托号**、**件数** | 按绑托结果按托汇总；与收货订单箱明细同源，生成后快照 |
| **用户填写（执行时写入）** | **目标库位**（头部；托明细目标库位规则待确认） | PDA 人工选择（Q10/R10）；写入后作为库位库存入账库位 |
| **下游回写** | **件数**（实际上架，若与生成时不一致）、**上架完成时间**、**上架人**（待确认） | PDA 上架确认时写入（R11）；联动收货订单→已上架 |
| **系统生成（非快照）** | **作业单号**、**状态**、系统字段 | 单据生命周期字段；随动作变更 |
| **系统计算（不存储或待确认）** | **托数**、**已上架托数**、**未上架托数** | 由托明细聚合；是否落库见 §六 |
| **不在本单存储** | **收货单号**、**目的仓库**、**预报箱数** 等 | 粗纲约定：通过**运单号**关联共用表获取；不重复落库 |

## 六、待确认字段规则

| 字段 | 未确认规则 | 影响页面/规则 | 建议确认对象 |
| :--- | :--- | :--- | :--- |
| **作业单号** | 编码规则（前缀、流水位数） | 生成、PDA 检索、打印/日志 | 产品 + 研发 |
| **头部托号** | 大票多托时头部**托号**展示哪一个托，或是否留空仅看托明细 | PDA 待上架列表、详情头部 | 产品 |
| **初始库位** | 绑托完成时**初始库位**取值来源（作业库位/收货区/人工收货占位等） | 生成上架单、PDA 列表 | 产品 + 仓库 |
| **件数** | 是否允许实际上架**件数**小于生成时件数（部分上架） | 库存结转、收货订单→已上架判定 | 产品 |
| **托明细.目标库位** | 目标库位仅头部维护，还是每托可不同库位 | PDA 上架交互、库位库存入账 | 产品 |
| **托明细.上架状态** | 枚举命名、是否落库；与头部**状态**的联动时点 | R36 按托确认、整单完成判定 | 产品 + 研发 |
| **托数 / 已上架托数 / 未上架托数** | 仅页面计算展示还是单据落库 | PDA 进度 UI | 产品 |
| **上架人** | 是否独立字段，或仅用**最后修改人** | 详情展示、操作追溯 | 产品 |
| **创建人** | 生成时记系统账号还是绑托操作人 | 审计日志 | 产品 |
| **PDA 列表** | 列序、列宽、默认排序（创建时间/待上架优先） | PDA 待上架任务列表 | 产品 |
| **归属仓库** | 是否增加**归属仓库**字段用于数据权限过滤，或仅通过**运单号**→共用表**收货仓库**过滤 | PDA 可见范围（§七 权限） | 产品 + 研发 |
