## 1.2 状态 Tab 栏

列表页主过滤入口。Tab 集合来自主 PRD §5.2 空单调拨四态。

| Tab 标签 | 过滤逻辑 |
| :--- | :--- |
| 全部 | 展示所有状态（默认选中） |
| 待出库 | 状态 = 待出库 |
| 已出库 | 状态 = 已出库 |
| 已完成 | 状态 = 已完成 |
| 已取消 | 状态 = 已取消 |

**Tab 交互规则**：

- 每个 Tab 右侧展示当前条件下的计数（格式：`Tab名 (N)`，超过 99 展示 `99+`，0 也展示）
- 切换 Tab 后列表刷新，页码重置为第 1 页，**不清空**查询区其他条件
- 切换到具体状态 Tab 时，查询区的「状态」筛选条件**隐藏**（避免语义重叠）；切换回「全部」时恢复

## 1.3 查询区

### 布局说明

桌面端栅格布局（约 4 列 × 2 行）。默认展示全部筛选项，无「展开/收起」区域。

右侧操作组顺序：`重置` → `查询`（主按钮）

### 查询条件

> 以下字段均来自字段清单「可筛选=是」；控件类型取自字段清单「取值说明/备注」及 §5.5 现网口径。

| 字段 | 控件类型 | 规格说明 |
| :--- | :--- | :--- |
| 调拨计划单号 | `Input` | 精确匹配；placeholder：`调拨计划单号`；支持单值 |
| 运单号 | `Input` | 精确匹配；placeholder：`运单号`；按明细运单号反查所属计划单（字段清单 §5.5） |
| 调出仓库 | `SelectWithSearch` | **多选**；数据来源仓库档案；展示格式 `仓库代码(仓库名称)`；仅列出可用仓库 |
| 调入仓库 | `SelectWithSearch` | **多选**；规格同调出仓库 |
| 状态 | `Select` | 枚举：`待出库`、`已出库`、`已完成`、`已取消`；**选中具体状态 Tab 时隐藏本项** |

**查询交互**：

- 点击「查询」：携带 Tab 条件 + 查询区条件请求列表，页码重置为 1
- 点击「重置」：清空查询区全部条件（**不重置**当前 Tab），立即刷新列表
- Enter 键在输入框内触发查询

## 1.5 表格

| 行勾选 | 不支持 |
| 列宽拖拽 | 支持 |

### 明细子表（行展开区）

> 承载字段清单明细区「列表展示=是」的字段；一计划多运单，每行一条实装运单。

| 列名 | 对应字段 | 内容说明 |
| :--- | :--- | :--- |
| 运单号 | 运单号 | 文本；界面列名用运单号（R23） |
| 客户代码 | 客户代码 | 文本 |

| 重量 | 重量 | 数字，单位 KG，最多 2 位小数 |
| 体积 | 体积 | 数字，单位 CBM，保留 6 位小数 |

**子表空态**：待出库空单或无 PDA 回写时，展开区展示「暂无实装运单」。

### 状态 Tag 配色

| 状态 | 颜色语义 |
| :--- | :--- |
| 待出库 | 蓝色 |
| 已出库 | 橙色 |
| 已完成 | 绿色 |
| 已取消 | 灰色 |

### 行内操作

行内操作使用**文字动作**，按状态与前置条件动态展示。**不渲染 disabled 操作**（不可用时不展示入口）。

| 状态 | 前置条件 | 展示的操作 |
| :--- | :--- | :--- |
| 待出库 | 明细无运单 | 查看 / 作废 |
| 待出库 | 明细已有运单 | 查看 |
| 已出库 | — | 查看 |
| 已完成 | — | 查看 |
| 已取消 | — | 查看 |

**动作说明**（翻译自主 PRD §5.2，不在此扩展规则）：

- **查看**：跳转详情页 `/order/TransferPlan/{调拨计划单号}`
- **作废**：触发二次确认弹窗（§1.6）；成功后状态 → 已取消；已有扫描明细则接口拒绝（主 PRD §5.2 失败处理）

> **不在列表提供的动作**：PDA 发车、调入仓收货完成（系统）——分别由 PDA / 对接回写触发，管理后台列表无入口。

## 1.7 Mock 数据规格

### 状态覆盖要求

| 状态 | 最少条数 | 备注 |
| :--- | :--- | :--- |
| 待出库（无明细） | ≥ 2 | 可演示作废；展开子表为空态 |
| 待出库（有明细，作废应拒绝） | ≥ 1 | 子表含运单号等 5 列 |
| 已出库 | ≥ 2 | 子表含实装明细 |
| 已完成 | ≥ 1 | 终态 |
| 已取消 | ≥ 1 | 终态 |
| **总计** | **≥ 7** | |

### 数据要求

- **调拨计划单号**格式：`AT` + `YYMMDD` + 5 位流水号，如 `AT26083100001`
- **调出仓库**：加盟揽收仓，如 `NC01(南昌加盟揽收仓)`
- **调入仓库**：集货仓，如 `DG01(东莞集货仓)`
- **运单号**：虚构，如 `SDL260581625`
- **客户代码**：虚构，如 `amz001`
- 所有数据使用虚构演示数据，不使用真实公司信息

## 1.8 页面状态与反馈

### 空状态

| 场景 | 展示 |
| :--- | :--- |
| 首次进入 / 查询无结果 | 表格区域居中展示「暂无数据」插图 + 文案「暂无调拨计划」 |
| 某 Tab 计数为 0 | Tab 仍展示 `(0)`；点击进入后同上空状态 |
| 行展开无明细 | 子表区域文案「暂无实装运单」 |

### 加载状态

| 场景 | 展示 |
| :--- | :--- |
| 首次加载 / Tab 切换 / 查询 / 翻页 | 表格区域展示 Skeleton 行（≥ 5 行）或 Loading 遮罩 |
| Tab 计数加载 | Tab 标签计数位展示小型 Loading，加载完成后替换为数字 |

### 错误状态

| 场景 | 反馈类型 | 文案 |
| :--- | :--- | :--- |
| 列表接口失败 | Toast | 加载失败，请重试 |
| 网络异常 | Toast | 网络异常，请重试 |
| Tab 计数接口失败 | 静默降级 | Tab 计数展示 `-`，不影响列表主查询 |
| 作废失败（已有扫描明细） | Toast | 作废失败，该计划已有实装运单 |
| 作废成功 | Toast | 作废成功 |
