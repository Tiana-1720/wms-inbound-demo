### 4.3 库存链路闭环（规则层）

```
上游发车 → 预报库存+（南昌）；东莞常规入库由现网推送
    → 分货/按托绑托（无库存变动；整单完成才生成上架单）
    → 上架完成 → 预报库存−、库位库存+
    → PDA 装车 → 出库单已复核（可多次追加）；调拨仍为待出库；不生调拨入库
    → PC 确认出库 → 库位库存−；出库单已出库；调拨计划已出库
    → 东莞全部关联运单常规入库收货完成 → 调拨计划已完成
```

**结论**：规则层闭环 ✅；缺用例数据数值验算（见第五节）。
