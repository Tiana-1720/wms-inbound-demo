### 4.2 库存链路闭环（规则层）

```
上游发车 → 预报库存+（南昌）；东莞常规入库由现网推送
    → 分货/按托绑托（无库存变动；整单完成才生成上架单）
    → 上架完成 → 预报库存−、库位库存+（备货库位）
    → OMS 建计划同步生成空出库单（待出库、明细空）
    → PDA 装车暂存/锁定 或 PC 关联运单 → 关联运单至出库单（仍为待出库/已复核）；箱库存已占用
    → PDA 装车锁定 或 PC 手动锁单 → 出库单已复核；调拨计划已复核
    → PC 先打印装柜单再确认出库 → 库位库存−；出库单已出库；调拨计划已出库
    → 东莞全部关联运单常规入库收货完成 → 调拨计划已完成
```

**结论**：规则层闭环 ✅；缺用例数据数值验算（见第五节）。
