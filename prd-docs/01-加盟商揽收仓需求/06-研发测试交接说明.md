## 1. 本次做什么、不做什么

### 做什么

本次是在**现网 WMS 之上做增量**，支撑南昌/赣州**加盟揽收仓**上线，核心三件事：

1. **仓库类型拆分**：新增「加盟揽收仓」，现网「揽收仓」迁移为「自营揽收仓」。
2. **收货订单（常规入库）**：接收速达发车推送，按运单号落单；加盟路径走 `待收货 → 已绑托 → 已上架`（或取消）；后台仅列表查看/筛选，不改预报。
3. **调拨计划（空单调拨增量）**：OMS 创建空白调拨；PDA 装车→出库单**已复核**；PC 确认出库→**已出库**并扣库位库存；东莞常规入库由发车现网推送，**不生调拨入库单**；东莞全部关联运单收货完成→调拨**已完成**。

### 不做什么（请勿自行扩大）

| 类别 | 明确 Out of Scope |
| :--- | :--- |
| 终端 | PDA 交互细节（见 [03-02-加盟商揽收仓PDA主PRD.md](./03-02-加盟商揽收仓PDA主PRD.md)，本文不覆盖） |
| 现网能力 | 集货仓/自营揽收仓原有作业、计划调拨创建/编辑/下推/PDA 复核装柜（沿用现网，零改造） |
| 上游 | 速达报文开发、加盟商下单/贴标/发车界面 |
| 后台 | 手工新建收货订单、打印装车清单、空单调拨取消（枚举已预留，**本期无入口**） |
| 其他 | 费用结算、运力调度、盘点、经营报表；上架单/出库单字段定稿 |

## 2. 本次变化（增量摘要）

### 2.1 受影响字段（相对现网）

> 下列仅列**本次相对现网有增量**的字段/规则；现网已有能力（运单号命名、客户代码必填、入库类型过滤、调拨计划单号、列表数量列、司机/电话/车牌等）不在此重复。

**收货订单 / 入库单（定稿 V1.11）**

| 变化类型 | 字段/主题 | 要点 |
| :--- | :--- | :--- |
| 规则 | 收货箱数/收货人/收货时间/收货仓库 | **绑托完成**后回写；收货重量/体积**加盟路径不回写** |
| 规则 | 东莞常规入库 | 发车时**现网自动推送**；**不由**空单调拨装车生成调拨入库单 |

**调拨计划单（定稿 V1.7）**

| 变化类型 | 字段/主题 | 要点 |
| :--- | :--- | :--- |
| 新增 | 调拨类型 | 上游推送=计划调拨，OMS 创建=空单调拨；**落库区分，页面不展示、不可筛** |
| 修改 | 明细 | OMS 创建时空；**仅 PDA 装车回写**实装运单/箱数/重量/体积 |
| 修改 | 下推与同步 | 空单调拨：**PDA 装车**生成/追加出库单（已复核）；**PC 确认出库**→已出库并扣库存；建计划**不下推**；**不生**调拨入库单 |
| 锁定 | 调出仓库、调入仓库 | 创建后锁定；**调出≠调入**（R29） |

**上架单 / 出库单**：仍为粗纲，**不在本期后台页面范围**。

### 2.2 受影响状态机

**收货订单（加盟路径）**

```
待收货 ──上游取消──→ 已取消 ──重新发车──→ 待收货
待收货 ──PDA绑托──→ 已绑托 ──PDA上架──→ 已上架（终态）
```

- 不进入「收货中」「已收货」（留给自营/集货仓现网）。
- 仅**待收货**可取消；已绑托/已上架拒绝取消。
- 同一运单号未取消不可二次发车。

**调拨计划（本期关注空单调拨；计划调拨沿用现网）**

```
待出库 ──PDA装车──→ 待出库（出库单已复核）
待出库 ──PC确认出库──→ 已出库 ──东莞全部关联运单收货完成──→ 已完成（终态）
已取消（预留，本期无写入入口）
```

- 状态**仅 Tab 过滤**，查询区无状态下拉。
- 建计划**不下推**；**PDA 装车**生成/追加出库单（已复核）；**PC 确认出库**后调拨→已出库、库位库存 −。
- 东莞对该计划**全部关联运单**常规入库均**收货完成**即调拨完结。

### 2.3 受影响页面

| 页面 | 路径 | 本期变化 |
| :--- | :--- | :--- |
| 收货订单列表 | `/order/Inbound` | **沿用现网**；加盟路径状态与接口回写见 §2.2 |
| 调拨计划列表 | `/order/TransferPlan` | 混排两类调拨（后台按调拨类型区分）；**新增**按钮仅总部、仅空单；其余沿用现网 |
| 调拨计划新增 | 列表弹窗 / `/order/TransferPlan/new` | **Modal**（640px）；仅选调出/调入仓；取消/确定 |
| 调拨计划详情 | `/order/TransferPlan/{单号}` | **沿用现网**，本期无页面改造 |

### 2.4 核心业务规则（R 号速查）

| 规则 | 摘要 |
| :--- | :--- |
| R02 | 调出仓=加盟揽收仓 → 空单调拨；其他走现网计划调拨 |
| R06/R09 | 运单号唯一；预报快照只读，差异须待收货取消重发 |
| R11–R14 | 库存：发车预报+ → 绑托不变 → 上架预报−库位+ → **PC确认出库**库位− |
| R16 | **OMS 创建空白调拨**（WMS「调拨计划→新增」即 OMS 同一能力）；明细仅 PDA 回写 |
| R18–R19 | 装车生成出库单已复核；不生调拨入库；东莞全部关联运单收货完成即调拨完结 |
| R22 | 空单两仓创建后锁定；已出库/已完成只读 |
| R24–R28 | 下推按**调拨类型**分支，不按仓库配时机 |
| R29 | **调出仓库 ≠ 调入仓库** |

### 2.5 异常与边界

| 场景 | 处理 |
| :--- | :--- |
| 未取消重复发车 | 按运单号拒绝 |
| 已绑托/已上架取消 | 拒绝 |
| 待收货取消与绑托并发 | 已到已绑托则取消失败 |
| 预报与实收不一致 | 不改预报；待收货走取消重发，已绑托后线下处理 |
| 空单拆票/目的仓与调入仓不一致 | PDA 装车拦截 |
| 出库单已出库后再次装车 | 拦截 |
| PC 确认出库前多次装车 | 允许；同一出库单追加运单 |

## 4. 测试重点与待确认事项

### 4.1 关键业务场景（建议用例主线）

| 编号 | 场景 | 验证要点 |
| :--- | :--- | :--- |
| S01 | 上游发车生成收货订单 | 待收货；预报库存 +预报箱数；列表可见 |
| S02 | 待收货取消后重发 | 取消→已取消预报−；重发全量覆盖回待收货 |
| S03 | OMS 创建空单调拨 | 待出库；明细空 |
| S04 | 空单 PDA 装车 + PC 确认出库 | 装车后出库单已复核；确认后已出库、库位库存 − |
| S05 | 东莞全部关联运单收货即调拨完结 | 调拨→已完成 |
| S06 | 已绑托/已上架不可取消 | 上游/WMS 取消均拒绝 |
| S09 | 重复发车 | 同运单号未取消则拒绝 |

**验收编号对照**：主 PRD §九 V01–V15 可直接转测试用例。

### 4.2 权限测试

| 角色 | 后台操作 | 数据可见 |
| :--- | :--- | :--- |
| 总部作业部 | OMS 创建空白调拨；PC 确认出库 | 可用仓库命中的收货订单、调拨单 |
| 加盟揽收仓操作员 | 后台以查看为主 | 沿用现网数据权限 |
| 集货仓操作员 | 后台以查看为主 | 调入仓命中的调拨单；东莞常规入库（发车现网推送） |

- 调拨数据权限：**调出 OR 调入**命中即可见（东莞账号应能看到南昌→东莞空单）。
- WMS 管理后台「调拨计划→新增」即 **OMS 创建空白调拨** 同一能力；仅总部作业部权限；计划调拨不可从该入口创建。

### 4.3 页面/交互测试重点

- 收货订单：沿用现网列表；无手工新增入口；重点验证加盟路径状态推进与上游取消/重发。
- 调拨计划：Tab 含「已取消」但**无取消操作**；OMS 创建空白调拨入口（「调拨计划→新增」）仅总部作业部可见。
- 新增弹窗：调出限加盟揽收仓；**调出=调入阻断**（R29）；保存后关闭弹窗并刷新列表。
- 调拨计划详情：沿用现网，本期无改造项。

### 4.4 待确认事项（尚未拍板）

| 编号 | 主题 | 影响 | 状态 |
| :--- | :--- | :--- | :--- |

| D-02 | **异常类型**枚举 | 收货订单异常 Tab 筛选项 | P2，待产品确认 |

| — | **空单调拨取消** | 待出库→已取消 | 后期迭代；本期勿实现取消入口 |
| — | **PDA 装车/PC 确认出库** | 空单实装回写、拆票拦截 | 见 PDA PRD V1.3，与管理后台联调时再对齐 |

### 4.5 研发联调提醒

1. **下推引擎**：必须按 `调拨类型` 分支（R24），计划调拨走现网、空单调拨走增量；**禁止**按仓库单独配下推时机。
2. **状态变更**：全部通过动作/接口触发，**禁止**表单直改状态字段。
3. **计划调拨回归**：列表混排后，现网计划调拨的创建/编辑/下推/PDA 路径须做回归，确保未被空单逻辑污染。
4. **主数据**：仓库类型迁移（揽收仓→自营揽收仓）需一次性数据脚本，并验证 R02 判定。
