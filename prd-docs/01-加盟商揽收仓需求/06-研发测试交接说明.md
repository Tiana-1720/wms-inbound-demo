## 1. 本次做什么、不做什么

### 做什么

本次是在**现网 WMS 之上做增量**，支撑南昌/赣州**加盟揽收仓**上线，核心链路如下：

1. **仓库类型拆分**：新增「加盟揽收仓」，现网「揽收仓」迁移为「自营揽收仓」。
2. **收货订单（常规入库）**：接收速达发车推送，按运单号落单；加盟路径走 **待收货 → 已绑托 → 已上架**（或取消）；后台仅列表查看/筛选，不改预报。
3. **PDA 分货绑托**：独立新页 `PDA → 入库管理 → 分货`；按 M/P/N 策略组托；绑托完成回写收货字段并生成上架单；绑托阶段**无库存变动**。
4. **PDA 上架**：绑托后系统生成上架单；操作员选备货库位确认上架；**预报库存 − / 库位库存 +**。
5. **调拨计划（空单调拨增量）**：OMS 创建空白调拨；PDA 装车 → 出库单**已复核**并**占用**库位库存；PC 确认出库 → **已出库**并**实扣**；东莞常规入库由发车现网推送，**不生调拨入库单**；东莞全部关联运单收货完成 → 调拨**已完成**。
6. **分货参数配置**：管理后台按加盟揽收仓维护 **M**（小票阈值）、**P**（混托上限）；未配置则 PDA 分货不可用。

### 不做什么（请勿自行扩大）

| 类别 | 明确 Out of Scope |
| :--- | :--- |
| 现网能力 | 集货仓/自营揽收仓原有作业、计划调拨创建/编辑/下推/PDA 下架→复核→装柜（沿用现网，零改造） |
| 上游 | 速达报文开发、加盟商下单/贴标/发车界面 |
| 后台 | 手工新建收货订单、收货订单详情页（本期不做）、打印装车清单、空单调拨取消（枚举已预留，**本期无入口**） |
| PDA | 计划调拨装柜路径、库存查询菜单、离线扫描、打印装车清单、空单调拨取消 |
| 其他 | 费用结算、运力调度、盘点、经营报表；**出库单字段定稿**（粗纲阶段） |

## 2. 本次变化（增量摘要）

> 下列仅列**相对现网有增量**的字段、规则、状态、页面与异常；现网已有能力（运单号命名、客户代码必填、入库类型过滤、调拨计划单号、列表数量列、司机/电话/车牌等）不在此重复。

### 2.1 受影响字段

**收货订单 / 入库单（定稿 V1.11）**

| 变化类型 | 字段/主题 | 要点 |
| :--- | :--- | :--- |
| 规则 | 收货箱数/收货人/收货时间/收货仓库 | **全部箱绑托完成**后回写；绑托阶段头部仍为待收货 |
| 规则 | 收货重量/收货体积 | **加盟路径不回写** |
| 规则 | 东莞常规入库 | 发车时**现网自动推送**；**不由**空单调拨装车生成调拨入库单 |

**调拨计划单（定稿 V1.9）**

| 变化类型 | 字段/主题 | 要点 |
| :--- | :--- | :--- |
| 新增 | 调拨类型 | 上游推送=计划调拨，OMS 创建=空单调拨；**落库区分，页面不展示、不可筛** |
| 修改 | 明细 | OMS 创建时空；**仅 PDA 装车回写**实装运单/箱数/重量/体积 |
| 修改 | 下推与同步 | 空单调拨：**PDA 装车**生成/追加出库单（已复核）；**PC 确认出库**→已出库并扣库存；建计划**不下推**；**不生**调拨入库单 |
| 锁定 | 调出仓库、调入仓库 | 创建后锁定；**调出≠调入**（R29） |

**上架单（定稿 V1.3）**

| 变化类型 | 字段/主题 | 要点 |
| :--- | :--- | :--- |
| 新增单据 | 上架单 | 绑托完成系统生成；默认一运单一张；**小票混托**托满时多运单共一张 |
| 回写 | 目标库位、件数、上架完成时间 | PDA 确认上架后回写；**仅允许备货库位**（R49） |
| 展示 | 初始库位 | 加盟路径值为空，**仍展示该列**（沿用现网列表结构） |

**分货参数（库内配置，非单据字段）**

| 参数 | 含义 | 维护方 |
| :--- | :--- | :--- |
| **M** | 小票阈值（件）：预报箱数 ≤ M 为小票 | 管理后台按加盟揽收仓 |
| **P** | 混托格小票运单数上限 | 管理后台按加盟揽收仓 |
| **N** | 作业托数（1–10） | PDA 进入分货页时选择，非后台配置 |

**出库单**：仍为粗纲（V0.x），**不在本期页面范围**；空单调拨装车下推仅涉及状态 **已复核 / 已出库** 两态。

### 2.2 受影响状态机

**收货订单（加盟路径）**：待收货 →（PDA 全部箱绑托完成）→ 已绑托 →（PDA 上架完成）→ 已上架（终态）；待收货可上游取消 → 已取消 → 重新发车回待收货。不进入「收货中」「已收货」。**不存在「部分绑托」状态**——尚有未绑托箱时头部仍为待收货。

**上架单**：待上架 →（PDA 确认上架）→ 已完成（终态）。

**调拨计划（沿用现网六态；本期关注空单调拨）**：待出库 →（空单调拨·PDA 装车）→ 已复核 →（PC 确认出库）→ 已出库 →（东莞全部关联运单收货完成）→ 已完成。计划调拨仍走现网 待出库 → 已下架 → 已复核 路径。状态**仅 Tab 过滤**，查询区无状态下拉；**已取消**枚举预留，本期无写入入口。

**出库单（空单路径）**：PDA 装车 → **已复核**（可多次追加运单）；PC 确认出库 → **已出库**。装车完成时调拨计划仍为**待出库**，与出库单已复核并存。

### 2.4 核心业务规则（R 号速查）

| 规则域 | 编号 | 摘要 |
| :--- | :--- | :--- |
| 调拨判定 | R02 | 调出仓=加盟揽收仓 → 空单调拨；其他走现网计划调拨 |
| 收货 | R06/R09 | 运单号唯一；预报快照只读，差异须待收货取消重发 |
| 库存 | R11–R14 | 发车预报+ → 绑托不变 → 上架预报−库位+（仅备货库位）→ **装车占用** → **PC 确认出库**实扣 |
| 调拨 | R16–R19、R22、R24–R30 | OMS 空白调拨；装车生成出库单已复核；不生调拨入库；东莞全部关联运单收货完成即完结；两仓创建后锁定 |
| 后台配置 | R48/R49 | **M/P** 须配置后 PDA 方可分货；上架**仅备货库位** |
| PDA 分货 | R37–R47 | M 小票阈值、P 混托上限、N 作业托数；小票混托须每票扫齐方可绑托；N>1 小票首箱入混托格/大票新托；落托确认弹窗 |

### 2.5 异常与边界

| 场景 | 处理 |
| :--- | :--- |
| 未取消重复发车 | 按运单号拒绝 |
| 已绑托/已上架取消 | 拒绝 |
| 待收货取消与绑托并发 | 已到已绑托则取消失败 |
| 预报与实收不一致 | 不改预报；待收货走取消重发，已绑托后线下处理 |
| M/P 未配置 | PDA 分货 Toast 阻断 |
| 空单拆票/目的仓与调入仓不一致 | PDA 装车拦截 |
| 出库单已出库后再次装车 | 拦截 |
| PC 确认出库前多次装车 | 允许；同一出库单追加运单 |
| 调出=调入 | 新增弹窗阻断（R29） |

## 4. 测试重点与待确认事项

### 4.1 关键业务场景（建议用例主线）

| 编号 | 场景 | 验证要点 |
| :--- | :--- | :--- |
| S01 | 上游发车生成收货订单 | 待收货；预报库存 +预报箱数；列表可见 |
| S02 | 待收货取消后重发 | 取消→已取消预报−；重发全量覆盖回待收货 |
| S03 | 配置 M/P 后 PDA 分货 | 未配置阻断；配置后大小票判定、混托上限、落托确认生效 |
| S04 | PDA 分货→上架闭环 | 全部箱绑托→已绑托并生成上架单；上架后预报−库位+；仅备货库位 |
| S05 | OMS 创建空单调拨 | 待出库；明细空；仅总部可见新增入口 |
| S06 | 空单 PDA 装车 + PC 确认出库 | 装车后出库单已复核且**已占用库存**；确认后已出库、库位库存实扣 |
| S07 | 东莞全部关联运单收货即调拨完结 | 调拨→已完成 |
| S08 | 已绑托/已上架不可取消 | 上游/WMS 取消均拒绝 |
| S09 | 重复发车 | 同运单号未取消则拒绝 |
| S10 | 计划调拨回归 | 列表混排后，现网计划调拨创建/编辑/下推/PDA 路径未被空单逻辑污染 |

**验收编号对照**：后台主 PRD §九 V01–V15；PDA 主 PRD 验收章节可直接转用例。

### 4.2 权限测试

| 角色 | 后台 | PDA | 数据可见 |
| :--- | :--- | :--- | :--- |
| 总部作业部 | OMS 创建空白调拨；PC 确认出库；维护 M/P | 分货/上架/装车（按菜单授权） | 可用仓库命中的收货订单、调拨单 |
| 加盟揽收仓操作员 | 以查看为主 | 分货/上架/装车（按菜单授权） | 沿用现网数据权限 |
| 集货仓操作员 | 以查看为主 | 装车（调入仓命中可见） | 调入仓命中的调拨单；东莞常规入库（发车现网推送） |

- 调拨数据权限：**调出 OR 调入**命中即可见（东莞账号应能看到南昌→东莞空单）。
- WMS「调拨计划→新增」= **OMS 创建空白调拨**同一能力；仅总部作业部。
- 分货参数：总部作业部或系统管理员可维护。

### 4.3 页面/交互测试重点

- **收货订单**：沿用现网列表；无手工新增；重点验证加盟路径状态推进与上游取消/重发。
- **调拨计划**：Tab 含「已取消」但**无取消操作**；新增仅总部、仅空单；调出=调入阻断。
- **分货参数**：保存后立即生效；PDA 未配置时入口阻断。
- **PDA 分货**：作业托数弹窗不可跳过；扫描**不校验**收货订单状态（仅展示）；小票混托须每票扫齐。
- **PDA 上架**：按托确认；跨库位不一致提醒；整单完成后收货订单→已上架。
- **PDA 装车**：仅空单调拨；扫箱带出整托；不拆票；可多次装车追加同一出库单。

### 4.5 研发联调提醒

1. **下推引擎**：必须按 `调拨类型` 分支（R24），计划调拨走现网、空单调拨走增量；**禁止**按仓库单独配下推时机。
2. **状态变更**：全部通过动作/接口触发，**禁止**表单直改状态字段。
3. **绑托与上架单**：不存在「部分绑托」状态；**全部箱绑托完成**才→已绑托并生成上架单（小票混托例外：托满即生成含多运单的上架单）。
4. **装车两步出库**：PDA 装车→出库单已复核+占用库存；PC 确认出库→已出库+实扣；调拨计划已出库由 PC 触发。
5. **主数据**：仓库类型迁移（揽收仓→自营揽收仓）需一次性数据脚本，并验证 R02 判定。
6. **计划调拨回归**：列表混排后须回归现网路径，确保未被空单逻辑污染。
