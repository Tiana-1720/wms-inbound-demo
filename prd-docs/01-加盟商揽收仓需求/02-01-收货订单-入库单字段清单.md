# 收货订单-入库单字段清单

> **文档定位**：收货订单与入库单**共用同一数据表**，本文件为共用表字段的唯一定义来源；TMS 推送接口字段映射见 §七。
> **单据关系**：**一入库单（收货单号）对应一运单号**；速达发车推送生成一条共用表记录，PDA 收货/绑托/上架在同一记录上推进状态，不另建入库单号。
> **视图说明**：
>
> - **收货订单菜单**（订单管理 → 收货订单）：可查看全部状态，不按状态藏单（主 PRD §3.1）；**仅展示入库类型=常规入库**的订单，入库类型字段本身不展示
> - **加盟揽收仓路径**：待收货 → 已绑托 → 已上架；或待收货 → 已取消。不进入收货中、已收货（主 PRD §5.1）
> - 全局枚举另含收货中 / 已收货，供自营揽收仓、集货仓现网使用，本文不展开现网作业页
> - **调拨入库单**（空单发车后按实装运单拆到调入仓）：同一套入库单字段，**入库类型=调拨入库**（主 PRD §3.4）
> **引用规则**：
> - 下游单据继承本表字段时，标注「继承自收货订单-入库单字段清单」，不重复写字段定义
> - 下游文档只引用字段名称写规则，严禁重复定义字段本体
> - **上架单、出库单字段不在本文件定义**
> **修改原则**：字段定义变化 → **只改本文件**；下游 Demo PRD 不手动修改，由 AI 重新生成
> **版本**：V1.11 定稿版 | 更新时间：2026-08-31
> **规则来源**：`03-01-加盟商揽收仓管理后台主PRD.md` V1.1；现网口径 `prd-docs/99-历史需求/WMS_V1.0  260314.md`（表格 5–7、12、19、22）
> **粗纲来源**：本文件 V1.2（头部/明细/汇总/系统字段及 TMS 映射）

| 待收货       | PDA 按托确认绑托 | 箱号匹配预报；该运单**尚有未绑托箱号** | **待收货** | 回写明细**托号**；**不回写**头部收货箱数等；**不生成上架单**；无库存变动 |
| 待收货       | PDA 确认绑托（整单完成） | 箱号匹配预报；该运单**全部箱号**已绑托 | 已绑托  | 回写托号、绑托完成时间、收货箱数、收货人、收货时间、**收货仓库**；**不回写**收货重量/收货体积；无库存变动；**同事务生成上架单** |
| 已绑托       | PDA 上架完成 | —                  | 已上架  | 回写上架完成时间；预报库存 −、库位库存 +            |
| 已绑托 / 已上架 | 取消       | —                  | 不变   | 拒绝（R08）                           |


管理后台动作：查看、筛选。无手工新增、无改预报、无直改状态。

### 5.2 菜单与列表

- 收货订单列表/详情可查看全部状态（含待收货 / 已绑托 / 已上架 / 已取消），不按状态藏单；**仅展示入库类型=常规入库**，入库类型列不展示、不可筛
- **默认排序**：按收货单创建时间升序（现网收货订单 / 入库管理查询条件）
- **筛选（列表页查询区）**：对齐现网收货订单列表页截图，**固定暴露 12 项**：运单号、参考号、收货单号、客户代码、渠道、收货仓库、目的国、业务类型、业务归属、运输类型、预计到仓日期、收货日期。**无展开/收起区**。状态与异常类型仅通过 §1.2 状态 Tab 过滤，不在查询区重复提供下拉。
- **筛选（字段能力，本期列表页未暴露）**：预报仓库、目的仓库、客户等级、状态、异常类型、箱号、托号等字段在清单中仍可标记「可筛选=是」，供后续高级检索或详情场景使用；其中**目的仓库**为上游快照文本，若后续暴露筛选项则用 `Input` 模糊匹配，**不引用目的仓库档案字典**
- 列表优先列（粗纲）：参考号、运单号、目的仓库、预报仓库、收货仓库、预报箱数、收货箱数、状态、预计到仓时间、业务归属、创建时间。**列序、列宽待定**
- **列表展示列语义**：头部/系统字段「列表展示=是」= 收货订单**主列表**展示；**全部明细字段**「列表展示=否」= 主列表不展示，仅在**详情明细表**展示；明细字段仍可「可筛选=是」用于主列表检索
- 界面列名用**运单号**（沿用现网）
- 数据权限：未收货看预报仓库，收货后看收货仓库（§七）；仓库下拉显示格式 `仓库代码(仓库名称)`（现网表格 5）

### 5.4 调拨入库单（同一字段清单，场景差异）

空单发车后按实装运单各生成一张调入仓入库单（主 PRD §3.4），**不另定义字段本体**：

- 收货单号：新生成
- 入库类型=调拨入库
- 预报仓库=调拨计划单的调入仓库
- 收货仓库：空，待集货仓收货回写
- 运单号 / 客户代码：继承实装
- 实装箱数 / 重量 / 体积：**写入预报列**（预报箱数、预报重量、预报体积）；收货重量/收货体积不回写
- **生成时**集货仓按每张单的**预报箱数**计**预报库存 +**（主 PRD §3.4）
- 该批入库单均收货完成后，调拨计划状态 → 已完成；绑托、上架不挡住调拨完结

### 5.5 明确不纳入本单的字段

- 上架单：作业单号、初始库位、目标库位、作业类型（上架单清单，本文不展开）
- 出库单：出库单号、归属仓库、发运结果（出库单清单，本文不展开）
- 调拨计划单号：调拨计划单字段；本单与空单调拨无下推关系（§3.5）
- 扫描时间、扫描人、明细绑托时间：不需要，不收录
- 共托上限：不需要，不收录

### 5.6 重发与取消对字段的影响

- 仅待收货可取消；已绑托、已上架拒绝（R08）
- 取消后重发：全量覆盖头部与收货明细，回写字段重置，状态回待收货（R07）
- 未取消重复发车：按运单号拒绝，不用仓库号匹配（R06/S09）
