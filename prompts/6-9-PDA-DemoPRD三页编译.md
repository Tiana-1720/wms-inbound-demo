## PDA 移动端通用规范（三页均须遵守）

| 项目 | 规格 |
| :--- | :--- |
| 设备视口 | 以手机竖屏为主，设计基准宽度 **375px**；内容区可纵向滚动 |
| 扫描输入 | 页面顶部常驻 `ScanInput`（支持硬件扫枪 + 软键盘）；扫码后自动触发校验，无需再点搜索 |
| 底部操作栏 | 主操作固定在底部 `FixedBottomBar`；单手持握场景，主按钮高度 ≥ 44px |
| 按钮显隐 | **不渲染 disabled 按钮**（不可用时不展示入口，不用灰色禁用态占位） |
| 列表形态 | 待办任务用 `MobileListCard` 卡片列表，不用桌面端宽表格 |
| 库位选择 | 使用 `BottomSheet` + `SelectWithSearch`；选项过滤规则只引用主 PRD，不扩展 |
| 加载/空/错 | 每页均须定义三种状态（见各文件要求） |
| 成功反馈 | 关键动作成功用 Toast；完成后按主 PRD 停留在当前页或返回上一级（不臆造跳转） |
| 仓库类型分支 | 上架页须注明：**仓库类型=加盟揽收仓** 时走 §11.3 增量；非加盟仓走现网逻辑（Demo 只展开加盟路径，现网差异用对照表简述，不新开规则） |

文件 1：04-05-分货_Demo.md
（PDA 分货作业页）
═══════════════════════════════════════

**权威来源**：主 PRD §二 In Scope「收货分货绑托」、§5.1、§6.1；字段清单《收货订单-入库单》头部 + §二收货明细。

**菜单路径**：`PDA → 入库管理 → 分货`。**不沿用**现网 `PDA → 入库管理 → 绑托` 页面，为加盟揽收仓独立新页；业务动作仍对齐主 PRD §5.1（确认绑托等）。

必须包含：

### 1. 页面概述
- 页面目标（一句话：逐箱扫描完成收货确认与分货绑托）
- 页面路径（路由占位，如 `/pda/inbound/bind-pallet`）
- 菜单路径与权限说明
- 骨架结构：顶栏 → 扫描区 → 运单信息区 → 当前托盘/扫描进度区 → 箱明细列表 → 底部操作栏

### 2. 页面字段展示区
只展示字段清单中与本页相关的字段（**禁止新增**）：

| 区域 | 允许展示的字段（示例，以字段清单为准） |
| :--- | :--- |
| 运单信息区 | **运单号**、**预报箱数**、**收货箱数**（绑托前为已扫箱数/进度）、**状态** |
| 箱明细行 | **箱号**、**托号**（绑托后回写；绑托中可为当前分配托号） |
| 不展示 | 预报重量/体积、收货重量/体积（加盟路径不回写，R05） |

字段控件类型一律 **ReadonlyText**（PDA 本页不可编辑预报类字段，R31）。

### 3. 扫描交互
- 扫描对象：箱号（客户箱号/德速箱号）
- 校验规则：翻译主 PRD §5.1.3「待收货 + 确认绑托」前置条件与失败处理（无预报拦截、已绑托箱不可重复扫等）
- 扫描成功后的页面反馈（高亮当前箱、累加已扫箱数等**呈现规则**；不新增校验逻辑）

### 4. 底部操作按钮
来自 §5.1.4 动作能力矩阵，按**收货订单状态=待收货** 翻译：

| 按钮 | 展示条件 | 行为说明 |
| :--- | :--- | :--- |
| 重置 | 待收货且有扫描数据 | 清空当前页扫描缓存（呈现层） |
| 确认绑托 | 待收货且至少扫入 1 箱 | 触发 §5.1.3 确认绑托；成功后状态→已绑托 |

**不展示**的动作：查看待上架单、执行上架、修改预报、取消（矩阵中为 ❌ 的均不出现）。

### 5. 二次确认与阻断弹窗
翻译主 PRD 失败处理与 §8.3 边界，至少覆盖：
- 无预报箱号扫描
- 件数差异提示走上游取消重发
- 确认绑托成功 Toast

### 6. 空状态、加载状态、错误状态

| 状态 | 触发条件 | 展示 |
| :--- | :--- | :--- |
| 加载 | 扫码后拉取运单/箱预报 | 骨架屏或 Loading |
| 空状态 | 进入页面尚未扫描 | 引导文案「请扫描箱号开始分货」 |
| 错误 | 校验失败 | 行内红字或 Toast；**不新增**主 PRD 未定义的 error code |

### 7. Mock 数据规格
- 至少覆盖：待收货一票一托、多票共托、大票多托各 1 组演示数据
- 箱号、运单号使用虚构数据

| 按钮 | 说明 |
| :--- | :--- |

| 上架明细 | 跳转子页 C（顶部入口或文字链） |

#### 3.5 加盟增量对照表（简述，不重复主 PRD 全文）

- 只读列表

### 5. 空状态、加载状态、错误状态
- 入口页无待上架任务
- 扫描校验失败（未绑托、重复上架）
- 跨库位不一致确认弹窗（§11.3 #5，沿用现网文案呈现）

### 6. Mock 数据规格
- 待上架 / 已完成各至少 1 条
